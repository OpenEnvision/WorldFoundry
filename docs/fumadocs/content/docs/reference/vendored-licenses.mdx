---
title: Third-party notices
description: Where to find the authoritative license and provenance records for in-tree upstream code.
---

WorldFoundry includes selected upstream inference code and optional native dependencies. Complete license texts, copyright statements, and component restrictions are collected in the root `THIRD-PARTY-NOTICES`; this page provides links to those records.

- [Licenses and third-party notices](https://github.com/iChubai/WorldFoundry/blob/release/public-inference-20260909/THIRD-PARTY-NOTICES) include WorldFoundry's Apache-2.0 license, upstream terms, model notices, and the consolidated `thirdparty/` license notes. `Original-File` labels identify where each retained text came from.
- [Upstream provenance](https://github.com/iChubai/WorldFoundry/blob/release/public-inference-20260909/thirdparty/UPSTREAM_PROVENANCE.md) records source repositories and revisions for vendored components.

The Kandinsky6 BigVGAN audio decoder retains all nine upstream license texts:
NVIDIA, HiFi-GAN, Snake, alias-free-torch, Seungwon Park, Julius, Descript,
Charactr and Amphion. Look up the `bigvgan_v2/LICENSE` and
`bigvgan_v2/incl_licenses/LICENSE_1` through `LICENSE_8` records in
`THIRD-PARTY-NOTICES`. Their complete texts are included in both distribution
formats; the decoder's source comments identify the applicable records.

Read the applicable license text and retained source-file notices before redistributing or using a component. Consolidation does not change any component's license or remove distribution restrictions. Model checkpoints and datasets may have separate terms; their catalog entries and upstream release pages identify those sources. Wheels and source distributions include the central notice bundle.
