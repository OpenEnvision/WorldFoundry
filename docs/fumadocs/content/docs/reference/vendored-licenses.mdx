title: Third-party notices
description: Where to find the authoritative license and provenance records for in-tree upstream code.
---

WorldFoundry includes selected upstream inference code and optional native dependencies. The repository's notice and provenance files are the source of truth; this page is a map to them, not a replacement for their terms.

- [Third-party notices](https://github.com/OpenEnvision/WorldFoundry/blob/main/THIRD-PARTY-NOTICES) cover upstream source adaptations, research implementations, models, and optional packages used across the repository.
- [Vendored license notes](https://github.com/OpenEnvision/WorldFoundry/blob/main/thirdparty/THIRD_PARTY_LICENSES.md) summarize licenses and restrictions for code under `thirdparty/`.
- [Upstream provenance](https://github.com/OpenEnvision/WorldFoundry/blob/main/thirdparty/UPSTREAM_PROVENANCE.md) records source repositories and revisions for vendored components.

Read the applicable upstream license text and source-file notices before redistributing or using a component. Model checkpoints and datasets may have separate terms; their catalog entries and upstream release pages identify those sources.
