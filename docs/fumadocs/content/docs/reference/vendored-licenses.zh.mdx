WorldFoundry 包含部分上游推理代码和可选的原生依赖。仓库中的 notice 与 provenance 文件是这些信息的权威来源；本页只提供入口，不替代原始许可条款。

- [第三方声明](https://github.com/OpenEnvision/WorldFoundry/blob/main/THIRD-PARTY-NOTICES)涵盖仓库使用的上游源码改编、研究实现、模型与可选组件。
- [仓内依赖许可说明](https://github.com/OpenEnvision/WorldFoundry/blob/main/thirdparty/THIRD_PARTY_LICENSES.md)汇总 `thirdparty/` 下代码的许可与使用限制。
- [上游来源记录](https://github.com/OpenEnvision/WorldFoundry/blob/main/thirdparty/UPSTREAM_PROVENANCE.md)记录仓内依赖的源码仓库与版本。

重新分发或使用组件前，请阅读适用的上游许可原文和源码文件中的声明。模型 checkpoint 与数据集可能另有条款；可从目录条目和上游发布页查找来源。
