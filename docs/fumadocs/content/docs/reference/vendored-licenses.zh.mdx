title: 第三方许可与来源
description: 查找仓内上游代码的正式许可说明与来源记录。
---

WorldFoundry 包含部分上游推理代码和可选的原生依赖。仓库级许可原文、版权声明和组件限制维护在根目录的 `THIRD-PARTY-NOTICES`。上游要求保留的组件许可文件（包括仓内 BigVGAN 声明）仍随源码保存，并在 package data 中声明。本页提供集中记录的入口。

- [项目许可证](https://github.com/OpenEnvision/WorldFoundry/blob/main/LICENSE)包含 WorldFoundry 自有代码的 Apache-2.0 条款。
- [许可证与第三方声明](https://github.com/OpenEnvision/WorldFoundry/blob/main/THIRD-PARTY-NOTICES)包含 WorldFoundry 自身的 Apache-2.0 许可证、上游许可原文、模型声明，以及集中后的 `thirdparty/` 许可说明。`Original-File` 标明每段保留文本的原始来源。
- [上游来源记录](https://github.com/OpenEnvision/WorldFoundry/blob/main/thirdparty/UPSTREAM_PROVENANCE.md)记录仓内依赖的源码仓库与版本。

重新分发或使用组件前，请阅读适用的许可原文和源码中保留的声明。集中整理不改变组件的许可证，也不解除分发限制。模型 checkpoint 与数据集可能另有条款；可从目录条目和上游发布页查找来源。wheel 和源码发行包均包含项目许可证和集中的第三方许可文件。
