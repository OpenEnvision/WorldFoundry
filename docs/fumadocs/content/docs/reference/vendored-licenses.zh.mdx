WorldFoundry 包含部分上游推理代码和可选的原生依赖。完整许可证文本、版权声明和组件使用限制统一放在根目录的 `THIRD-PARTY-NOTICES`；本页提供正式记录的入口。

- [许可证与第三方声明](https://github.com/iChubai/WorldFoundry/blob/release/public-inference-20260909/THIRD-PARTY-NOTICES)包含 WorldFoundry 自身的 Apache-2.0 许可证、上游许可原文、模型声明，以及集中后的 `thirdparty/` 许可说明。`Original-File` 标明每段保留文本的原始来源。
- [上游来源记录](https://github.com/iChubai/WorldFoundry/blob/release/public-inference-20260909/thirdparty/UPSTREAM_PROVENANCE.md)记录仓内依赖的源码仓库与版本。

重新分发或使用组件前，请阅读适用的许可原文和源码中保留的声明。集中整理不改变组件的许可证，也不解除分发限制。模型 checkpoint 与数据集可能另有条款；可从目录条目和上游发布页查找来源。wheel 和源码发行包均包含集中后的许可文件。
