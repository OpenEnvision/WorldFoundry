ManiSkill 是加州大学圣迭戈分校 Hao Su 实验室基于 **SAPIEN** 的 **GPU 并行**操作评测：数十个技能族、多种机器人本体、演示数据集，以及面向 RL 与模仿学习的大规模并行 rollout。论文是 [ManiSkill: Generalizable Manipulation Skill Benchmark with Large-Scale Demonstrations](https://arxiv.org/abs/2302.04659)。项目：[maniskill.ai](https://maniskill.ai/)。代码：[haosulab/ManiSkill](https://github.com/haosulab/ManiSkill)（Apache-2.0）。后续的 ManiSkill2 / ManiSkill3 仍由同一实验室开发，并使用同一引擎。

WorldFoundry **只导入官方结果**。先在上游工具中完成评测，再用 `official-validation` 将 JSON/CSV rollout 摘要归一化到统一 scorecard。模拟器执行、策略加载和数据采集都在上游工具中完成。仓库镜像：`cache/vla_va_wam/repos/haosulab--ManiSkill`。

## 如何运行

```bash
wf zoo benchmark-run \
  --benchmark-id maniskill \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/maniskill/official-validation \
  --json
```

省略 `--official-results-path` 时，默认导入路径是 `WORLDFOUNDRY_MANISKILL_RESULTS_PATH`。任务清单：`worldfoundry/data/benchmarks/tasks/external/maniskill.yaml`。产物：`scorecard.json`（主键 `success_rate`）与 `raw_results.jsonl`。
