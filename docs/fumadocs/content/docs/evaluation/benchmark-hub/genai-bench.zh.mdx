GenAI-Bench（滑铁卢大学 TIGER-Lab，随 GenAI-Arena 发布）测的是**自动裁判是否对齐人工偏好**，不是生成器好不好看。每条记录是同一 prompt 的一对输出加人工标签。WorldFoundry 打整体 **成对准确率**，并按三个任务拆开：

- **图像生成**
- **图像编辑**
- **视频生成**

任务级成对齐备时，`genai_bench_average` 是各任务准确率的均值。

论文：[GenAI-Bench](https://arxiv.org/abs/2406.04485)。代码：[TIGER-AI-Lab/GenAI-Bench](https://github.com/TIGER-AI-Lab/GenAI-Bench)。数据集：[`TIGER-Lab/GenAI-Bench`](https://huggingface.co/datasets/TIGER-Lab/GenAI-Bench)（CC-BY-4.0）。

WorldFoundry **归一化官方结果行**。一行必须有 `task`（`image_generation` / `image_editing` / `video_generation`）、人工标签（`human_label` / `human_preference`）和裁判预测（`prediction` / `judge_prediction`）。它不生成偏好标签。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id genai-bench \
  --mode official-validation \
  --official-results-path <official_results.jsonl> \
  --generated-artifact-dir <generated_videos> \
  --output-dir tmp/genai-bench/official-validation \
  --json
```

`--preference-pairs-path` 提供成对清单。默认导入路径：`WORLDFOUNDRY_GENAI_BENCH_RESULTS_PATH`。共享资源：`genai_bench_dataset_assets`、`t2v_metrics_source_assets`。

仓内指针：`worldfoundry/data/benchmarks/tasks/external/genai-bench.yaml`。

产物包括 `scorecard.json`（主键 `genai_bench_average`）、`benchmark_contract.json`、`raw_metric_table.jsonl`。
