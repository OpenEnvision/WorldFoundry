World-in-World（约翰霍普金斯，联合北大、普林斯顿、MIT 与哈佛；ICLR 2026 口头）在镜像智能体-环境交互的 **闭环** 里评生成式世界模型。**任务成功优先于视觉质量。** 统一在线规划器与标准化动作 API 覆盖四个环境：

- Active Recognition
- Active Embodied QA
- Image-Goal Navigation（成功率 + SPL）
- 机器人操作

论文发现：视觉质量本身不保证成功（可控性更重要）；动作-观察后训练优于升级视频生成器；推理时计算能提升闭环表现。

`world_in_world_average` 是已有闭环指标的均值。

论文：[World-in-World](https://arxiv.org/abs/2510.18135)。项目：[world-in-world.github.io](https://world-in-world.github.io/)。代码：[World-In-World/world-in-world](https://github.com/World-In-World/world-in-world)。

WorldFoundry 是 **结果导入器**。闭环环境、规划器、worker 与任务打分器在 **上游** 执行。捆绑资产只支持解析与覆盖检查。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id world-in-world \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir tmp/world-in-world/official-validation \
  --json
```

可选 `--task` / `--exp-id` 限定导入范围。默认：`WORLDFOUNDRY_WORLD_IN_WORLD_RESULTS_PATH`。

仓内指针：`worldfoundry/data/benchmarks/tasks/external/world-in-world.yaml`，`worldfoundry/data/benchmarks/assets/world-in-world`，`worldfoundry/evaluation/tasks/execution/runners/world_in_world`。

产物包括 `scorecard.json`（主键 `world_in_world_average`）。
