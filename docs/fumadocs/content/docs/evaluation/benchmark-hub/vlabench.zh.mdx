VLABench（复旦大学 OpenMOSS）评的是需要 **世界知识与多步推理** 的语言条件操作，不只是指令跟随。官方规模：**100 个任务类别**、MuJoCo 中 **2000+ 物体**，探测网格 / 纹理理解、空间与语义推理、物理定律理解，以及 VLA 策略与 VLM 规划器的长程规划。

论文：[VLABench](https://arxiv.org/abs/2502.09858)。代码：[OpenMOSS/VLABench](https://github.com/OpenMOSS/VLABench)。许可证：上游条款。

WorldFoundry 是 **官方结果导入器**。模拟器执行、策略加载与 rollout 采集仍在上游。scorecard 主键：`success_rate`。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id vlabench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/vlabench/official-validation \
  --json
```

默认导入：`WORLDFOUNDRY_VLABENCH_RESULTS_PATH`。可选根：`WORLDFOUNDRY_VLABENCH_ROOT`。

仓内指针：`worldfoundry/data/benchmarks/tasks/external/vlabench.yaml`。

产物包括 `scorecard.json`（主键 `success_rate`）、`raw_results.jsonl`、`evaluation/summary.json`。
