LIBERO-PRO（华中科技大学，联合哈佛、MIT、武汉理工与 Lehigh）**不是**新的终身学习套件，也**不是** [LIBERO-Plus](/zh/docs/evaluation/benchmark-hub/libero-plus) 的 10,030 实例因子网格。它是叠在原始 LIBERO 任务上的**即插即用**层。论点是：原版 LIBERO 的训练 / 评测几乎是同一场景，所以 90%+ 可能是轨迹回放。PRO 施加**合理**扰动，再问策略是否仍把指令接地。

论文图 6 的五类：

- **物体属性** — 颜色、纹理、尺度；语义目标不变。
- **初始构型** — 仍物理可行的摆放。很小的位置偏移就会让许多 VLA 归零。
- **指令** — 同一目标的改写。
- **任务重设计** — 新的物体集合或组合目标。这类**不**与另外四类混用。
- **环境** — 背景、光照、纹理；可行性不变。

另外四类可以组合。官方评测与原版 LIBERO 一致：**每任务 50 个 episode**。论文报告干净 LIBERO 上超过 **90%** 的模型在泛化 PRO 设置下塌到 **0%**——这是上游结论，不是 Hub 行。

论文：[LIBERO-PRO](https://arxiv.org/abs/2510.03827)。项目：[LIBERO-PRO 主页](https://zxy-mllab.github.io/LIBERO-PRO-Webpage/)。代码：[Zxy-MLlab/LIBERO-PRO](https://github.com/Zxy-MLlab/LIBERO-PRO)（MIT）。数据集：`zhouxueyang/LIBERO-Pro`。

WorldFoundry **只导入官方结果**。你在上游跑该叠加层，再经 `official-validation` 归一化导出。仓内不跑 robosuite。[基础 LIBERO](/zh/docs/evaluation/benchmark-hub/libero) 可以接线闭环；本页不行。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id libero-pro \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/libero-pro/official-validation \
  --json
```

可选 `WORLDFOUNDRY_LIBERO_PRO_ROOT` 指向 `Zxy-MLlab/LIBERO-PRO` 检出。默认导入路径：`WORLDFOUNDRY_LIBERO_PRO_RESULTS_PATH`。清单：`worldfoundry/data/benchmarks/tasks/external/libero-pro.yaml`。输出：`scorecard.json`（主键 `success_rate`）、`raw_results.jsonl`、`evaluation/summary.json`。
