Kinetix（牛津大学 FLAIR；ICLR 2025 口头报告）是一个 **开放式、JAX 加速的 2D 物理 RL 环境空间**。可程序化表示的关卡在同一个模拟器里覆盖机器人式移动、抓取与经典控制，通用智能体可以大规模预训练，再在留出任务上评测。

论文：[Kinetix](https://arxiv.org/abs/2410.23208)。代码：[FLAIROx/Kinetix](https://github.com/FLAIROx/Kinetix)。许可证：上游条款。

WorldFoundry 是 **官方结果导入器**。模拟器执行、策略加载与 rollout 采集仍在上游。scorecard 主键是 `success_rate`。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id kinetix \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/kinetix/official-validation \
  --json
```

默认导入：`WORLDFOUNDRY_KINETIX_RESULTS_PATH`。可选根：`WORLDFOUNDRY_KINETIX_ROOT`。

仓内指针：`worldfoundry/data/benchmarks/tasks/external/kinetix.yaml`。

产物包括 `scorecard.json`（主键 `success_rate`）、`raw_results.jsonl` 与 `evaluation/summary.json`。
