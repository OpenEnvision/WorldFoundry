VideoPhy2（UCLA 与 Google DeepMind）是 [VideoPhy](/zh/docs/evaluation/benchmark-hub/videophy) 的 **动作向** 后继。Prompt 套件聚焦更难的物理活动与物体交互（**宣称 200 个动作**）。AutoEval 增加 **规则级** 判断：哪些物理规则适用、每条是遵守还是违反（`rule_followed_rate`），同时报语义遵守、物理常识，以及主键 **联合分**。

论文：[VideoPhy-2](https://arxiv.org/abs/2503.06800)。项目：[videophy2.github.io](https://videophy2.github.io/)。代码：[Hritikbansal/videophy](https://github.com/Hritikbansal/videophy)。

WorldFoundry **捆绑 prompt 列表** 并驱动仓内 AutoEval 裁判（`--autoeval-checkpoint`，可选 `--autoeval-lora-checkpoint`）。官方打分路径存在；**完整 200 条 prompt 复现仍待完成**。权重要调用方提供。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id videophy2 \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir tmp/videophy2/official-validation \
  --json
```

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/videophy2/run_videophy2_official_runner.py \
  --run-official \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --autoeval-checkpoint /path/to/videophy2_autoeval \
  --output-dir tmp/videophy2/official \
  --json
```

环境变量：`WORLDFOUNDRY_VIDEOPHY2_RESULTS_PATH`、`WORLDFOUNDRY_VIDEOPHY2_JUDGE_BACKEND`。Prompt 列表：`worldfoundry/data/benchmarks/assets/videophy2/prompts.json`。共享资源：`videophy2_dataset_assets`。

仓内指针：`worldfoundry/data/benchmarks/tasks/external/videophy2.yaml`，`worldfoundry/evaluation/tasks/execution/runners/videophy2`。

产物包括 `scorecard.json`（主键 `joint_score`）。
