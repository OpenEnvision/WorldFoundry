MiKASA-Robo 是 **MIKASA**（面向智能体的记忆密集技能评估套件）的桌面部分，来自 AIRI、MIPT 与 HSE。ICLR 2026 论文是 **32** 个 ManiSkill RL 任务、**12** 组、四类记忆：**物体**、**空间**、**顺序**、**容量**（遮挡回忆、先前布局、长动作顺序）。后续 **MIKASA-Robo-VLA** 扩展为 **90** 个语言条件任务（**10** 类记忆）、短 / 中 / 长时程（25–2160 步），以及 **22500** 条 oracle 轨迹。这两次发布**不可互换**。

论文：[Memory, Benchmark & Robots](https://arxiv.org/abs/2502.10550)（[OpenReview](https://openreview.net/forum?id=9cLPurIZMj)）。VLA 文档：[mikasarobo.github.io](https://mikasarobo.github.io/)。代码：[CognitiveAISystems/MIKASA-Robo](https://github.com/CognitiveAISystems/MIKASA-Robo)。

WorldFoundry **导入**官方结果导出。它**不跑** ManiSkill、不采集 PPO/oracle 轨迹，也不替你选定 RL 还是 VLA——请在导出上声明。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id mikasa \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/mikasa/official-validation \
  --json
```

可选 `WORLDFOUNDRY_MIKASA_ROOT` 指向本地 runtime / 仓库。默认导入路径：`WORLDFOUNDRY_MIKASA_RESULTS_PATH`。清单：`worldfoundry/data/benchmarks/tasks/external/mikasa.yaml`。产物：`scorecard.json`（主键 `success_rate`）、`raw_results.jsonl`、`evaluation/summary.json`。
