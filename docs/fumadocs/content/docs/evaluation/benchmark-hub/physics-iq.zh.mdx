Physics-IQ（Google DeepMind）问的是视频模型会不会**续写真实物理**，不是像素好不好看。每个测试项给出一段实拍场景，模型必须生成接下来的 **5 秒**。发表协议是 **66 个场景 × 2 视角**（396 项）。WorldFoundry 的 contract 跟踪 **198 视频单次**划分。打分把续写与真实未来对比：基于运动 mask 的 **spatial / spatiotemporal** 一致度，再加 **MSE** 惩罚，聚合为 `physics_iq_score`（官方 `final_score_orig`）。当前官方代码还会输出分量截断的 `physics_iq_stable_score`。

论文：[Physics-IQ](https://arxiv.org/abs/2501.09038)。项目：[physics-iq.github.io](https://physics-iq.github.io/)。代码：[google-deepmind/physics-IQ-benchmark](https://github.com/google-deepmind/physics-IQ-benchmark)。

和本 Hub 上那些操作导入器不同，WorldFoundry **仓内内置打分 runtime**（`run_physics_iq_official_runner.py`，经 `--protocol` 与 `physics-iq-verified` 共享），并把 prompt/场景元数据放在 `worldfoundry/data/benchmarks/assets/physics-iq`。官方**媒体**（真实视频、mask、条件帧）仍要从 DeepMind 下载——不在仓库里。[Physics-IQ Verified](/zh/docs/evaluation/benchmark-hub/physics-iq-verified) 用另一套数据；两者**不可互换**。

## 如何运行

导入已有的 `raw_metrics.csv`：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id physics-iq \
  --mode official-validation \
  --official-results-path <raw_metrics.csv> \
  --output-dir tmp/physics-iq/official-validation \
  --json
```

从按官方 scenario id 命名的 198 段续写重算：

```bash
export WORLDFOUNDRY_GENERATED_ARTIFACT_DIR=/path/to/physics-iq/generated_videos
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/physics_iq/run_physics_iq_official_runner.py \
  --protocol physics-iq \
  --run-official \
  --dataset-root /path/to/physics-iq-benchmark \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --output-dir tmp/physics-iq/official-run \
  --strict \
  --json
```

缺场景视频时 `--strict` 会失败。`--generated-mask-dir` 可提供预计算 mask；否则 mask 来自真实视频。产物包括 `scorecard.json`（主键 `physics_iq_score`）、`raw_metrics.csv`、`official_metrics.json`，以及来源提供时的逐样本行。
