BEHAVIOR-1K 是斯坦福 Vision & Learning Lab 的人本具身评测：从人类时间使用调查里选出 **1000** 项日常活动（清洁、烹饪、整理），用 **BDDL** 谓词语言书写，在 **OmniGibson** 里仿真，带流体、物体状态和家居物理。成功是**逻辑目标是否满足**，不是像素分。**子目标**满足率是部分分。

论文：[BEHAVIOR-1K](https://arxiv.org/abs/2403.09227)。项目：[behavior.stanford.edu](https://behavior.stanford.edu/)。模拟器 / 代码：[StanfordVL/OmniGibson](https://github.com/StanfordVL/OmniGibson)（本 catalog 记为 `upstream_terms`）。

WorldFoundry **导入**官方 OmniGibson 结果导出。它不内置 OmniGibson、那 1000 项活动定义或策略 checkpoint。那些遵循斯坦福文档。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id behavior1k \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/behavior1k/official-validation \
  --json
```

可选的 `WORLDFOUNDRY_BEHAVIOR1K_ROOT` 指向本地 OmniGibson / 活动根目录。默认导入路径：`WORLDFOUNDRY_BEHAVIOR1K_RESULTS_PATH`。清单：`worldfoundry/data/benchmarks/tasks/external/behavior1k.yaml`。产物：`scorecard.json`（主键 `success_rate`；另有 `subgoal_success`）、`raw_results.jsonl`、`evaluation/summary.json`。
