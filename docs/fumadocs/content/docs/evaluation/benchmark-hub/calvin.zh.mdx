CALVIN（Composing Actions from Language and Vision）是弗莱堡大学的长时程、语言条件操作评测（IEEE RA-L 2022）。策略在 **PyBullet** 桌面上必须串起最多**五条**语言指令。四个环境配置 **A/B/C/D** 测零样本迁移：标志性划分是在 A/B/C 上训练，在未见过的 **D** 上评测。论文报告的是每个链长度的成功率，以及**平均完成的指令数**，不是单一的 episode 成败比特。

论文：[CALVIN](https://ieeexplore.ieee.org/document/9788026)（项目 [calvin.cs.uni-freiburg.de](http://calvin.cs.uni-freiburg.de/)）。代码：[mees/calvin](https://github.com/mees/calvin)（MIT）。

WorldFoundry 是**官方结果导入器**。你在上游跑序列评测器，再归一化导出。模拟器、数据集根目录和策略权重遵循官方 CALVIN 文档。仓库镜像：`cache/vla_va_wam/repos/mees--calvin`。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id calvin \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/calvin/official-validation \
  --json
```

默认导入路径：`WORLDFOUNDRY_CALVIN_RESULTS_PATH`。清单：`worldfoundry/data/benchmarks/tasks/external/calvin.yaml`。产物：`scorecard.json`（主键 `success_rate`；另有 `sequence_success`、`completion`）与 `raw_results.jsonl`。
