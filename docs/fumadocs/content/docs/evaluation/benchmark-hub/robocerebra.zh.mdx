RoboCerebra（北京航空航天大学 CoLa 实验室，NeurIPS 2025）考察长时程家务序列上的 **System-2** 规划，而不是反应式 System-1 控制。官方发布是 **100** 个任务变体上的 **1000** 条人工标注轨迹（平均 **9.1** 个原子步；时程约 **3000** 仿真步），建立在 **LIBERO** 栈上。发表评测为 **600** 次 rollout（**60** 任务 × **10** 次），并用锚点对齐规划器 / VLA 交接。六个官方条件：**Ideal**、**Memory Exploration**、**Memory Execution**、**Random Disturbance**、**Observation Mismatching**、**Mix**。

论文：[RoboCerebra](https://arxiv.org/abs/2506.06677)。项目：[robocerebra.github.io](https://robocerebra.github.io/)。代码：[buaa-colalab/RoboCerebra](https://github.com/buaa-colalab/RoboCerebra)。

WorldFoundry **导入**官方结果导出（`worldfoundry-eval zoo benchmark-run --mode official-validation`）。它**不跑**捆绑的 LIBERO 模拟器、不采集 rollout，也不托管分层 VLM 规划器 + VLA 控制器。若要数字可比较，请在导出上写明六条件划分。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id robocerebra \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/robocerebra/official-validation \
  --json
```

可选 `WORLDFOUNDRY_ROBOCEREBRA_ROOT` 指向本地评测 / runtime 根目录。默认导入路径：`WORLDFOUNDRY_ROBOCEREBRA_RESULTS_PATH`。清单：`worldfoundry/data/benchmarks/tasks/external/robocerebra.yaml`。产物：`scorecard.json`（主键 `success_rate`）、`raw_results.jsonl`、`evaluation/summary.json`。
