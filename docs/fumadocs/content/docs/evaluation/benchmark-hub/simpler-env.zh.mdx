SimplerEnv（SIMPLER — Simulated Manipulation Policy Evaluation for Real Robot Setups）是加州大学圣迭戈分校与 Google DeepMind（联合斯坦福、伯克利）的 **real-to-sim** 评测。ManiSkill2 / SAPIEN 场景经过标定，让 **RT-1**、**RT-1-X**、**Octo** 等策略在仿真里的排序，尽量对上对应的 **Google Robot** 与 **WidowX / Bridge** 真机排序。套件的要点是那份相关性，不是又一套厨房资产。

论文：[OpenReview](https://openreview.net/forum?id=LZh48DTg71)。项目：[simpler-env.github.io](https://simpler-env.github.io/)。代码：[simpler-env/SimplerEnv](https://github.com/simpler-env/SimplerEnv)（MIT）。

WorldFoundry **不跑**这些场景。它把官方 rollout 导出归一进 scorecard。上游 rollout 仍需要 ManiSkill2/SAPIEN 栈和本体资产。仓库镜像：`cache/vla_va_wam/repos/simpler-env--SimplerEnv`。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id simpler-env \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/simpler-env/official-validation \
  --json
```

默认导入路径：`WORLDFOUNDRY_SIMPLERENV_RESULTS_PATH`。清单：`worldfoundry/data/benchmarks/tasks/external/simpler-env.yaml`。产物：`scorecard.json`（主键 `success_rate`）与 `raw_results.jsonl`。
