WBench (Meituan LongCat) evaluates **multi-turn interactive video world models** along five axes that roll into `wbench_average`:

- **Quality** — aesthetic, imaging, flicker, dynamics, smoothness, HPSv3
- **Setting** — scene / subject adherence
- **Interaction** — navigation trajectory, event edits, subject actions, perspective switches
- **Consistency** — background, segment continuity, perspective, subject, geometric / photometric reconstruction, spatial (incl. gated)
- **Physical** — visual plausibility, causal fidelity

Paper: [WBench](https://arxiv.org/abs/2605.25874). Project: [meituan-longcat.github.io/WBench](https://meituan-longcat.github.io/WBench/). Code: [meituan-longcat/WBench](https://github.com/meituan-longcat/WBench). Data: [`meituan-longcat/WBench`](https://huggingface.co/datasets/meituan-longcat/WBench). Weights: [`meituan-longcat/WBench-weights`](https://huggingface.co/meituan-longcat/WBench-weights).

WorldFoundry **checks in the metric runtime** (HPSv3, TransNetV2, PAVRM, DreamSim, MegaSAM pose precompute). A **real single-video `temporal_flickering` component is verified**; the **289-case multi-turn protocol is not**. `--official-results-path` imports `report.json` or per-metric directories.

## How to run

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/wbench/run_wbench_official_runner.py \
  --run-official \
  --model-name <model_name> \
  --phase gpu \
  --metrics temporal_flickering \
  --dataset-root <WBench_dataset> \
  --generated-artifact-dir <one_officially_named_generated_video> \
  --output-dir tmp/wbench/flicker \
  --json
```

`--submission-protocol text_multi_turn|camera_conditioned|action_conditioned` only when videos truly follow that official multi-turn interface. Env: `WORLDFOUNDRY_WBENCH_RESULTS_PATH`, `WORLDFOUNDRY_WBENCH_ROOT`. Shared stack: `video_world_perception_stack`.

In-tree pointers: `worldfoundry/data/benchmarks/tasks/external/wbench.yaml`, `worldfoundry/evaluation/tasks/execution/runners/wbench`.

Outputs include `scorecard.json` (primary `wbench_average`).
