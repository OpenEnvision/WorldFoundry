LIBERO-Plus（CVPR 2026，复旦 / FudanNLP）是叠在原始 LIBERO Spatial / Object / Goal / Long 任务上的**仅评测**鲁棒性层，不是第五个终身学习套件。作者用受控扰动生成 **10,030** 个实例，覆盖 **七** 个因子（**21** 个子维）：

- **物体布局** — 目标位移、干扰物（1,525）。
- **相机视角** — 位姿与视场（1,599）。
- **机器人初始状态** — 起始位姿（1,550）。
- **语言指令** — LLM 改写（1,537）。
- **光照** — 强度、方向、颜色、阴影（1,142）。
- **背景纹理** — 场景 / 表面外观（1,076）。
- **传感器噪声** — 光度退化（1,601）。

实例按四个参考模型做成几个，分成 **L1–L5**（L1 = 四个都能做，L5 = 四个都不能）。论文对十个 VLA 的扫描报告：干净 LIBERO 约 **95%**，在不大的相机或初始状态扰动下掉到 **30% 以下**——这是上游结论，不是 Hub 分数。

论文：[LIBERO-Plus](https://arxiv.org/abs/2510.13626)。项目：[sylvestf.github.io/LIBERO-plus](https://sylvestf.github.io/LIBERO-plus/)。代码：[sylvestf/LIBERO-plus](https://github.com/sylvestf/LIBERO-plus)（MIT；可替换的 `libero` fork）。

WorldFoundry **只导入官方结果**。你在上游跑该 fork，再经 `official-validation` 归一化导出。仓内不跑 robosuite，也不带 Plus 资产。[基础 LIBERO](/zh/docs/evaluation/benchmark-hub/libero) 可以接线闭环；本页不行。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id libero-plus \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/libero-plus/official-validation \
  --json
```

可选 `WORLDFOUNDRY_LIBERO_PLUS_ROOT` 指向 `sylvestf/LIBERO-plus` 检出。默认导入路径：`WORLDFOUNDRY_LIBERO_PLUS_RESULTS_PATH`。清单：`worldfoundry/data/benchmarks/tasks/external/libero-plus.yaml`。输出：`scorecard.json`（主键 `success_rate`）、`raw_results.jsonl`、`evaluation/summary.json`。
