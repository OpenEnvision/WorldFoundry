PhyFPS-Bench-Gen（TACO Group，德州农工大学）审计**时间刻度幻觉**：生成器声明的容器帧率（**Meta FPS**）是否与运动隐含的物理速度（**PhyFPS**，由 Visual Chronometer 预测）一致。它**不是**定律、锚定、教育或续写评测。

套件是 **100 条 prompt**。输出命名为 `0001.mp4` … `0100.mp4`。预测器在滑动窗口上运行（`--stride`、`--clip-length`）；scorecard 报告 Meta 与 PhyFPS 的误差，以及视频内 / 视频间变异系数。**全部指标越低越好。**

代码：[taco-group/Visual_Chronometer](https://github.com/taco-group/Visual_Chronometer)。权重：[xiangbog/Visual_Chronometer](https://huggingface.co/xiangbog/Visual_Chronometer)（`vc_common_10_60fps.ckpt`）。

WorldFoundry 在仓内运行 Visual Chronometer `predict.py`，和/或归一化调用方的 `results.csv`。对齐指标需要 `WORLDFOUNDRY_PHYFPS_META_FPS`（或 manifest）。

## 如何运行

导入已有的 `results.csv`：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id phyfps-bench-gen \
  --mode official-validation \
  --official-results-path <results.csv> \
  --generated-artifact-dir <generated_videos> \
  --output-dir tmp/phyfps-bench-gen/official-validation \
  --json
```

在仓内预测 PhyFPS（对齐需要 VC-Common 权重与 Meta FPS）：

```bash
export WORLDFOUNDRY_PHYFPS_META_FPS=24
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/phyfps_bench_gen/run_phyfps_bench_gen_official_runner.py \
  --run-official \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --stride 4 \
  --output-dir tmp/phyfps_bench_gen/official \
  --json
```

产物包括 `scorecard.json`（主键 `phyfps_bench_gen_average`）与 `results.csv`。
