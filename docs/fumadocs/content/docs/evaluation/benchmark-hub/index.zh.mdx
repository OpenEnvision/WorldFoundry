这个 Hub 是**配方索引**，不是排行榜站。每张卡片来自 benchmark catalog 与 task manifest：套件测什么、需要哪些文件、WorldFoundry 哪条路径是真的（官方导入、仓内打分，或闭环）。它**不会编造排名**。详情页在有作者维护的实时榜时链出去，否则引用论文表或如实写明缺失。

## 怎么选

先想清楚要检验的主张，再打开对应配方——不要先装独立环境。

- **终身 / 知识迁移操作** — [LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（Franka 桌面上的四个套件）。厨房相关看 [RoboCasa](/zh/docs/evaluation/benchmark-hub/robocasa)。
- **GPU 并行技能族** — [ManiSkill](/zh/docs/evaluation/benchmark-hub/maniskill)（SAPIEN）。WorldFoundry 导入 rollout，不替代模拟器。
- **长时程语言链** — [CALVIN](/zh/docs/evaluation/benchmark-hub/calvin)（A/B/C → D，链长度 1–5 的成功率）。
- **真机到仿真的策略排序** — [SimplerEnv](/zh/docs/evaluation/benchmark-hub/simpler-env)（按真机标定的 Google Robot 与 WidowX/Bridge）。
- **带逻辑目标的家务活动** — [BEHAVIOR-1K](/zh/docs/evaluation/benchmark-hub/behavior1k)（OmniGibson 中 1000 项 BDDL 活动）。
- **视频模型会不会续写真实物理** — [Physics-IQ](/zh/docs/evaluation/benchmark-hub/physics-iq)（5 秒续写；仓内打分器）。只有当你要的就是那套协议时，才配 [Physics-IQ Verified](/zh/docs/evaluation/benchmark-hub/physics-iq-verified)——媒体不可互换。
- **开源文生视频片段质量 / 组合** — [VBench](/zh/docs/evaluation/benchmark-hub/vbench)、[T2V-CompBench](/zh/docs/evaluation/benchmark-hub/t2v-compbench)、[FETV](/zh/docs/evaluation/benchmark-hub/fetv)。

安装 benchmark-specific package 前先看[运行环境矩阵](/zh/docs/evaluation/benchmark-hub/runtime-environments)。它区分统一环境、仓库管理的独立环境、托管 judge，以及按维度划分的 native/checkpoint 栈。

## 如何运行一个 Benchmark

先打开配方。Prompt 文件、generated-artifact 布局、checkpoint 名称、judge model 和 official result 格式都是 benchmark-specific 的。

### 导入 Official Result 文件

配方写明 WorldFoundry **归一化**上游导出、不跑模拟器时用这条。

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id <benchmark-id> \
  --mode official-validation \
  --official-results-path <official-result-file-or-dir> \
  --generated-artifact-dir <generated-artifact-dir> \
  --output-dir tmp/<benchmark-id>/official-validation \
  --json
```

### 在仓内给生成产物打分

只有配方明确说仓内 runtime 能从 generated artifacts 重算分数，并且所需媒体或 checkpoint 已就位时，才用 `official-run`。常见例子是 Physics-IQ。

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id <benchmark-id> \
  --mode official-run \
  --generated-artifact-dir <generated-artifact-dir> \
  --output-dir tmp/<benchmark-id>/official-run \
  --json
```

需要先用已注册模型生成 artifact 时：

```bash
worldfoundry-eval run \
  --benchmark <benchmark-id> \
  --model <model-id> \
  --mode official-run \
  --output-dir tmp/<benchmark-id>/<model-id> \
  --json
```
