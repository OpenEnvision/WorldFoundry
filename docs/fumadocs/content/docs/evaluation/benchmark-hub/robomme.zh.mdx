RoboMME（密歇根大学，联合斯坦福与 Figure AI；ICML 2026）是面向**记忆增强** VLA 的标准化评测。**16** 个长时程任务分成四个认知套件——**Counting**（时间：精确计数）、**Permanence**（空间：遮挡与交换）、**Reference**（物体：依据先前线索解析身份）、**Imitation**（程序：复现演示轨迹）——各 4 个任务。官方发布含 **1600** 条演示与 **77 万**训练时间步，以及基于 **π0.5** 骨干的 **14** 个记忆增强变体。论文按套件报告成功率，不是单一抓放二值位。

论文：[RoboMME](https://arxiv.org/abs/2603.04639)。项目：[robomme.github.io](https://robomme.github.io/)。代码：[RoboMME/robomme_policy_learning](https://github.com/RoboMME/robomme_policy_learning)。

WorldFoundry **导入**官方 rollout 导出，并归一化总体与逐套件成功率。它**不跑** RoboMME 模拟器或那些 π0.5 变体。请在导出上写明套件（`counting` / `permanence` / `reference` / `imitation`）。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id robomme \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/robomme/official-validation \
  --json
```

可选 `WORLDFOUNDRY_ROBOMME_ROOT` 指向本地 runtime / 仓库。默认导入路径：`WORLDFOUNDRY_ROBOMME_RESULTS_PATH`。清单：`worldfoundry/data/benchmarks/tasks/external/robomme.yaml`。产物：`scorecard.json`（主键 `success_rate`；另有 `counting_success_rate`、`permanence_success_rate`、`reference_success_rate`、`imitation_success_rate`）、`raw_results.jsonl`、`evaluation/summary.json`。
