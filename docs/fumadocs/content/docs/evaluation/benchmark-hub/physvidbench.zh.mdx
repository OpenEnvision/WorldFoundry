PhysVidBench（Koç University / Cyberiada）是**字幕中介 QA**，不是像素对齐，也不是 PhyGenEval。T2V 模型先生成视频；上游 **AuroraCap** 出字幕；LLM 针对字幕回答物理**是/否**（可供性、工具使用、材料、时序动力学）。目录记录 **383 条 prompt** 与 **4123 道问题**（`cc-by-4.0`）。

[PhyGenBench](/zh/docs/evaluation/benchmark-hub/phygenbench) 用 VQAScore/VLM 阶段直接评视频。[PhyGround](/zh/docs/evaluation/benchmark-hub/phyground) 套 1–5 定律准则。PhysVidBench 在仓内不看像素——只看字幕 + 问题。

论文：[PhysVidBench](https://arxiv.org/abs/2507.15824)。项目：[cyberiada.github.io/PhysVidBench](https://cyberiada.github.io/PhysVidBench/)。代码：[ensanli/PhysVidBenchCode](https://github.com/ensanli/PhysVidBenchCode)。数据：[Anonymousny/PhysVidBench](https://huggingface.co/datasets/Anonymousny/PhysVidBench)。

WorldFoundry 捆绑 `prompts_questions.csv` 与字幕轨道。它**导入**上游 `output.csv`，或对你提供的字幕跑**有界 Gemini QA**。它**不**对你的视频跑 AuroraCap，也无法证明这些字幕来自那些视频。

## 如何运行

导入上游 QA 导出：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id physvidbench \
  --mode official-validation \
  --official-results-path <output.csv> \
  --generated-artifact-dir <generated_videos> \
  --output-dir tmp/physvidbench/official-validation \
  --json
```

对所供（或捆绑）字幕跑有界 Gemini QA——不是官方全流水线证据：

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/physvidbench/run_physvidbench_official_runner.py \
  --run-official \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --captions-dir worldfoundry/data/benchmarks/assets/physvidbench/captions \
  --output-dir tmp/physvidbench/official \
  --json
```

用 `WORLDFOUNDRY_PHYSVIDBENCH_JUDGE_BACKEND` 选择 judge。产物包括 `scorecard.json`（主键 `physvidbench_average`）与 `output.csv`。
