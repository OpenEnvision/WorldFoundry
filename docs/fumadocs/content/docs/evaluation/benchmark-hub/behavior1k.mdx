BEHAVIOR-1K is Stanford Vision & Learning Lab's human-centered embodied benchmark: **1,000** everyday activities (cleaning, cooking, tidying) chosen from human time-use surveys, written in the **BDDL** predicate language, and simulated in **OmniGibson** with fluids, object states, and household physics. Success is **logical goal satisfaction**, not a pixel score. **Subgoal** satisfaction is the partial-credit signal.

Paper: [BEHAVIOR-1K](https://arxiv.org/abs/2403.09227). Project: [behavior.stanford.edu](https://behavior.stanford.edu/). Simulator / code: [StanfordVL/OmniGibson](https://github.com/StanfordVL/OmniGibson) (`upstream_terms` in this catalog).

WorldFoundry **imports** official OmniGibson result exports. It does not vendor OmniGibson, the 1,000 activity definitions, or policy checkpoints. Those follow Stanford's documentation.

## How to run

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id behavior1k \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/behavior1k/official-validation \
  --json
```

Optional `WORLDFOUNDRY_BEHAVIOR1K_ROOT` points at a local OmniGibson / activity root. Default import path: `WORLDFOUNDRY_BEHAVIOR1K_RESULTS_PATH`. Manifest: `worldfoundry/data/benchmarks/tasks/external/behavior1k.yaml`. Outputs: `scorecard.json` (primary `success_rate`; also `subgoal_success`), `raw_results.jsonl`, and `evaluation/summary.json`.
