WBench（美团 LongCat）评的是 **多轮交互视频世界模型**，五个轴汇总为 `wbench_average`：

- **质量** — 美学、成像、闪烁、动态、平滑、HPSv3
- **设定** — 场景 / 主体遵守
- **交互** — 导航轨迹、事件编辑、主体动作、视角切换
- **一致性** — 背景、片段连续、视角、主体、几何 / 光度重建、空间（含 gated）
- **物理** — 视觉合理性、因果忠实

论文：[WBench](https://arxiv.org/abs/2605.25874)。项目：[meituan-longcat.github.io/WBench](https://meituan-longcat.github.io/WBench/)。代码：[meituan-longcat/WBench](https://github.com/meituan-longcat/WBench)。数据：[`meituan-longcat/WBench`](https://huggingface.co/datasets/meituan-longcat/WBench)。权重：[`meituan-longcat/WBench-weights`](https://huggingface.co/meituan-longcat/WBench-weights)。

WorldFoundry **检入指标 runtime**（HPSv3、TransNetV2、PAVRM、DreamSim、MegaSAM 位姿预计算）。**真实单视频 `temporal_flickering` 组件已验证**；**289 例多轮协议未验证**。`--official-results-path` 导入 `report.json` 或分指标目录。

## 如何运行

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/wbench/run_wbench_official_runner.py \
  --run-official \
  --model-name <model_name> \
  --phase gpu \
  --metrics temporal_flickering \
  --dataset-root <WBench_dataset> \
  --generated-artifact-dir <one_officially_named_generated_video> \
  --output-dir tmp/wbench/flicker \
  --json
```

只有视频真正遵循该官方多轮接口时才传 `--submission-protocol text_multi_turn|camera_conditioned|action_conditioned`。环境变量：`WORLDFOUNDRY_WBENCH_RESULTS_PATH`、`WORLDFOUNDRY_WBENCH_ROOT`。共享栈：`video_world_perception_stack`。

仓内指针：`worldfoundry/data/benchmarks/tasks/external/wbench.yaml`，`worldfoundry/evaluation/tasks/execution/runners/wbench`。

产物包括 `scorecard.json`（主键 `wbench_average`）。
