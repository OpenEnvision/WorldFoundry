EWMBench（AgiBot / AgibotTech）评的是 AgiBot-World 生态里**动作条件**的机器人操作视频。这是世界模型质量评测，不是桌面操作成功率套件。四个分面汇总为 `ewmbench_average`：

- **场景一致性** — 工作空间是否保持稳定？
- **运动正确性** — 机械臂 / 物体轨迹是否匹配任务？
- **语义对齐** — 片段是否匹配语言指令？
- **多样性** — 生成 rollout 的多样性。

论文：[EWMBench](https://arxiv.org/abs/2505.09694)。数据 / 项目：[`agibot-world/EWMBench`](https://huggingface.co/datasets/agibot-world/EWMBench)（CC-BY-NC-SA-4.0）。代码：[AgibotTech/EWMBench](https://github.com/AgibotTech/EWMBench)。

WorldFoundry **内置 runtime 资源**，并通过 `benchmark-run` 归一化官方结果文件。依赖就位时，`--run-official` 可调度上游 `evaluate.py`。检测器 / VLM 裁判资源仍在上游。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id ewmbench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir tmp/ewmbench/official-validation \
  --json
```

`--task-manifest` 与 `--config-path` 绑定任务集和打分配置；`--limit` 限制接线运行。默认导入路径：`WORLDFOUNDRY_EWMBENCH_RESULTS_PATH`。可选根：`WORLDFOUNDRY_EWMBENCH_ROOT`。共享资源：`ewmbench_dataset_assets`。

仓内指针：

```text
worldfoundry/data/benchmarks/tasks/external/ewmbench.yaml
worldfoundry/evaluation/tasks/execution/runners/ewmbench/runtime/ewmbench
```

产物包括 `scorecard.json`（主键 `ewmbench_average`）、`benchmark_contract.json`、`raw_metric_table.jsonl`。
