FETV（北大与华为诺亚）是**细粒度**开放域文生视频评测。**619 条 prompt** 落在三个正交轴上：**主要内容**、**属性控制**（颜色、数量、风格）、**prompt 复杂度**（简单 vs 组合）。打分混合人工评分（静态质量、时序质量、整体 / 细粒度对齐）与自动指标（CLIPScore、BLIPScore、FID、FVD）。只有声明的分量齐备时才写出 `fetv_average`。

论文：[FETV（NeurIPS 2023 D&B）](https://proceedings.neurips.cc/paper_files/paper/2023/hash/c481049f7410f38e788f67c171c64ad5-Abstract-Datasets_and_Benchmarks.html)。Prompt：[llyx97/FETV](https://github.com/llyx97/FETV)。打分器：[llyx97/FETV-EVAL](https://github.com/llyx97/FETV-EVAL)。数据集：[`lyx97/FETV`](https://huggingface.co/datasets/lyx97/FETV)（CC-BY-4.0）。

WorldFoundry **内置 FETV-EVAL**，把生成视频接到官方 prompt 索引（官方 16 帧布局），通过共享基座资源跑 **CLIPScore**，并归一化 FETV-EVAL 结果目录或 CSV。人工评分不能重算。BLIP / FID / FVD 需要对应包与参考帧。

## 如何运行

导入 FETV-EVAL 目录或官方 CSV：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id fetv \
  --mode official-validation \
  --official-results-path <official_results.csv-or-FETV-EVAL-dir> \
  --generated-artifact-dir <generated_videos> \
  --output-dir tmp/fetv/official-validation \
  --json
```

用 `--fetv-metrics` 选择自动指标族（`clip_score`、`blip_score`、`fid`、`fvd`）。FID / FVD 需要 `--fetv-fid-real-video-dir` / `--fetv-fvd-real-video-dir`。默认导入路径：`WORLDFOUNDRY_FETV_RESULTS_PATH`。可选：`WORLDFOUNDRY_FETV_RUNTIME_ROOT`、`WORLDFOUNDRY_FETV_ARTIFACT_SCORE_DIR`。共享栈：`video_quality_motion_stack`、`fetv_blip_retrieval_source`、`fetv_stylegan_v_fvd_source`。

仓内指针：

```text
worldfoundry/data/benchmarks/tasks/external/fetv.yaml
worldfoundry/evaluation/tasks/execution/runners/fetv/runtime/fetv_eval
worldfoundry/data/benchmarks/assets/fetv/fetv_data.json
```

产物包括 `scorecard.json`（齐备时主键 `fetv_average`）、`benchmark_contract.json`、`raw_metric_table.jsonl`。
