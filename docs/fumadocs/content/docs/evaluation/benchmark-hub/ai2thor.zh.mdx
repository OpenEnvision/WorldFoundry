AI2-THOR（艾伦人工智能研究所，Ai2）是面向具身 AI 的 **Unity** 家居模拟器。原始 **iTHOR** 集合是 **120** 个美术手建房间：厨房、客厅、卧室、浴室各 30 个（`FloorPlan1–30`、`201–230`、`301–330`、`401–430`）。智能体使用**离散**动作（`MoveAhead`、`RotateLeft`、`PickupObject`、开关、拨动）与物理和物体状态交互。官方常用划分是每种房型 **20 / 5 / 5** 训练 / 验证 / 测试。后续场景包（RoboTHOR、ProcTHOR）和语言套件（**ALFRED**、**TEACh**）建立在这个引擎上——不是 WorldFoundry 默认任务。

论文：[AI2-THOR: An Interactive 3D Environment for Visual AI](https://arxiv.org/abs/1712.05474)。项目：[ai2thor.allenai.org](https://ai2thor.allenai.org/)。代码：[allenai/ai2thor](https://github.com/allenai/ai2thor)（Apache-2.0）。

WorldFoundry **评测**原生闭环：`worldfoundry-eval embodied run` 启动 Unity 构建，逐步执行已经输出模拟器 token 的策略。仓内配置（`FloorPlan1`–`FloorPlan3`）只做**接线检查**，不是 ALFRED/TEACh。也可以通过 `WORLDFOUNDRY_AI2THOR_RESULTS_PATH` **导入**已有 rollout 导出。本页**不跑** VLA 推理——策略或策略服务由你提供。

## 如何运行

闭环接线（需要 Unity 包、模拟器缓存，以及 CloudRendering 或 X11 显示）：

```bash
worldfoundry-eval embodied run \
  --config worldfoundry/data/benchmarks/eval_configs/embodied/ai2thor/floorplan1.yaml
```

导入已有导出：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id ai2thor \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/ai2thor/official-validation \
  --json
```

可选 `WORLDFOUNDRY_AI2THOR_ROOT` 指向本地 runtime / 仓库。默认导入路径：`WORLDFOUNDRY_AI2THOR_RESULTS_PATH`。清单：`worldfoundry/data/benchmarks/tasks/external/ai2thor.yaml`。仓库镜像：`cache/vla_va_wam/repos/allenai--ai2thor`。产物：`scorecard.json`（主键 `success_rate`）、`run_manifest.json`、`results.jsonl`、`metrics/summary.json`。
