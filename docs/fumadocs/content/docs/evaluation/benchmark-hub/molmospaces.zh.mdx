MolmoSpaces-Bench 是艾伦人工智能研究所（Ai2）为 MolmoBot / MolmoSpaces 空间语言操作准备的**仿真评测**。论文中的训练数据（**MolmoBot-Data**）是 **170 万**条专家轨迹，生态数字为 **23.2 万**环境、**4.8 万**可操作物体——那**不是**本评测。评测本身是 **1000 episode** 阶梯：Pick MSProc / Classic / 照片级 Pick / Pick Random-Cam（20 秒），然后是 Pick&Place、PnP Next-To（5 cm）、PnP Color（40 秒）。官方表把**抓取阶段**成功率与**最终** / oracle 成功率分开。公开榜在 [molmospaces.allen.ai/leaderboard](https://molmospaces.allen.ai/leaderboard)；本 Hub **尚未**收录其行。

论文：[MolmoBot](https://arxiv.org/abs/2603.16861)。项目：[allenai.github.io/MolmoBot](https://allenai.github.io/MolmoBot/)。代码：[allenai/MolmoBot](https://github.com/allenai/MolmoBot)。WorldFoundry 的 contract 划分名是 `pick_and_place`。

WorldFoundry **导入**官方 rollout 导出。它**不跑** MolmoSpaces、不生成那 170 万条，也不把 Ai2 榜复制到本页。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id molmospaces \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/molmospaces/official-validation \
  --json
```

可选 `WORLDFOUNDRY_MOLMOSPACES_ROOT` 指向本地 runtime / 仓库。默认导入路径：`WORLDFOUNDRY_MOLMOSPACES_RESULTS_PATH`。清单：`worldfoundry/data/benchmarks/tasks/external/molmospaces.yaml`。产物：`scorecard.json`（主键 `success_rate`；另有 `pick_success_rate`）、`raw_results.jsonl`、`evaluation/summary.json`。
