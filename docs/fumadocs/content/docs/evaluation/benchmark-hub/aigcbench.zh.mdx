AIGCBench（BenchCouncil，中科院计算所）评的是**图生视频**：给定条件图像和 prompt，片段是否保真、是否有运动、时序是否连贯？指标族：

- **首帧保真** — 相对条件图像的 `mse_first` / `ssim_first`。
- **对齐** — 图像-视频与文本-视频 CLIP。
- **参考视频对齐** — 关键帧 / 对应帧 CLIP 与 SSIM（需要官方参考）。
- **运动** — 光流平方均值。
- **时序** — 相邻帧 CLIP。
- **感知质量** — DOVER。也会记录 `frame_count`。

论文：[AIGCBench](https://arxiv.org/abs/2401.01651)。项目：[benchcouncil.org/AIGCBench](https://www.benchcouncil.org/AIGCBench)。代码：[BenchCouncil/AIGCBench](https://github.com/BenchCouncil/AIGCBench)（Apache-2.0）。数据集：[`stevenfan/AIGCBench_v1.0`](https://huggingface.co/datasets/stevenfan/AIGCBench_v1.0)。

WorldFoundry **导入官方指标 CSV / TSV**（或流水线分数转储）。`worldfoundry/data/benchmarks/assets/aigcbench` 里的 `prompt_suite.json` 可在不下载完整 Hugging Face 数据的情况下物化请求。CLIP、DOVER 与光流打分器仍由调用方提供。官方导出提供时，主键为 `aigcbench_average`。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id aigcbench \
  --mode official-validation \
  --official-results-path <official_results.csv> \
  --generated-artifact-dir <generated_videos> \
  --output-dir tmp/aigcbench/official-validation \
  --json
```

`--strict` 会在覆盖缺口处失败；`--prompt-manifest` 可限制 prompt 子集。首帧 / 参考视频指标族需要官方资源就位。默认导入路径：`WORLDFOUNDRY_AIGCBENCH_RESULTS_PATH`。共享栈：`video_quality_motion_stack`。

仓内指针：

```text
worldfoundry/data/benchmarks/tasks/external/aigcbench.yaml
worldfoundry/data/benchmarks/assets/aigcbench
```

产物包括 `scorecard.json`（主键 `aigcbench_average`）、`benchmark_contract.json`、`raw_metric_table.jsonl`。
