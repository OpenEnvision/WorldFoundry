Kinetix (FLAIR, University of Oxford; ICLR 2025 oral) is an **open-ended space of JAX-accelerated 2D physics RL environments**. Procedurally representable levels cover robotic-style locomotion, grasping, and classic control inside one simulator, so a general agent can pretrain at scale and evaluate on held-out tasks.

Paper: [Kinetix](https://arxiv.org/abs/2410.23208). Code: [FLAIROx/Kinetix](https://github.com/FLAIROx/Kinetix). License: upstream terms.

WorldFoundry is an **official-results importer**. Simulator execution, policy loading, and rollout collection stay upstream. The scorecard primary is `success_rate`.

## How to run

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id kinetix \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/kinetix/official-validation \
  --json
```

Default import: `WORLDFOUNDRY_KINETIX_RESULTS_PATH`. Optional root: `WORLDFOUNDRY_KINETIX_ROOT`.

In-tree pointer: `worldfoundry/data/benchmarks/tasks/external/kinetix.yaml`.

Outputs include `scorecard.json` (primary `success_rate`), `raw_results.jsonl`, and `evaluation/summary.json`.
