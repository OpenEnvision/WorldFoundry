PhyGround（美国东北大学）是**准则锚定**，不是实拍续写，也不是 PhyGenEval。**250** 条文本+图像转视频 prompt 各带预期物理结果，以及 **13 条**定律分类（固体、流体、光学）中适用的 **2–4** 条。Judge（PhyJudge-9B 或人工）按 **1–5** 分评语义符合、物理时序有效性、持久性与各适用定律。这更像量表，而不是 [Physics-IQ](/zh/docs/evaluation/benchmark-hub/physics-iq) 的 mask IoU。

[PhyGenBench](/zh/docs/evaluation/benchmark-hub/phygenbench) 是 T2V *生成*常识套件（160 条 / 27 条定律 / PhyGenEval）。PhyGround 是 TI2V *定律准则*打分（250 条 / 13 条定律）。

论文：[PhyGround](https://arxiv.org/abs/2605.10806)。项目：[phyground.github.io](https://phyground.github.io/)。代码：[NU-World-Model-Embodied-AI/PhyGround](https://github.com/NU-World-Model-Embodied-AI/PhyGround)。数据：[NU-World-Model-Embodied-AI/phyground](https://huggingface.co/datasets/NU-World-Model-Embodied-AI/phyground)。

WorldFoundry **导入** PhyJudge/vLLM 或云端 judge 的 `scores.json`。它**不**对候选视频执行 PhyJudge-9B。

## 如何运行

就位数据根（`prompts/`、`first_images/`、`annotations/`、`videos/<model_id>/`）并导入 judge 输出：

```bash
hf download NU-World-Model-Embodied-AI/phyground --repo-type dataset --local-dir <phyground_data_root>

worldfoundry-eval zoo benchmark-run \
  --benchmark-id phyground \
  --mode official-validation \
  --benchmark-data-root <phyground_data_root> \
  --generated-artifact-dir <phyground_data_root>/videos/<model_id> \
  --result-model-id <model_id> \
  --output-dir tmp/phyground/official-validation \
  --json
```

也可把 `--official-results-path` 指到 `scores.json` / `annotations/`。`--prompt-manifest` 可校验 prompt 覆盖。产物包括 `scorecard.json`（主键 `phyground_overall`）。
