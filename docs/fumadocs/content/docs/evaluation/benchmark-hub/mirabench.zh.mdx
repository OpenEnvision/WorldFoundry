MiraBench（腾讯 ARC Lab）是 **MiraData** 的评测半边。MiraData 是带结构化字幕的长视频数据集。它从六个视角打分：时间一致性、时间运动强度、3D 一致性、视觉质量、文本-视频对齐、分布一致性。官方打分器暴露 **17 个指标**（DINO/CLIP 时间一致性、RAFT 风格运动、3D 重建误差、美学 / 成像质量、ViCLIP 对齐、FVD / FID / KID）。标准套件是 **150 条 prompt**。许可证：GPL-3.0。

论文：[MiraData](https://arxiv.org/abs/2407.06358)。项目：[mira-space.github.io](https://mira-space.github.io/)。数据：[`TencentARC/MiraData`](https://huggingface.co/datasets/TencentARC/MiraData)。代码：[mira-space/MiraData](https://github.com/mira-space/MiraData)。

WorldFoundry **仓内内置 runtime**（`calculate_score.py`），并把 `average_score.csv` 转成 scorecard。`WORLDFOUNDRY_MIRABENCH_SCORER_BACKEND=mock` 只是接线。

## 如何运行

```bash
export WORLDFOUNDRY_MIRABENCH_META_CSV=/path/to/mirabench/meta_generated.csv
export WORLDFOUNDRY_MIRABENCH_GT_META_CSV=/path/to/mirabench/meta_gt.csv
export WORLDFOUNDRY_GENERATED_ARTIFACT_DIR=/path/to/mirabench/generated_videos
export WORLDFOUNDRY_MIRABENCH_CKPT_PATH=/path/to/mirabench/data/ckpt

${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/mirabench/run_mirabench_official_runner.py \
  --run-official \
  --meta-csv "${WORLDFOUNDRY_MIRABENCH_META_CSV}" \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --output-dir tmp/mirabench/official-run \
  --strict \
  --json
```

导入 `average_score.csv`：

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id mirabench \
  --mode official-validation \
  --official-results-path /path/to/mirabench/average_score.csv \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --output-dir tmp/mirabench/official-validation \
  --json
```

视频命名 `1.mp4` … `150.mp4`（来自 `video_idx`）。示例 meta 捆绑在 `worldfoundry/data/benchmarks/assets/mirabench/data/evaluation_example/`。`--strict` 会在缺 prompt 视频时失败。完整打分需要 AMT、ViCLIP、MUSIQ、FVD/FID/KID 与 3D 一致性资产。

仓内指针：`worldfoundry/data/benchmarks/tasks/external/mirabench.yaml`，`worldfoundry/evaluation/tasks/execution/runners/mirabench/runtime/mirabench`。

产物包括 `scorecard.json`（主键 `mirabench_average`）与 `mirabench_average_score.json`。
