Native acceleration plugins are disabled by default. Validate the checkpoint, execution path, and quality budget before measuring actual execution and total latency. In the 2026-10-03 full SANA video diagnostic, conservative fusion preserved final latents and decoded video bit for bit, improving total time by about **0.8%–1.1%**. More aggressive cache and fusion configurations failed the fixed quality gates.

## Upstream comparison

The audit uses [FlashDreams `91c906b`](https://github.com/NVIDIA/flashdreams/tree/91c906b69992f63fb19907a25cd805fb783d314a) and [Sana Sol-Engine `670482d`](https://github.com/NVlabs/Sana/tree/670482d8a857d578ac8a2ea89b052d0fb47badba). Distinguish callable native integrations from optional packages and forwarded flags.

| Technique | Upstream approach | Existing WorldFoundry support and this change |
| --- | --- | --- |
| Attention kernels | FlashDreams Triton FA2/TMA, cuDNN and native FP8; Sol Flash/cuDNN and Sol-Attn | Existing SDPA, FA2/3/4, Sage/Sage3, xFormers, TMA and native cuDNN FP8. Adds a shared Sol dispatcher and independent Wan self/cross policies. |
| Block fusion | AdaLN, residual gates, QK norm/RoPE, projection and FFN glue | Existing common kernels and Wan QKV/RoPE/FFN transforms. Adds removable SANA adapters; defaults retain native normalization and token strides. |
| Invariant/history reuse | Text cross-KV, streaming KV and stable cache layouts | Existing Wan cross-KV and several autoregressive caches. Raw KV, rotated KV and recurrent linear-attention states retain separate contracts. |
| Feature cache | Sol EasyCache, TeaCache and model-specific controllers | Existing Tea/Ada/Mag/Taylor/block caches, mostly Wan. Adds native EasyCache for stateless SanaMS/SanaMSVideo and single-expert WanModel. |
| Quantization | FlashDreams separate projection/attention precision; Sol documents FP8 and SVDQuant/Nunchaku | Existing FP8, INT8, INT4, NVFP4 paths; some low-bit modes still dequantize into dense GEMMs. General native Wan/SANA SVDQuant/Nunchaku and a complete optimized-MHA precision schedule remain work to do. |
| Compile, graphs, parallelism | Regional compile, stable-shape capture and model-specific pipelines | Existing compile/cache, CUDA Graph, SP/CFG/VAE parallelism and offload. Plugins preserve existing cache/Graph/SP restrictions. |
| Composition search | Sol model/hardware/quality-budget search | Existing operator autotuning. Adds fixed-candidate real SANA generation search, scoped to the tested prompt, seeds, geometry and device. |

HyperFlow already forwards `--sol-attn` upstream, and WorldGen already has an optional Flux/Nunchaku path. Those do not establish shared native Wan/SANA support. FlashDreams OmniDreams LightVAE, complete optimized MHA, and steady-state graphs also require matching weights, calibration or model-specific lifecycle work.

Sources: [FlashDreams accelerated](https://github.com/NVIDIA/flashdreams/blob/91c906b69992f63fb19907a25cd805fb783d314a/docs/source/developer_guides/flashdreams_accelerated.md), Sol [kernel](https://github.com/NVlabs/Sana/blob/670482d8a857d578ac8a2ea89b052d0fb47badba/site_docs/techniques/kernel.md), [cache](https://github.com/NVlabs/Sana/blob/670482d8a857d578ac8a2ea89b052d0fb47badba/site_docs/techniques/cache.md), [quant](https://github.com/NVlabs/Sana/blob/670482d8a857d578ac8a2ea89b052d0fb47badba/site_docs/techniques/quant.md), and [Sol-Attn](https://github.com/NVlabs/Sana/blob/670482d8a857d578ac8a2ea89b052d0fb47badba/site_docs/techniques/sparse/sol_attn.md). The EasyCache controller independently implements the [upstream algorithm](https://github.com/H-EmbodVis/EasyCache/tree/bfc63232cfae8c77e2dccf9d72b8f2f56bd995b8).

## Ownership and lifecycle

| Layer | File under `worldfoundry/` | Responsibility |
| --- | --- | --- |
| Installer | `core/acceleration/plugins.py` | Registry, prepared plans, conflicts, atomic groups, rollback and removal |
| Request state | `core/acceleration/easycache.py` | Online drift estimates, condition snapshots, dense/reuse decisions and receipts |
| Model adapters | `base_models/diffusion_model/optimizations/plugins.py` | Checkpoint graph and composition validation; reversible model-local attributes |
| SANA seam | `base_models/diffusion_model/models/networks/sana/block_ops.py` | Norm/modulation/residual glue with training, DropPath and custom norm semantics |
| Sol provider | `core/attention/backends/sol.py` | Optional dependency boundary and dtype/shape/parameter validation |

Tests live in core and native model suites; reproducible diagnostics live in `benchmarks/inference/`. Installation prepares every plan before mutation and undoes earlier changes on failure. Built-ins preserve checkpoint parameters and state-dict keys. Change plugins only while the model is idle, before compilation/capture; rebuild a compiled model before removal. Removal checks every bound denoiser's live cache requests.

EasyCache owns state per explicit request ID and CFG branch. Native request finalization releases tensors on success and failure, retaining bounded JSON receipts. Snapshots detect in-place edits to inference-tensor conditions. Threshold `0.0` executes every original block and returns the dense output directly.

The loader applies shared configuration only to DiTs declaring `supports_acceleration_plugins`. The assembler rejects denoisers that accept requested plugins without installing them. Installation reports always say `execution_verified=False`; kernel execution and skipped blocks require separate receipts.

## Configuration

```python
import torch
from worldfoundry.base_models.diffusion_model.pipeline import NativeDiffusionPipeline
from worldfoundry.core.model_loading.policy import RuntimePolicy

policy = RuntimePolicy(
    device="cuda", dtype=torch.bfloat16,
    options={"accelerations": {"sana_block_fusion": True}},
)
pipeline = NativeDiffusionPipeline.from_pretrained("sana-video-2b-480p", policy=policy)
# Run an ordinary DiffusionRequest, then inspect that request's report.
report = pipeline.components.denoiser.runtime_optimization_report()
```

An already loaded idle model can also use a removable session, without changing environment variables:

```python
from worldfoundry.base_models.diffusion_model.optimizations.plugins import (
    diffusion_acceleration_registry,
    install_diffusion_accelerations,
)

model = pipeline.components.denoiser.model
existing = getattr(model, "_worldfoundry_accelerations", None)
if existing is not None:
    existing.uninstall()
session = install_diffusion_accelerations(model, {"easycache": {"threshold": 0.0}}, policy)
# Native runner finally blocks finalize requests; direct callers use end_request.
session.uninstall()

registry = diffusion_acceleration_registry()
# registry.register("custom_kernel", prepare_factory)
# Preparation validates without mutation; activation returns a reversible handle.
```

Choose load-time configuration or manual installation; uninstall the current session before replacing it. Component options override runtime options. Public native pipeline load arguments also accept `accelerations={...}`.

| Plugin | Defaults and supported contract |
| --- | --- |
| `sana_block_fusion` | `backend=auto`, `min_elements=12582912`; small inputs, autograd and unsupported layouts retain eager execution. `fuse_layer_norm=False`, `repack_tokens=False`. Those extra switches change numerical scheduling and failed this full-video quality diagnostic. |
| `easycache` | Requires an explicit nonnegative threshold. Learns dense input/output change ratios and estimates accumulated drift before reusing `current_input + last_dense_transform`. This is an **embedded-token-block-stack** variant, not every upstream raw-latent variant. |
| `attention_policy` | Native Wan self/cross selection. Sol accepts self only: BF16, head dimension 128, no mask/backward, `kv_splits=1`. Invalid parameters or unavailable dependencies fail without a silent dense fallback. |

EasyCache currently rejects streaming, camera/control subclasses, dual-expert schedules, offload, compile, CUDA Graph, SP, other feature caches, approximate processors and inplace residuals. Conditions must contain tensors, mappings, lists/tuples and scalars. Block callbacks must preserve their inputs. Scoped attention rejects unvalidated Graph/SP/approximate-processor compositions; the Wan Sol path also rejects compile.

Wan Sol configuration, after installing the provider in an isolated environment:

```python
policy = RuntimePolicy(
    device="cuda", dtype=torch.bfloat16,
    options={
        "dit_weight_dtype": "bf16",
        "accelerations": {"attention_policy": {
            "self": {"backend": "sol_attn", "tau": 1.0}, "cross": "torch",
        }},
    },
)
```

The tested environment uses sol-attn 0.5.0, PyTorch 2.10.0+cu128, Triton 3.6.0, CUTLASS DSL 4.8.0, cuda-python 13.4.1 and apache-tvm-ffi 0.1.14.post1. Install the pinned Sol branch's `techniques/sparse_backends` in a separate environment. The common probe requires at least PyTorch 2.10, CUDA 12.8, Triton 3.6 and sol-attn 0.5.

## H100 results and rejected candidates

| Measurement | Result | Validation and limits |
| --- | --- | --- |
| Official SANA-Video 2B block 0, 32760 tokens, contiguous BF16 inputs, three seeds | Block **1.040–1.043×**, glue **2.176–2.179×** | Bitwise equal. Synthetic activations do not certify video quality. |
| Same real block with native token strides, 7920/32760 tokens, three seeds | Block **1.021–1.022×**, glue **1.173–1.179×** | Bitwise equal. Only scale-shift executes fused; residual remains eager. |
| Full native video, 320×576, 41 frames, 20 steps, CFG 6, shift 7, two seeds | Conservative fusion **1.008–1.011×** | Final latents and RGB video bitwise equal. Includes prompt encoding, denoising and VAE; three interleaved wall-time pairs per seed. |
| Sol-Attn, BF16, 8 heads, head 128, correlated synthetic inputs | 4096 tokens **0.720×**; 8192 **2.950×**; 32768 **7.763×** | Relative L2 about 0.00017–0.00041. Short sequences are slower; native Wan generation quality remains unverified. |
| Sol-Attn, independent random Q/K/V | **Rejected; no speedup claim** | Relative L2 about 0.74–0.75 exceeds the fixed 0.01 gate. |
| Full SANA, EasyCache threshold 0.1 | **Rejected; no speedup claim** | Latent relative L2 0.083/0.129, PSNR 30.75/27.34 dB, SSIM 0.947/0.889. |

Video candidates share fixed gates: finite outputs, latent relative L2 ≤0.03, PSNR ≥33 dB and SSIM ≥0.98. Layout repacking and full norm fusion failed. Cache thresholds 0.025/0.05 skipped no blocks on these seeds; their combination timings do not establish an EasyCache gain. Selection requires quality and execution gates for every seed, then compares paired-bootstrap lower bounds. It selected conservative fusion.

Small shapes show no stable benefit. All raw samples, runtime fingerprints and actual execution are retained. Three video timing pairs do not establish a general speedup or VBench/WorldScore semantic quality certification.

Final targeted regression: **236 passed, 3 skipped**, covering existing SANA/Wan paths, CUDA rounding, real checkpoint loading, request/CFG isolation, condition invalidation, removal, training policy and dispatch. Two skips are image blocks without frame-aware conditioning; the third requires the Sol package absent from the main environment. The isolated Sol environment separately passed **9 tests**, including a real H100 CuTe invocation. This is not a full-repository result: legacy `tests/test_sana_integration.py` still imports a removed package path.

Next integrations require native quantized checkpoints/providers, complete MHA scheduling, and explicit dual-expert/cache/Graph/SP lifecycles, followed by model-specific generation and performance validation. The registry supplies a common installation and rollback contract; that remaining model work has not been implemented here.
