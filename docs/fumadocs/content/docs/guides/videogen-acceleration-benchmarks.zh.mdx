WorldFoundry 在同一套开源推理栈中统一覆盖 **15 个基础模型**（11 个旗舰视频生成模型 + 4 个实时自回归/交互世界模型）。所有汇报档位均要求**零回退运行时回执**（`fallbacks: []`、`capture_failed: 0`、`dense_fallback_calls: 0`）与 **4 帧 RGB 人工视觉抽检**双重把关。

## 评测方法论与硬件声明

- **软硬件基线**：裸机 **NVIDIA H200 SXM（141 GiB HBM3e，SM90，NVSwitch）**，PyTorch `2.11.0+cu128`、CUDA 12.8、Triton 3.6.0、Hopper FlashAttention-3 `3.0.1`、SM90 CUTLASS `sol_attn` 与内置 Hopper TMA `PISA`。
- **并发与独占严格区分**：
  - **零并发独占（Clean）**：独占 GPU、零外部进程（覆盖 **15 个模型中的 11 个**及单卡 `LTX-2.5`）。
  - **同会话配对（Paired）**：`Wan2.2-TI2V-5B`、`Wan2.2-T2V-A14B`、`HunyuanVideo-13B` 与 `2x H200 LTX-2.5 CFG=2` 期间宿主机存在外部后台训练任务（每卡 ~33.5 GiB）。我们在同一张卡上背靠背配对测得 `L0` 与加速档位，仅汇报**同会话相对加速比（`L0 / L_opt`）**，不将并发壁钟秒数冒充独占耗时（经 `SANA-Video` 并发 `2.862x` vs 独占 `2.836x`、`LingBot-Video` 并发 `3.059x` vs 独占 `3.069x` 交叉验证，配对倍率误差低于 `1%`）；功能正确性、CUDA Graph 捕获/回放、零 fallback 回执、PSNR/SSIM 与视觉画质不受并发影响。
- **跨架构精度差异披露**：NVIDIA SOL Engine 部分结果基于 Blackwell **B200 SM100 原生 NVFP4**；WorldFoundry 在 H200 上采用 **SM90 行级 FP8 W8A8（`use_fast_accum=False` 全 FP32 累加）**。SM100 NVFP4 权重打包与分发已完成实现与单测，待物理 B200 实测补齐。

## 与同类框架的客观对比

- **WorldFoundry 优势**：单一开源栈覆盖 **15 个模型**；自回归世界模型在无损 BF16 下达到 **30–67.5 FPS** 且图段/显存 `O(1)`；全链路零回退 JSON 回执、FP32 累加 FP8（`use_fast_accum=False`）、FP64 Triton RoPE 与强制人工视觉把关。
- **同类框架当前仍领先之处**：
  - **NVIDIA SOL Engine**：拥有物理 **Blackwell B200 NVFP4** 实测数据（WorldFoundry 已实现 SM100 NVFP4 打包与分发，但目前实卡评测基于 Hopper H200 FP8）。
  - **SGLang-Diffusion**：在多租户连续批处理（continuous batching）与 OpenAI 兼容在线服务平面方面更成熟。
  - **隐空间级联适配器**：MiniMax-H3 超级加速当前通过解码上采样 + LTX VAE 编码完成阶段衔接（5s 耗时 `1.72s`），训练专用隐空间适配器可进一步压缩衔接开销。

## 画质拦截与主动否决记录

- **已拦截 — LTX-2.3 蒸馏 Stage-2 Token Pruning**：3 步蒸馏阶段剪枝 20–25% Token（`1.60s / 2.91x`，`15.4 dB`）导致天空/树冠彩虹色斑，已在 `total_steps < 6` 时默认自动旁路。
- **已拦截 — HunyuanVideo-13B `tau=1.25`**：虽达 `5.84x`，但 PSNR 降至 `20.80 dB` 且尾帧狐狸动作偏移，已否决并采用 `tau=1.0 + dense_single=(0,-2,-1)`（`5.25x`，`22.51 dB`）。
- **已修复 — Hopper FP22 累加漂移与 FP32 RoPE 漂移**：深层 DiT FP8 默认开启 `use_fast_accum=False`（开销低于 `3%`）并采用 FP64 寄存器驻留 Triton RoPE（比 `complex128` 快 `13.63x`）。
