## Architecture

The inference-only rollout methods and three small configuration adapters are extracted from the pinned upstream and paired with WorldFoundry checkpoint/LoRA loaders, LTX VAE, Gemma encoding and the existing Alaya history encoder. An inference-only entry skips trainer setup, optimizers, critics and training data.

## Runtime contract

Select variant=ar (30 steps) or dmd (4 steps). Stage2b transformer/history weights, the LTX-2.3 base, Gemma and ViGeo1.1 are required; DMD additionally needs stage3 LoRA. This is separate from the original merged DA3 checkpoint route.

## Readiness and limitations

- Uses extracted inference-only rollout methods and inference configuration sections; no trainer or optimizer is instantiated.
- CPU configuration and adapter contracts checked; checkpoint loading, VRAM usage and GPU artifact parity remain pending.
- Single-GPU inference bridge; full-window native VAE encoding may use more peak memory than the upstream streaming encoder.
