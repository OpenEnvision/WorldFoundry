I2VGen-XL is Alibaba ali-vilab's cascaded image-to-video model, one of the earlier high-resolution open I2V releases. It turns a still image (with optional text) into a short video through a two-stage generate-then-refine cascade. The WorldFoundry route is complete and reports missing checkpoint assets at runtime.

## What it is for

Use `i2vgen-xl` for the family's joint T2V/I2V inference path. The catalog records both task profiles on this page.

Per the upstream publication, I2VGen-XL uses a base stage for semantic coherence and a refinement stage for detail/resolution, both latent diffusion models. This repository records the prompt+image contract and environment/checkpoint assumptions in the runtime profile; run readiness is kept in release run manifests, not here. It is published by Alibaba (Tongyi Lab).

Catalog tasks include image-to-video and text-to-video. Documented modalities: image and text in, video out.

Recorded evaluation entry points include [AIGCBench](/docs/evaluation/benchmark-hub/aigcbench) (I2V-focused benchmark suite).
