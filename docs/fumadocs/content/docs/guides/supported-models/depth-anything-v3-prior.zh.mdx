## 用来做什么

做前馈几何时选 `depth-anything-v3-prior`：视图进、重建/轨迹/点云出。需要 catalog 的 3D 路由、而不是仅深度先验时用它。

DA3 扩展了 Depth Anything 的训练配方并增加米制与几何头。本先验条目接入 metric-large checkpoint；运行时配置位于 runtime/configs/depth_anything_v3，与 VIPE 配置分离。该模型由字节跳动（Seed 团队）发布。

catalog 记录的任务包括 单目深度估计、米制深度估计、几何先验。别名包括 `dav3-prior`、`da3metric-large-prior`。模态上，它接受图像，输出深度。

给其他 pipeline 用的度量深度先验。不是完整 SOH 导出卡。

## 运行时契约

可选 `input_path`、`focal_length`、`execute`、`max_points`；产物 `depth-anything-v3-prior.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `DepthAnythingV3PriorPipeline`。

系列状态：**已验证**。

它作为独立几何先验集成在 worldfoundry/base_models 下，通过共享的 geometry-prior pipeline/operator 契约对外暴露。 上层管线（如 ViPE）从这一规范位置导入它，而不是各自保留私有副本。 官方 SOH 导出路径请使用兄弟条目 depth-anything-v3。

仅先验用途：完整的 DA3 重建能力在 depth-anything-v3 条目上。

记录的 checkpoint：`depth-anything/DA3METRIC-LARGE`（`model.safetensors`）。运行时配置在 `worldfoundry/data/models/runtime/configs/depth_anything_v3`，**与 ViPE 分开**。Runner 在共享 prior 契约上 **已验证**。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run depth-anything-v3-prior --pipeline.task-profile default`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `depth-anything/DA3METRIC-LARGE`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh depth-anything-v3-prior`；下载缺失的公开权重时加 `--download`。

状态：**已验证**。
