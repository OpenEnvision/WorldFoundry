## 用来做什么

用 `mineworld` 做 catalog 世界模型推理。需要动作条件未来帧、而不是独立片段生成器时选它。

按论文：视觉 tokenizer 加在「状态-动作」交错 token 上的自回归 Transformer，配并行解码实现实时速度。除此之外的内部细节此处未记录。该模型由微软（Microsoft）发布。

catalog 记录的任务包括 交互式世界模型、Minecraft 世界模型、动作条件视频。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件游戏世界滚动生成质量）。
