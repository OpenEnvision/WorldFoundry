## 架构

WorldFoundry 适配器只是自研的胶水层：解析就位的检出、检查就位条件并构造官方 inference.py 命令。WorldFoundry 交互 token 被渲染为 Minecraft/VPT 动作 JSONL，使共享的世界模型调用面驱动 Dreamer 4 的动作空间。

## 运行时契约

请就位官方检出（位于 WORLDFOUNDRY_MODEL_SOURCE_DIR/open-dreamer-inference 或 $WORLDFOUNDRY_OPEN_DREAMER_SOURCE），并带其自身的 CUDA-12 JAX 环境。上游未发布权重——需自行训练 Orbax checkpoint 或传入 checkpoint_path。上下文片段须为 RGB 368x640（或 360x640，自动零填充）。
