## 用来做什么

需要动作条件世界步进时选 `open-dreamer`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

WorldFoundry 适配器只是自研的胶水层：解析就位的检出、检查就位条件并构造官方 inference.py 命令。WorldFoundry 交互 token 被渲染为 Minecraft/VPT 动作 JSONL，使共享的世界模型调用面驱动 Dreamer 4 的动作空间。

catalog 记录的任务包括 交互式世界模型、Minecraft 世界模型、动作条件视频、diffusion-world-model。别名包括 `open_dreamer`、`opendreamer`、`dreamer-4`、`dreamer4`。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件世界滚动生成质量）。
