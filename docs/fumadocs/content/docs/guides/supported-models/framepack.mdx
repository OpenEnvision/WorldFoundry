FramePack is Stanford's **constant-memory** long image-to-video packer (ControlNet authors): input-frame context is packed into a **fixed-length** window so generation cost stays roughly constant as the clip grows, including minute-scale clips on modest VRAM. WorldFoundry vendors a minimal infer-only runtime under `worldfoundry/synthesis/visual_generation/framepack/framepack_runtime` and exposes `FramePackPipeline`. Integration is Verified. The **runner and official long-video demo are still pending**.

## What it is for

Pack long video as next-frame chunks from a start image.

Launch `worldfoundry-eval run framepack`.

Score on [ChronoMagic-Bench](/docs/evaluation/benchmark-hub/chronomagic-bench) — long-horizon generation suite matching FramePack's long-video focus.

## Runtime contract

Required: `prompt` and `image`; artifacts: `framepack.mp4`.

| Knob | Default |
| --- | --- |
| Duration | **5** s |
| FPS | **30** |
| Steps | **25** per FramePack section |
| Latent window | **9** |
| CFG / GS / RS | **1.0** / **10.0** / **0.0** |
| Seed | **31337** |
| TeaCache | **on** |
