Uni3C from Alibaba DAMO Academy unifies camera control and human-motion control for image-to-video generation: the PCDController stage steers the camera while the unified stage combines camera plus human motion (RealisDance-DiT). WorldFoundry vendors both official stage-two inference paths in-tree, with public Apache-2.0 checkpoints (ewrfcas/Uni3C, theFoxofSky/RealisDance-DiT) on top of the Wan2.1-I2V-14B-720P base.

## What it is for

Use `uni3c` for camera-conditioned video inference. The recipe binds the recorded camera-control profile.

Three checkpoint roles are recorded: ewrfcas/Uni3C as pcd_controller, Wan-AI/Wan2.1-I2V-14B-720P-Diffusers as camera_base, and theFoxofSky/RealisDance-DiT as the unified camera-plus-human model. Pre-rendered control bundles stay explicit runtime inputs; preprocessing is not silently substituted.

Catalog tasks include image-to-video, camera-controlled-video, and human-motion-controlled-video. Catalog aliases include `PCDController` and `alibaba-damo-academy/Uni3C`. Documented modalities: image in, video out.

Recorded evaluation entry points include [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera-trajectory adherence under explicit control).

## Runtime contract

Optional `prompt`, `input_path`, `render_path`, `mode`, and `num_frames`; artifacts `generated_video` and `uni3c.mp4`.

CLI task profiles: `image-camera-control-video`. WorldFoundry binds `Uni3CPipeline`.

Family status: **Verified**.

Recorded `image-camera-control-video` defaults: fps=16, seed=0.

Choose the camera-only or unified camera-plus-human route and provide the matching pre-rendered control bundle. The default PCDController camera route is checkpoint-backed and GPU-validated on H100; the unified camera-plus-human route still requires its own checkpoint-backed validation.

## Running in WorldFoundry

Launch `worldfoundry-eval run uni3c --pipeline.task-profile image-camera-control-video` to follow the camera path. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

Recorded weight repositories include `ewrfcas/Uni3C`, `Wan-AI/Wan2.1-I2V-14B-720P-Diffusers`, and `theFoxofSky/RealisDance-DiT`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh uni3c`. Add `--download` to fetch missing public checkpoints.
