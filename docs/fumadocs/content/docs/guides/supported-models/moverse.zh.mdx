## 用来做什么

`moverse` 是记录的相机控制路由。按 catalog 相机路径推进时从这里起步。

记录的组装复用 WorldFoundry 共享的 GeoCalib AutoLevel、Depth Anything 3、SHARP 全景、 Wan（视频基座 Wan2.1-T2V-1.3B）与 TAEHV 组件，另加作为全景基座的 FLUX.1-Fill-dev 与 MoVerse 自有组件权重。上游无许可文件——下游使用前请审查。

catalog 记录的任务包括 image-to-navigable-world、相机可控视频、panoramic-gaussian-scaffold。别名包括 `mo-verse`、`Orange-3DV-Team/MoVerse`。模态上，它接受图像，输出世界状态。

记录的评测入口包括[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（可游走生成世界的质量）、[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（游走过程的相机控制贴合度）。

## 运行时契约

可选 `prompt`、`input_path`、`interactions`、`frames`、`fps`；产物 `generated_world`、`gaussian_scaffold`、`generated_video`。

CLI task profile：`default`。绑定的 pipeline 类是 `MoVersePipeline`。

系列状态：**Runner 一致性待确认**。

`default` 记录默认值：frames=161, fps=16。

执行为离线模式，需要预先就位四个 Hugging Face snapshot，另加 ffmpeg、gsplat 与兼容的 CUDA 内核。 运行时规划与缺失资产诊断无需导入重量级模型栈。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run moverse --pipeline.task-profile default`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

记录的权重仓库包括 `Orange-3DV-Team/MoVerse`、`black-forest-labs/FLUX.1-Fill-dev`、`depth-anything/DA3NESTED-GIANT-LARGE-1.1` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh moverse`；下载缺失的公开权重时加 `--download`。
