## 用来做什么

`worldmem` 是记录的交互世界线。要用动作推进世界时从这里起步。

仓库记录的设计主题是基于记忆的长期一致性：存储并检索历史观测以条件化后续滚动生成。官方仓库与论文指针之外的架构内部细节仓库未记录。

catalog 记录的任务包括 交互式世界模型、Minecraft 世界模型、长期一致性。

记录的评测入口包括[MemoBench](/zh/docs/evaluation/benchmark-hub/memobench)（世界滚动生成的长期记忆一致性）、[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件交互滚动生成质量）。
