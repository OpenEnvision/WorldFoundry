## 用来做什么

任务是 catalog 静帧而不是视频时，用 `show-o`。

Transformer 是带逐层 QK-Norm 的 Phi-1.5，词表额外增加 8,192 个可学习图像 token。统一 prompt 用 [MMU]/[T2I] 标明任务，用 [SOT]/[EOT]、[SOI]/[EOI] 框住文本与图像。训练同时做 mask-token prediction 与 next-token prediction（L_MTP + α L_NTP）。生成从全 [MASK] 开始、按 T 步逐步揭开，步数大约是自回归解码图像的 1/20；树内运行时默认 256 像素、CFG 3.0、18 步。该模型由新加坡国立大学（Show Lab）发布。

catalog 记录的任务包括 multimodal-generation、文生图。别名包括 `show_o`、`showo`。模态上，它接受文本、图像，输出图像、文本。
