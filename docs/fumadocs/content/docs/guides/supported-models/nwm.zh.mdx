Navigation World Models（NWM）是 Meta 的导航世界模型（CVPR 2025 highlight）：条件扩散 Transformer，从历史帧与导航动作预测第一视角未来视频，并能通过「想象」来规划轨迹。记录的 variant 覆盖 RECON 与 SCAND 数据集 checkpoint。本 catalog 中源码已内置树内；执行保持 checkpoint/数据集限制。

## 用来做什么

用 `nwm-recon` 做 catalog 世界模型推理。需要动作条件未来帧、而不是独立片段生成器时选它。

按上游发布，条件扩散 Transformer（CDiT）参数量达 1B，以动作与时间嵌入为条件做第一视角预测（checkpoint 位于 facebook/nwm，CC-BY-NC-4.0）。该模型由Meta AI（FAIR）发布。

catalog 记录的任务包括 navigation-world-model、动作条件视频、egocentric-video-generation。别名包括 `navigation-world-models`、`nwm-recon`、`nwm-scand`。输出模态为视频。同系列还有 `nwm-scand`。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（导航世界滚动生成质量）。
