## 用来做什么

用 `zing` 做 catalog 世界模型推理。需要动作条件未来帧、而不是独立片段生成器时选它。

复用原生 Wan2.2 TI2V-5B 层、UMT5、VAE38 和注意力实现，新增键盘卷积和支持提示词切换的因果缓存。该模型由seedleap发布。

catalog 记录的任务包括 文生视频、图生视频、交互式世界模型。别名包括 `zing-0.5`、`zing-world-model`。模态上，它接受文本、图像，输出视频。

## 运行时契约

可选 `prompt`、`input_path`、`load.checkpoint_dir`、`num_frames`、`height`；产物 `generated_world`、`zing.mp4`。

CLI task profile：`interactive-world-model`。绑定的 pipeline 类是 `ZingPipeline`。

系列状态：**Runner 一致性待确认**。

`interactive-world-model` 记录默认值：height=480, width=832, fps=24, seed=0。

通过 ZingPipeline.from_pretrained 加载。 num_frames 包含可选参考帧，必须为 1+4*N；宽高为 32 的倍数。 总长 N 帧时键盘控制为 N-1 行、每行八个值。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run zing --pipeline.task-profile interactive-world-model` 推进世界。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

记录的权重仓库包括 `seedleap/zing-0.5`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh zing`；下载缺失的公开权重时加 `--download`。
