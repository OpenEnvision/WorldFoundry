## 架构

HunyuanVideo Transformer 结合 GameCraft 相机网络与历史条件自回归采样；基础层、VAE、编码器基础实现和调度器均复用共享代码。

## 运行时契约

就位本地 GameCraft 权重。每个动作生成 33 帧；显式 num_frames 必须等于动作数量乘以 33。支持 CPU offload 与 output_path 导出。

## 评测 Benchmark

- [WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench) — 动作跟随的世界滚动生成质量。

## 就绪状态与限制

- 已验证单张 H100、CPU offload、单动作及标准权重；多卡推理未验证，FP8 转换不受支持。
