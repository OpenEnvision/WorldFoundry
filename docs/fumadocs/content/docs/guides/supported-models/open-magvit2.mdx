In this catalog the runnable route is class-conditional ImageNet image generation — full 256-token generation passed checkpoint-backed GPU and semantic visual QA (verified at 256x256, ImageNet class 207). The artifact is a generated PNG image, not video.

## What it is for

`open-magvit2` is the recorded image-generation line. Start here for prompt-to-image inference.

Two parts recorded in-tree: the lookup-free quantization (LFQ) tokenizer with a very large codebook, and an autoregressive transformer that predicts visual tokens for a requested ImageNet class. The class_id input selects the category; generation runs the vendored CUDA wrapper. It is published by Tencent (ARC Lab).

Catalog tasks include video-tokenization, class-conditional-image-generation, and autoregressive-generation. Catalog aliases include `open_magvit2` and `openmagvit2`.
