## What it is for

Use `worldcrafter-base` for camera-conditioned video inference. The recipe binds the recorded camera-control profile.

Catalog tasks include text-to-video, image-to-video, camera-controlled-video, and world-model. Documented modalities: text and image in, video out.

## Runtime contract

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run worldcrafter-base --pipeline.task-profile text-to-video`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `TencentARC/WorldCrafter-Base` and `TencentARC/WorldCrafter-Fast`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh worldcrafter-base`. Add `--download` to fetch missing public checkpoints.
