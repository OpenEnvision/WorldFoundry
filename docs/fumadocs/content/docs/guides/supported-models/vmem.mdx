VMem is an interactive video scene generation model with a surfel-indexed view memory: as you navigate a scene, it remembers which surfaces were seen from where, keeping new views consistent with the past. ## Architecture

VMem indexes past views by surface elements (surfels) and retrieves only the relevant ones to condition generation of the next view (per the publication, arXiv 2506.18903). The route depends on CUT3R as its geometry backbone; both checkpoints must be staged.

## Runtime contract

One of the few fully verified interactive routes in the video category — the in-tree Studio/API route produced and visually validated the official-style navigation demo on 2026-06-27. Inputs cover prompt/image/video/actions; outputs are generated_video artifacts.

## Evaluation benchmarks

- [WorldScore](/docs/evaluation/benchmark-hub/worldscore) — Scores camera-navigable generated scenes.

## Readiness and limitations

- Requires both VMem and CUT3R checkpoints staged locally.
- Scene navigation quality depends on the geometry backbone; extreme viewpoint changes can still break consistency.
