## What it is for

`neoverse` is the recorded interactive world line. Start here when the job is stepping a world with actions.

Per the upstream release (arXiv 2601.00393), NeoVerse layers 4D reconstruction and control roles over a Wan video backbone. WorldFoundry expresses this as a native assembly over shared Wan infrastructure — real inference stays checkpoint/GPU gated with no metadata-only runner shim. It is published by CreateAI (formerly TuSimple).

Catalog tasks include 4D world modeling from in-the-wild monocular videos. Catalog aliases include `NeoVerse: Enhancing 4D World Model`.

Recorded evaluation entry points include [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Scores navigable generated worlds), [4DWorldBench](/docs/evaluation/benchmark-hub/4dworldbench) (Matches the entry's 4D world-model focus).
