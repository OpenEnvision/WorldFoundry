## What it is for

Pick `lingbot-vla-v2-6b` when you want the catalog VLA policy: instruction and observation in, an action trace out. Use it to roll the recorded policy, not to train a new one.

A Qwen3-VL/MoE policy with a 55-dimensional internal representation, denoising action decoding, image_grid_thw handling, and optional torch.compile paths. Training-only perception teachers are excluded; inference consumes their distilled representations from the trained weights. It is published by Robbyant (Ant Group).

Catalog tasks include vla, vla action prediction, vla policy rollout, and robot policy. Catalog aliases include `lingbot-vla2`, `lingbot-vla-v2-6b`, and `lingbotvla2`.

## Runtime contract

Optional `prompt`, `input_path`, `interactions`, `fps`, and `timeout_seconds`; artifacts `action_trace` and `lingbot_vla_v2_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `LingBotVLAV2Pipeline`.

Family status: **Static load only**.

The public 6B checkpoint uses the bundled official-derived inference config; robot-specific downstream checkpoints may override it with their own lingbotvla_cli.yaml.

Qwen3-VL/MoE policy inference, official batching, feature transforms, robot mappings, and normalization assets are integrated directly in-tree.

## Running in WorldFoundry

Launch `worldfoundry-eval run lingbot-vla-v2-6b --pipeline.task-profile default` to execute the policy. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the dedicated environment `worldfoundry-lingbot-vla-v2-cu128` (Python 3.11, CUDA 12.8, torch==2.8.0).

Recorded weight repositories include `robbyant/lingbot-vla-v2-6b` and `Qwen/Qwen3-VL-4B-Instruct`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lingbot-vla-v2-6b`. Add `--download` to fetch missing public checkpoints.

Recorded licenses include apache-2.0; status: **Static load only**.
