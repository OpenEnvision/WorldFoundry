## 用来做什么

需要相机可控视频时选 `worldcrafter-fast`：相机轨迹进、受控视频出。视角必须跟随路径时，用它而不是无约束 T2V。

catalog 记录的任务包括 文生视频、图生视频、相机可控视频、世界模型。模态上，它接受文本、图像，输出视频。

## 运行时契约

可选 `prompt`、`image`、`actions`、`seed`、`frames`；产物 `worldcrafter.mp4`。

CLI task profile：`text-to-video`、`image-to-video`、`camera-controlled-video`、`world-model`。绑定的 pipeline 类是 `WorldCrafterPipeline`。
