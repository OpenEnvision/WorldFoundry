MultiWorld（「It Takes Two」）是多智能体交互视频生成器：两名玩家的动作驱动同一个共享生成游戏世界。树内 ItTakesTwo 封装已完成使用真实权重的 81 帧 GPU 推理；游戏场景中的动作遵循性仍未验证。

## 用来做什么

需要动作条件世界步进时选 `multiworld`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

除已记录任务外的架构内部细节仓库未存。上游许可为自定义条款，已标记需人工审查。

catalog 记录的任务包括 video_generation、multi-agent-world-model、交互式视频生成、game-video。别名包括 `multiword`、`multiworld-ittakestwo`。输出模态为视频。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（多智能体世界滚动生成质量）。

## 运行时契约

可选 `input_path`、`interactions`、`frames`、`fps`、`height`；产物 `multiworld.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `MultiWorldItTakesTwoPipeline`。

系列状态：**已验证**。

`default` 记录默认值：frames=81, fps=60。

提供首帧图像和双玩家离散、连续动作张量（或动作 CSV）。 本地 toydata 权重已生成 480x480、35 步的 81 帧视频。 再分发前请审查上游自定义许可。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run multiworld --pipeline.task-profile default`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `Haoyuwu/MultiWorldCheckpoint`、`Wan-AI/Wan2.2-TI2V-5B`、`facebook/VGGT-1B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh multiworld`；下载缺失的公开权重时加 `--download`。

状态：**已验证**。
