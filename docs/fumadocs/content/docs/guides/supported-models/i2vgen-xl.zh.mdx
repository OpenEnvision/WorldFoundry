## 用来做什么

用 `i2vgen-xl` 跑本系列联合 T2V/I2V 推理路径。本页记录了这两种任务 profile。

按上游论文，I2VGen-XL 由保证语义连贯的基础级与提升细节/分辨率的细化级组成，均为潜空间扩散模型。本仓库在 runtime profile 中记录 prompt+image 契约与环境/checkpoint 假设；运行就绪状态保存在发布 run manifest 中，不在此处。该模型由阿里巴巴（通义实验室）发布。

catalog 记录的任务包括 图生视频、文生视频。模态上，它接受图像、文本，输出视频。

记录的评测入口包括[AIGCBench](/zh/docs/evaluation/benchmark-hub/aigcbench)（面向图生视频的评测集）。
