## What it is for

Pick `multiworld` when you need an action-conditioned world stepper: recorded actions and a frame in, a rollout out. Use it for interactive world inference, not a text-to-video prompt dump.

Architecture internals beyond the recorded tasks are not stored in this repository. The upstream license is custom and flagged for manual review.

Catalog tasks include video generation, multi-agent-world-model, interactive-video-generation, and game-video. Catalog aliases include `multiword` and `multiworld-ittakestwo`. Documented outputs include video.

Recorded evaluation entry points include [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Multi-agent world-rollout quality).

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run multiworld --pipeline.task-profile default`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `Haoyuwu/MultiWorldCheckpoint`, `Wan-AI/Wan2.2-TI2V-5B`, and `facebook/VGGT-1B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh multiworld`. Add `--download` to fetch missing public checkpoints.
