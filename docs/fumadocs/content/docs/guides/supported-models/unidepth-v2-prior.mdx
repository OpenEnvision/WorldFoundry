UniDepth V2 is a universal monocular metric-depth model: from a single image of any camera it predicts a metric 3D point cloud directly, without external intrinsics. In this catalog it is a checkpoint-verified geometry prior — real checkpoint inference and official point export are verified through the shared geometry-prior contract and Workspace route.

## Architecture

Per the upstream publication, a camera self-prompting module predicts a dense camera representation that conditions depth decoding, enabling cross-camera generalization. The default checkpoint resolves from lpiccinelli/unidepth-v2-vitl14 (or a local model_path override); registered at base_models/three_dimensions/depth/unidepth.

## Runtime contract

It is integrated as an independent geometry prior under worldfoundry/base_models and exposed through the shared geometry-prior pipeline/operator contract.
