UniDepth V2 is a universal monocular metric-depth model: from a single image of any camera it predicts a metric 3D point cloud directly, without external intrinsics. In this catalog it is a checkpoint-verified geometry prior — real checkpoint inference and official point export are verified through the shared geometry-prior contract and Workspace route.

## What it is for

Use `unidepth-v2-prior` for catalog geometry inference. Choose it when the artifact is a reconstruction, not a generated video.

Per the upstream publication, a camera self-prompting module predicts a dense camera representation that conditions depth decoding, enabling cross-camera generalization. The default checkpoint resolves from lpiccinelli/unidepth-v2-vitl14 (or a local model_path override); registered at base_models/three_dimensions/depth/unidepth. It is published by ETH Zurich.

Catalog tasks include monocular-depth-estimation, metric-depth-estimation, and geometry-prior. Catalog aliases include `unidepth-v2`, `unidepth-v2-vitl14`, and `unidepth_v2_vitl14`. Documented modalities: image in, depth out.
