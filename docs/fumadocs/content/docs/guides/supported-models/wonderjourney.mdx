## What it is for

`wonderjourney` is the recorded interactive world line. Start here when the job is stepping a world with actions.

Per the paper (arXiv 2312.03884), an LLM proposes upcoming scene descriptions, a point-cloud-and-inpainting visual module renders each new scene from the previous one, and a VLM verifies results. Missing assets or runtime dependencies are reported at inference time. It is published by Stanford University / Google.

Catalog tasks include 3d-world-generation, scene-expansion, and image-to-3d-world. Documented modalities: image in, 3D scene and world state out.

Recorded evaluation entry points include [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Standard scoring for generated navigable scene sequences).
