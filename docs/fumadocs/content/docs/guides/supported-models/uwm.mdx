## What it is for

Pick `uwm` when you need an action-conditioned world stepper: recorded actions and a frame in, a rollout out. Use it for interactive world inference, not a text-to-video prompt dump.

UWM is a video-action diffusion design: one diffusion process jointly models future observations and robot actions, so the same network serves prediction and policy roles. Details beyond the official repository pointer are not recorded in this repository. It is published by University of Washington (WEIRD Lab).

Catalog tasks include robot-world-model, action-conditioned-video, and video-action-diffusion. Catalog aliases include `uwm-libero90` and `uwm-droid`.

Recorded evaluation entry points include [LIBERO](/docs/evaluation/benchmark-hub/libero) (The uwm-libero90 variant targets LIBERO tasks), [EWMBench](/docs/evaluation/benchmark-hub/ewmbench) (Robot world-model rollout quality).

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run uwm --pipeline.task-profile default`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).
