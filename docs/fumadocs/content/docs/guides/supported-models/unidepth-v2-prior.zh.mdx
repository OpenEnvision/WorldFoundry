UniDepth V2 是通用单目米制深度模型：对任意相机的单张图像直接预测米制 3D 点云，无需外部内参。本 catalog 中它是 checkpoint 已验证的几何先验——真实 checkpoint 推理与官方点云导出已通过共享 geometry-prior 契约与 Workspace 路径验证。

## 用来做什么

用 `unidepth-v2-prior` 做 catalog 几何推理。产物是重建而不是生成视频时选它。

按上游论文，相机自提示模块预测稠密相机表示并条件化深度解码，实现跨相机泛化。默认 checkpoint 从 lpiccinelli/unidepth-v2-vitl14 解析（或用本地 model_path 覆盖）；注册于 base_models/three_dimensions/depth/unidepth。该模型由苏黎世联邦理工学院（ETH Zurich）发布。

catalog 记录的任务包括 单目深度估计、米制深度估计、几何先验。别名包括 `unidepth-v2`、`unidepth-v2-vitl14`、`unidepth_v2_vitl14`。模态上，它接受图像，输出深度。
