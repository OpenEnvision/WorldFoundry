## 用来做什么

`wonderjourney` 是记录的交互世界线。要用动作推进世界时从这里起步。

按论文（arXiv 2312.03884），LLM 提议后续场景描述，点云加图像修复的视觉模块从上一场景渲染新场景，VLM 负责校验结果。资产或运行时依赖缺失会在推理时报告。该模型由斯坦福大学 / Google发布。

catalog 记录的任务包括 3D 世界生成、scene-expansion、image-to-3d-world。模态上，它接受图像，输出3D scene、世界状态。

记录的评测入口包括[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（生成可游走场景序列的标准评分）。
