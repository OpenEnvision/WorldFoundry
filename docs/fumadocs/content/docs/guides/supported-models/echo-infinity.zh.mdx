Echo-Infinity 是京东的**自回归长视频**生成器：输入文本，**按块**生成任意长度的视频。WorldFoundry 把仅推理路径封成 `EchoInfinityPipeline`。训练、提示词数据集、demo 和下载助手**不**包含在内。它与 [Echo-Memory](/zh/docs/guides/supported-models/echo-memory-context-k1) 来自同一团队。别名 `EchoInfinity`、`echo_infinity` 解析到这里。

<ModelPaperFigures modelId="echo-infinity" locale="zh" />

论文：[arXiv 2606.04527](https://arxiv.org/abs/2606.04527)。项目页：[echo-team-joy-future-academy-jd.github.io/Echo-Infinity](https://echo-team-joy-future-academy-jd.github.io/Echo-Infinity/)。代码：[Echo-Team-Joy-Future-Academy-JD/Echo-Infinity](https://github.com/Echo-Team-Joy-Future-Academy-JD/Echo-Infinity)。许可证：**unknown**。基座是 Wan2.1——研究预览级画质。

运行前在 `$WORLDFOUNDRY_CKPT_DIR` 下就位本地 Echo-Infinity **和** Wan2.1 权重。

<ModelCommandBuilder modelId="echo-infinity" locale="zh" />

## 用来做什么

基于 Wan2.1 权重运行 Echo-Infinity，生成长视频。

启动 `wf run echo-infinity`。

评测入口：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（长文生视频的质量评测）。

## 运行时契约

必填 `prompt`；可选 `image`、`video`；产物 `echo-infinity.mp4`。

| 旋钮 | 默认 |
| --- | --- |
| 主干 | `Wan-AI/Wan2.1-T2V-1.3B` |
| 学生 | `$WORLDFOUNDRY_CKPT_DIR/Echo-Infinity/echo_infinity.pt` |
| 潜帧 | **21**（`num_output_frames`） |
| 步数 | **4** — `[1000, 750, 500, 250]`，`warp_denoising_step` |
| 块 | **3** 帧（`num_frame_per_block`） |
| Seed | **0** |
| 局部注意力 | **12** |
| EMA | **关** |

## 在 WorldFoundry 中运行

状态：**Runner 一致性待确认**。统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。在该环境执行 `wf run echo-infinity`。
