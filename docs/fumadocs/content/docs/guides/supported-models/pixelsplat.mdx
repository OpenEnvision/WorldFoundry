**Publisher:** Massachusetts Institute of Technology (MIT) · University

pixelSplat reconstructs a 3D Gaussian scene from two calibrated views in a single forward pass (CVPR 2024). The in-tree runtime supports the original convolutional RE10K and ACID checkpoints and has been verified with real posed inputs on GPU.

## Architecture

Per the publication, an epipolar transformer resolves scale ambiguity between the two views, and the network predicts a probabilistic distribution over Gaussian parameters. WorldFoundry vendors the source under base_models/three_dimensions/point_clouds/pixelsplat with a lazy wrapper around the official test entrypoint (MIT license; checkpoint mirror dylanebert/pixelSplat).

## Runtime contract

Provide model_path pointing to re10k.ckpt or acid.ckpt, the matching experiment, and posed dataset_roots/index_path. Install the declared runtime dependencies and local Gaussian rasterizer. Bare image lists use a synthetic baseline. PLY output exports normalized geometry and DC color with standard opacity logits.

## Readiness and limitations

- Supports the original convolutional checkpoints; newer camera-ready architectures are not interchangeable.
- Validation covers two scenes per dataset, not the complete benchmark. Unposed input does not establish geometric accuracy.
- PLY export retains only DC color; view-dependent appearance is available in the native renderer.
