ZeroScope 是社区作者 **cerspense** 对 [ModelScopeT2V](/zh/docs/guides/supported-models/modelscope-t2v) 的**文生视频**微调，面向无水印 **16:9** 短片。prompt 进，`zeroscope.mp4` 出。树内运行时**只接受 prompt**：传入图像或视频会报错。没有相机路径、没有导航动作、也没有 3D 资产。

<ModelPaperFigures modelId="zeroscope" locale="zh" />

WorldFoundry 通过 `worldfoundry/synthesis/visual_generation/zeroscope/worldfoundry_runtime.py` 跑 Hugging Face Diffusers U-Net。在所选配置下，输出与**官方 Diffusers 路径一致**。别名 `zero-scope`、`zero_scope` 解析到这里。

记录了两张卡片：`cerspense/zeroscope_v2_576w`（基础 **576×320**）与 `cerspense/zeroscope_v2_XL`（放大）。Studio/API 接好的 profile 就位的是 **576w** checkpoint。两套许可都是 **CC-BY-NC-4.0**。

<ModelCommandBuilder modelId="zeroscope" locale="zh" />

## 用来做什么

冒烟测试旧代文生视频管线，或和 ModelScopeT2V 父模型对比——不是产出当代 DiT 成片。启动 `worldfoundry-eval run zeroscope`，必填 `prompt`。运行时默认：**8 帧**、**576×320**、**25 步**、guidance **9.0**、**8 fps**。产物：`zeroscope.mp4`。

这一代 U-Net 的细粒度评测入口是 [FETV](/zh/docs/evaluation/benchmark-hub/fetv)。第一人称世界探索用 [YUME](/zh/docs/guides/supported-models/yume)。3D splat 用 [WorldGen](/zh/docs/guides/supported-models/worldgen)。

## 在 WorldFoundry 中运行

`ZeroScopePipeline` 跑在 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。把 `cerspense/zeroscope_v2_576w` 就位到 `WORLDFOUNDRY_HFD_ROOT`。商用或自动化评测前先看 CC-BY-NC-4.0——manifest 里两次记录了政策审阅。

## 最小评测

576w 路径 runner 已验证。对生成片段跑 [FETV](/zh/docs/evaluation/benchmark-hub/fetv)，加 `--fetv-metrics clip_score`，读 `clip_score`——这是有界官方组件。`fetv_average` 要声明的组件齐全才出现。
