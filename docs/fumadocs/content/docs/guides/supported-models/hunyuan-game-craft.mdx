## Architecture

HunyuanVideo transformer with a GameCraft camera network and history-conditioned autoregressive sampling; generic layers, VAE, encoder foundations and scheduler are shared.

## Runtime contract

Provide local GameCraft checkpoints. Each action generates 33 frames; explicit num_frames must equal 33 times the action count. CPU offload and output_path export are supported.

## Evaluation benchmarks

- [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) — Action-following world-rollout quality.

## Readiness and limitations

- Validated on one H100 with CPU offload, one action and the standard checkpoint; distributed inference is unvalidated and FP8 conversion is unsupported.
- Dedicated environment (Python 3.10 / torch 2.5.1) isolated from the unified profile.
