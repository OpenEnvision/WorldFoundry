## What it is for

`hunyuan-game-craft` is the recorded camera-control route. Start here to follow a catalog camera path.

HunyuanVideo transformer with a GameCraft camera network and history-conditioned autoregressive sampling; generic layers, VAE, encoder foundations and scheduler are shared. It is published by Tencent (Hunyuan).

Catalog tasks include interactive-world-model, image-to-video, and camera-control. Catalog aliases include `hunyuan-gamecraft` and `gamecraft`. Documented modalities: image in, video out.

Recorded evaluation entry points include [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Action-following world-rollout quality).

## Runtime contract

Optional `image`, `prompt`, `interactions`, `frames`, and `fps`; artifacts `hunyuan-game-craft.mp4`.

CLI task profiles: `official-interactive-video`. WorldFoundry binds `HunyuanGameCraftPipeline`.

Family status: **Runner parity pending**.

Recorded `official-interactive-video` defaults: frames=129, fps=24, height=704, width=1216.

Provide local GameCraft checkpoints. Each action generates 33 frames; explicit num_frames must equal 33 times the action count. CPU offload and output_path export are supported.

## Running in WorldFoundry

Launch `worldfoundry-eval run hunyuan-game-craft --pipeline.task-profile official-interactive-video` to follow the camera path. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the dedicated environment `HYGameCraft` (Python 3.10, CUDA 12.4, torch==2.5.1).

Recorded weight repositories include `tencent/Hunyuan-GameCraft-1.0`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh hunyuan-game-craft`. Add `--download` to fetch missing public checkpoints.
