Segment and Track Anything (SAM-Track) combines SAM segmentation with AOT/DeAOT tracking so objects can be segmented once and tracked across a whole video, with GroundingDINO enabling text-prompted selection. In this catalog it is an independent tracking prior consumed through the shared geometry-prior contract.
