Segment and Track Anything (SAM-Track) combines SAM segmentation with AOT/DeAOT tracking so objects can be segmented once and tracked across a whole video, with GroundingDINO enabling text-prompted selection. In this catalog it is an independent tracking prior consumed through the shared geometry-prior contract.

## What it is for

Use `track-anything-prior` for catalog geometry inference. Choose it when the artifact is a reconstruction, not a generated video.

The recorded structure combines three subcomponents — SAM for masks, GroundingDINO for text grounding, and AOT/DeAOT for propagation — reusing canonical WorldFoundry owners where available. Registered at base_models/perception_core/tracking/track_anything; upstream license is AGPL-3.0. It is published by Zhejiang University (ReLER Lab).

Catalog tasks include video-object-segmentation, object-tracking, and geometry-prior. Catalog aliases include `segment-and-track-anything`, `track-anything`, and `aot-deaot-l`.
