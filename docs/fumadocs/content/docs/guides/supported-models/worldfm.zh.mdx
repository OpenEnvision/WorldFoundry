## 用来做什么

`worldfm` 是记录的交互世界线。要用动作推进世界时从这里起步。

输出同时覆盖视频与全景图产物，体现其超越单一固定视口的世界生成设计。官方仓库与 checkpoint 指针之外的架构内部细节仓库未记录。

catalog 记录的任务包括 世界模型、video。输出模态为视频。

记录的评测入口包括[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（3D 世界输出的统一世界生成质量）。

记录的权重仓库包括 `inspatio/WorldFM`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh worldfm`；下载缺失的公开权重时加 `--download`。
