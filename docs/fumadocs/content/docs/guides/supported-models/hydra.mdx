HyDRA is a camera-controlled video-to-video world model: it re-renders an input video along new camera behavior described by a camera JSON. The pinned runtime generated a coherent 77-frame continuation of an official example at 50 steps; a separate synthetic camera case showed an occlusion.

Recorded weight repositories include `H-EmbodVis/HyDRA` and `Wan-AI/Wan2.1-T2V-1.3B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh hydra`. Add `--download` to fetch missing public checkpoints.
