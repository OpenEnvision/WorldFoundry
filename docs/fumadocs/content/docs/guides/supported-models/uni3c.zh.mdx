## 用来做什么

用 `uni3c` 做相机条件视频推理。配方绑定了已记录的相机控制 profile。

仓库记录三个 checkpoint 角色：ewrfcas/Uni3C 为 pcd_controller、 Wan-AI/Wan2.1-I2V-14B-720P-Diffusers 为 camera_base、theFoxofSky/RealisDance-DiT 为相机+人体统一模型。预渲染控制包保持为显式运行时输入；预处理不会被隐式替换。

catalog 记录的任务包括 图生视频、相机可控视频、human-motion-controlled-video。别名包括 `PCDController`、`alibaba-damo-academy/Uni3C`。模态上，它接受图像，输出视频。

记录的评测入口包括[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（显式控制下的相机轨迹跟随）。

## 运行时契约

可选 `prompt`、`input_path`、`render_path`、`mode`、`num_frames`；产物 `generated_video`、`uni3c.mp4`。

CLI task profile：`image-camera-control-video`。绑定的 pipeline 类是 `Uni3CPipeline`。

系列状态：**已验证**。

`image-camera-control-video` 记录默认值：fps=16, seed=0。

按需选择仅相机或相机+人体统一路由，并提供匹配的预渲染控制包。 默认 PCDController 相机路线已使用正式 checkpoint 在 H100 上完成 GPU 验证；相机+人体统一路线仍需单独完成 checkpoint 支撑的验证。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run uni3c --pipeline.task-profile image-camera-control-video` 跟随相机路径。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

记录的权重仓库包括 `ewrfcas/Uni3C`、`Wan-AI/Wan2.1-I2V-14B-720P-Diffusers`、`theFoxofSky/RealisDance-DiT`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh uni3c`；下载缺失的公开权重时加 `--download`。

状态：**已验证**。
