## 用来做什么

`vchitect-2-t2v` 是记录的 prompt 到视频路由——不是图像编辑，也不是策略。只要任务是文生视频，从这里起步。

并行扩散 Transformer 配 SD3 系 VAE 解码器，由角色化的 DiT、条件器、调度器、初始化器与解码器组件装配。profile 记录了固定的官方源码 revision（Vchitect-2.0 @ be56767f）。该模型由上海人工智能实验室（Vchitect 团队）发布。

catalog 记录的任务包括 文生视频、视频生成。别名包括 `vchitect`、`vchitect-2`、`vchitect2-t2v`、`vchitect_2_t2v`。模态上，它接受文本，输出视频。

记录的评测入口包括[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（标准文生视频质量评测）。
