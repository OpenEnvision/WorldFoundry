## 用来做什么

需要动作条件世界步进时选 `solaris`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

按记录的 checkpoint 格式，运行时基于 JAX/Orbax；除已记录任务外的内部细节此处未存。上游许可已标记需人工审查。该模型由纽约大学（VisionX 实验室）发布。

catalog 记录的任务包括 video_generation、multi-agent-world-model、交互式视频生成。别名包括 `solaris-wm`。输出模态为视频。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（多智能体世界滚动生成质量）。
