MAGI-2 从文本联合生成视频与音频。WorldFoundry 已接入 [SandAI-org/MAGI-2-preview](https://github.com/SandAI-org/MAGI-2-preview) 的 Preview MoE、可选稠密视频 Refiner、Turbo 视频解码器、音频编解码器与文本编码器，许可为 Apache-2.0。

## 运行时契约

集成状态：**已集成**。公共 pipeline 支持十秒文生视频。Preview 输出为 12.5 fps；可选 Refiner 增加时间分辨率，以 25 fps 导出并保留 Preview 音频。

Refiner 按 8×4×4 潜变量块打包视频，使用发布配置中的半径二局部注意力窗口。精确范围并集注意力保留所有允许的 key，不创建二次大小的稠密 mask。采样默认使用零 SNR 重加噪、五步 UniPC、shift 5 与 guidance 2。

## 在 WorldFoundry 中运行

准备 `sand-ai/MAGI-2-preview` 的权重布局：`preview/`、`refiner/`、`turbo_vae/`、`stable-audio-open-1.0/` 与 `text_encoder/`。组件按需加载；Preview 层使用顺序 GPU 驻留。

```python
from worldfoundry.pipelines.magi2 import NativeMagi2Pipeline

pipeline = NativeMagi2Pipeline.from_pretrained("/weights/MAGI-2-preview", device="cuda")
pipeline(
    prompt="A cinematic camera move through a sunlit forest.",
    use_refiner=True,
    refiner_num_inference_steps=5,
    refiner_height=1088,
    refiner_width=1920,
    output_path="/outputs/magi2-refined.mp4",
    seed=42,
)
```

`use_refiner=False` 保留 Preview-only 行为。Refiner 高宽必须为 16 的正整数倍。Refiner 将潜变量时间尺寸从 `T` 变为 `2T−1`，输出音频来自 Preview 阶段。

## 已执行证据

H100 上的 Refiner 阶段真实权重回放使用已保存的真实 Preview 潜变量与真实 Qwen3.5、Refiner、Turbo 权重。五步采样与 seed 42 导出 128×128、25 fps 的 249 帧视频，并保留原始立体声 44.1 kHz Preview 音频。回放命令见 `python tests/manual/magi2_refinement.py --help`。

## 限制

- 不支持图像条件。
- 默认 1920×1088 分辨率回放与官方数值、视觉一致性尚待验证。
- 114B Preview 需要较大的主机内存与顺序 offload；上游面向八张 Hopper GPU。
