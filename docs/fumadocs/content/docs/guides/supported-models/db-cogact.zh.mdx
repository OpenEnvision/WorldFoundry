DB-CogACT 是在 Dexmal 的 Dexbotic 框架内重建的 CogACT 配方，发布的 checkpoint 阵容相当完整：单臂与双臂基础模型，外加 LIBERO、CALVIN、SimplerEnv 任务 checkpoint，全部 Apache-2.0。 WorldFoundry 从内置推理子集在进程内构建官方 Dexbotic 策略，无需外部 checkout 即输出 LIBERO 动作轨迹。

## 用来做什么

`db-cogact-libero` 是记录的指令到动作线。需要 WorldFoundry VLA rollout 而不是视频生成时从这里起步。

仓库记录 Dexbotic v1 推理契约：请求携带 observation.prompt 与观测图像，策略沿用 CogACT 的 VLM+DiT 动作设计并在 Dexbotic 中重实现。内置推理子集位于 worldfoundry/synthesis/action_generation/db_cogact/db_cogact_runtime。

catalog 记录的任务包括 视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行。别名包括 `dexbotic`、`db_cogact`、`dexbotic-cogact`。

记录的评测入口包括[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（有专门的 libero-db-cogact checkpoint）、[CALVIN](/zh/docs/evaluation/benchmark-hub/calvin)（有专门的 calvin-db-cogact checkpoint）、[SimplerEnv](/zh/docs/evaluation/benchmark-hub/simpler-env)（有专门的 simpler-db-cogact checkpoint）。

## 运行时契约

可选 `prompt`、`input_path`、`interactions`、`fps`、`timeout_seconds`；产物 `action_trace`、`db-cogact_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `DBCogACTPipeline`。

系列状态：**Runner 一致性待确认**。

按基准选择 checkpoint：libero-db-cogact、calvin-db-cogact 或 simpler-db-cogact；SArm/HArm 基础模型用于微调。 集成状态为 Runner 一致性待确认。

WorldFoundry records the Dexbotic v1 inference contract with an independent DB-CogACT synthesis entrypoint.

必填 `image`、`prompt`；可选 `model_id`、`state`、`image_slots`、`policy_family`、`action_representation`；产物 `action_trace`、`db-cogact_action_trace.json`。

Workspace 的 LIBERO 路径用了 `Dexmal/libero-db-cogact`，写出形状 **`[1, 16, 7]`** 的有限轨迹。这是已记录的 GPU action-trace 检查。CALVIN / SimplerEnv 专家是接线好的 checkpoint，不是额外已验证轨迹。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run db-cogact-libero --pipeline.task-profile default` 执行策略。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch>=2.6.0）。

记录的权重仓库包括 `Dexmal/libero-db-cogact`、`Dexmal/Dexbotic-CogACT-SArm`、`Dexmal/Dexbotic-CogACT-HArm` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh db-cogact-libero`；下载缺失的公开权重时加 `--download`。

记录 license 为 apache-2.0；状态：**Runner 一致性待确认**。
