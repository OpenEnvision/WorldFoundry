## What it is for

Use `krea-realtime-video` for catalog text-to-video inference. The recipe exists so you can launch a recorded T2V profile without assembling an upstream demo.

Upstream describes it as a 14B autoregressive/streaming video model distilled for realtime block-wise generation (weights at krea/krea-realtime-video, apache-2.0). This repository records the block-based generation controls (num_blocks) and the prompt/video input contract; deeper internals are not recorded here.

Catalog tasks include realtime-video-generation, text-to-video, video-to-video, and streaming-video. Catalog aliases include `krea-rt-14b`. Documented modalities: text and video in, video out.

Recorded evaluation entry points include [VBench](/docs/evaluation/benchmark-hub/vbench) (Baseline quality check for streaming T2V output).
