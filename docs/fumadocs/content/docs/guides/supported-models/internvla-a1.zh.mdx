## 用来做什么

需要 catalog 上的 VLA 策略时选 `internvla-a1`：指令与观测进、动作轨迹出。用来滚动已记录策略，不是用来训练新策略。

A1-3B 计算图将 Qwen3-VL-2B 视觉-语言编码与专家动作头、Cosmos-Tokenizer-CI8x8 封装、flow 采样与归一化路由耦合——全部树内、仅本地，无远程 checkpoint 代码。该模型由上海人工智能实验室（InternRobotics）发布。

catalog 记录的任务包括 视觉-语言-动作（VLA）、机器人策略、策略执行、具身评测。

记录的评测入口包括[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（有专门的 InternVLA-A1-3B-RoboTwin checkpoint）。
