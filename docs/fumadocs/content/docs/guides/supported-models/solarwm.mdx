## Architecture

A single WorldFoundry launcher selects the released solarwm infer route in its dedicated backend environment. Source backbones, training code and data pipelines are not vendored.

## Runtime contract

Default variant=wan-5b-dmd. Provide source_root, checkpoint_dir, base_path and data_root. Prompts, images and camera tracks come from the indexed samples. Use a separate interpreter for Wan, LTX and H3; route process counts follow the official configs.

## Evaluation benchmarks

- [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) — Long-horizon camera-controlled world consistency.

## Readiness and limitations

- Only the infer action is exposed. Training, preencoding and data-engine commands are excluded.
- Code is Apache-2.0; LTX and H3 base/adapter weights retain their respective community licenses and restrictions.
- Checkpoint-backed GPU generation is pending.
