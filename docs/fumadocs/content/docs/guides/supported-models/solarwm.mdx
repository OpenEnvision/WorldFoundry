## What it is for

Use `solarwm-wan2.2-5b` for catalog world-model inference. Choose it when you need action-conditioned future frames rather than a standalone clip generator.

A single WorldFoundry launcher selects the released solarwm infer route in its dedicated backend environment. Source backbones, training code and data pipelines are not vendored. It is published by Junchao-cs.

Catalog tasks include camera-controlled-video and interactive-world-model. Catalog aliases include `solar-wm`, `solarwm-wan2.2-5b`, `solarwm-wan22-5b`, and `solarwm-wan2.2-14b` among others. Also recorded: `solarwm-wan2.2-14b`, `solarwm-ltx-22b`, `solarwm-h3-33b`.

Recorded evaluation entry points include [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Long-horizon camera-controlled world consistency).

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run solarwm-wan2.2-5b --pipeline.task-profile indexed-inference`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the dedicated environment `worldfoundry-solarwm-wan22-cu124` (Python 3.10, CUDA 12.4, torch==2.5.1+cu124).

Recorded weight repositories include `junchaoh-cs/SolarWM` and `junchaoh-cs/SolarWM-H3-33B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh solarwm-wan2.2-5b`. Add `--download` to fetch missing public checkpoints.
