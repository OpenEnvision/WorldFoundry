Matrix-Game 1.0 是昆仑万维交互式游戏世界模型的第一代：从一张图与键鼠式动作生成可交互的游戏世界视频。本 catalog 中它注册为独立模型 id，绝不经由 Matrix-Game-2 路由；官方 Python 运行时的最小闭包已内置树内。

## 用来做什么

用键盘/鼠标 token 驱动 Matrix-Game 1。不是 2.0 或 3.x 运行时。

启动 `worldfoundry-eval run matrix-game-1`。

评测入口：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件游戏世界滚动生成质量）。

## 运行时契约

必填 `image`、`prompt`；`actions`：keyboard, mouse, navigation_token；产物 `world.mp4`。

本地缓存布局记录了 checkpoint 规模：Skywork--Matrix-Game 下的七个 DiT 分片、四个 text_encoder_i2v 分片、一个 VAE 权重、配置与资产。除此之外的架构内部细节仓库未记录。

## 在 WorldFoundry 中运行

状态：**Runner 一致性待验证**。统一环境 `worldfoundry-unified-cu128`（Python 3.11, CUDA 12.8）。先把 `Skywork/Matrix-Game` 就位到本地，缺文件加载失败，运行时不下载。在该环境执行 `worldfoundry-eval run matrix-game-1`。catalog 未记录 VRAM。
