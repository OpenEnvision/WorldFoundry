Kling API 是快手「可灵」视频生成系列的托管接入点，catalog 记录了文生视频与图生视频两类任务。提示词或参考图会提交到快手的服务端，渲染好的视频以 WorldFoundry 产物的形式返回。设立该条目的目的，是让托管的可灵结果与本地运行的开源模型共用同一套 Studio 结果格式，方便直接对比。

## 架构

这是由服务方托管运行的模型：厂商未公开其架构、参数规模或训练细节，本仓库也未记录这些信息。WorldFoundry 记录的只是集成层——一条向服务方端点提交请求并回收生成视频产物的 Studio pipeline。

## 运行时契约

Catalog 将该条目标记为 integrated：托管 API 的 Studio pipeline 已可用，但你必须自备服务方的 API key 与账号。本地不会下载任何权重、也不会创建 GPU 环境——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。凭据需在可灵开放平台（app.klingai.com）申请。

## 评测 Benchmark

- [VBench](/zh/docs/evaluation/benchmark-hub/vbench) — 对比托管文/图生视频输出的标准多维质量评测。
- [Physics-IQ Original](/zh/docs/evaluation/benchmark-hub/physics-iq) — 检验服务方视频模型是否遵循基本物理合理性。

## 就绪状态与限制

- 需要付费的服务方账号与 API key；WorldFoundry 不提供任何凭据。
- 模型版本由服务方控制，输出可能随时间变化而与本仓库无关——因此 manifest 将 runner parity 记录为 not applicable。
- 没有本地权重、不支持离线运行；除 WorldFoundry 保存的请求参数外，无法进一步固定可复现性。
