## 用来做什么

`kling-api` 是托管推理线。卡片上没有本地 checkpoint 时从这里起步。

这是由服务方托管运行的模型：厂商未公开其架构、参数规模或训练细节，本仓库也未记录这些信息。WorldFoundry 记录的只是集成层——一条向服务方端点提交请求并回收生成视频产物的 Studio pipeline。该模型由快手（Kuaishou）发布。

catalog 记录的任务包括 文生视频、图生视频、托管 API。模态上，它接受文本、图像，输出视频。

记录的评测入口包括[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（对比托管文/图生视频输出的标准多维质量评测）、[Physics-IQ Original](/zh/docs/evaluation/benchmark-hub/physics-iq)（检验服务方视频模型是否遵循基本物理合理性）。

## 运行时契约

可选 `prompt`、`negative_prompt`、`input_path`、`image_field`、`task_type`。

CLI task profile：`default`。绑定的 pipeline 类是 `KlingApiPipeline`。

系列状态：**Runner 一致性待确认**。

Catalog 将该条目标记为 integrated：托管 API 的 Studio pipeline 已可用，但你必须自备服务方的 API key 与账号。 本地不会下载任何权重、也不会创建 GPU 环境——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。 凭据需在可灵开放平台（app.klingai.com）申请。

需要付费的服务方账号与 API key；WorldFoundry 不提供任何凭据。
