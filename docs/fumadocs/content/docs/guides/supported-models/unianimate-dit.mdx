## What it is for

Use `unianimate-dit` for the family's joint T2V/I2V inference path. The catalog records both task profiles on this page.

Built on the Wan2.1 image-to-video diffusion transformer with pose-sequence conditioning for human animation (checkpoint: ZheWang123/UniAnimate-DiT). Deeper conditioning internals are not recorded in this repository. It is published by Alibaba (Tongyi Lab).

Catalog tasks include human-image-animation, image-to-video, and video-generation. Documented modalities: image in, video out.

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run unianimate-dit --pipeline.task-profile interactive-video`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `ZheWang123/UniAnimate-DiT`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh unianimate-dit`. Add `--download` to fetch missing public checkpoints.
