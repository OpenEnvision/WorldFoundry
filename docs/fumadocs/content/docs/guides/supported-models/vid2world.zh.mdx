## 用来做什么

`vid2world` 是记录的交互世界线。要用动作推进世界时从这里起步。

仓库记录的核心思想是视频扩散适配：将全序列扩散模型改造成因果、动作条件的滚动生成。官方仓库指针（thuml/Vid2World，锁定 head ae24077a）之外的架构内部细节仓库未记录。该模型由清华大学（THUML 机器学习组）发布。

catalog 记录的任务包括 交互式世界模型、video-diffusion-adaptation、动作条件视频。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件交互滚动生成质量）。

## 运行时契约

可选 `prompt`、`input_path`、`interactions`、`frames`、`fps`；产物 `generated_video`、`vid2world_runtime_plan.json`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `Vid2WorldPipeline`。

系列状态：**Runner 一致性待确认**。

`interactive-video` 记录默认值：frames=16, fps=16, seed=42。

配置解析与 pipeline 导入预期可通过；在所需 checkpoint/资产就位前，真实生成会输出运行时计划。 缺失资产由计划报告，不视为 catalog 阻塞。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run vid2world --pipeline.task-profile interactive-video`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

本卡片未记录公开 checkpoint id；按使用说明就位权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh vid2world`；下载缺失的公开权重时加 `--download`。
