MineWorld is Microsoft's real-time open-source interactive world model for Minecraft: an autoregressive transformer that plays forward Minecraft scenes from image/video context and actions (arXiv 2504.08388, MIT license). In this catalog the source is vendored in-tree; runnable execution still needs the official dependency environment, checkpoints, and validation/demo data.

## What it is for

Use `mineworld` for catalog world-model inference. Choose it when you need action-conditioned future frames rather than a standalone clip generator.

Per the paper, a visual tokenizer plus an autoregressive transformer over interleaved state-action tokens, with parallel decoding for real-time speed. Internals beyond this are not recorded here.

Catalog tasks include interactive-world-model, minecraft-world-model, and action-conditioned-video.

Recorded evaluation entry points include [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Action-conditioned game-world rollout quality).

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run mineworld --pipeline.task-profile interactive-video`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

No public checkpoint id is recorded on this card; follow the usage notes for staging. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh mineworld`. Add `--download` to fetch missing public checkpoints.
