## 用来做什么

`magi-1` 是记录的文本/图像到视频线。需要同一张卡片上同时有 prompt 与静帧条件时用它。

上游将 MAGI-1 描述为按块自回归生成、使用因果注意力的大型视频模型，支持流式续写。本仓库仅记录 prompt+image 输入契约与 generated_video 产物；规模与内部细节仓库未记录。

catalog 记录的任务包括 图生视频、视频生成。模态上，它接受图像，输出视频。

记录的评测入口包括[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（基础视频生成质量评测）。
