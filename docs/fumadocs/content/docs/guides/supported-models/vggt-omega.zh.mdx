VGGT-Omega 是以 facebook/VGGT-Omega 发布的 VGGT 扩展版本，覆盖 3D 重建、高斯泼溅与新视角合成。本 catalog 中它以异常严格的证据验证：与固定上游 commit 的单图 GPU 一致性对比在可比输出上达到 max_abs_diff=0.0，树内 runner 支持官方场景导出路径。

## 用来做什么

`vggt-omega` 是记录的重建线。从记录的视图写出几何时从这里起步。

它使用官方架构的表示 runner 加上现有的 WorldFoundry VGGTResult/save 接口，输出 predictions.npz 与 GLB 场景产物。权重存放于 assets/checkpoints、绝不提交进源码；checkpoint 许可为 CC-BY-NC-4.0。该模型由Meta AI发布。

catalog 记录的任务包括 3D 重建、高斯泼溅、新视角合成。别名包括 `vggt_omega`、`facebook/VGGT-Omega`。

不是 [VGGT](/zh/docs/guides/supported-models/vggt)、[VGGT-World](/zh/docs/guides/supported-models/vggt-world)。

## 运行时契约

可选 `input_path`、`interactions`、`camera_view`、`task_type`、`image_resolution`；产物 `scene_conf20.0_blackFalse_whiteFalse_camTrue_skyFalse_max200k.glb`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `VGGTOmegaPipeline`。

系列状态：**已验证**。

需要已验证的官方场景导出路径与 WorldFoundry 表示产物时使用本条目。 它与 vggt（基础版）及 vggt-world 条目相互独立——请按路径而非名称选择。

VGGT-Omega uses an official-architecture representation runner plus the existing WorldFoundry VGGTResult/save interface.

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run vggt-omega --pipeline.task-profile interactive-video` 写出几何。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `facebook/VGGT-Omega`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh vggt-omega`；下载缺失的公开权重时加 `--download`。

记录 license 为 cc-by-nc-4.0；状态：**已验证**。
