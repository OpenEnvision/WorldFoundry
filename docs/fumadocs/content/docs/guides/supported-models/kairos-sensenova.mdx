Kairos Sensenova is SenseTime's embodied world-model video generator: a 4B model covering text-, image-, and text+image-to-video with a robot-oriented distilled recipe. In this catalog both integration and runner are verified — the default robot 4B 480P DMD text-to-video recipe runs through the in-tree Apache-2.0 torchrun runtime with 8 ranks.

## Architecture

The default runnable variant follows the official robot 4B 480P distilled recipe (kairos_4b_config_DMD.py): 81 frames, 480x640, cfg_scale 5, tiled VAE decode, no CFG-parallel. Recorded checkpoints cover the robot 480P distilled, 480P pretrained, and 720P variants; the config layout expects Kairos, Qwen, and Wan2.1-T2V-14B subdirectories.

## Runtime contract

Set WORLDFOUNDRY_KAIROS_MODELS_ROOT (or models_root) to a directory matching the official config layout. 720P and non-distilled variants need the corresponding checkpoint paths and config override.
