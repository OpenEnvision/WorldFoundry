## 架构

树内路由接入 Spatia 推理与稠密 world-to-camera（W2C）轨迹输入：逐帧相机外参驱动重渲染。除内置源码外的架构内部细节仓库未记录。

## 运行时契约

提供源图像或视频及逐帧稠密 W2C 相机轨迹。可选 mask_path 将一张与原始源帧尺寸一致的前景掩码传入重建阶段；改变缓存输入时设置 force_rebuild_intermediate。本地图像输入已完成 832x480、40 步、17 帧推理；相机轨迹遵循性尚未确立。

## 评测 Benchmark

- [CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench) — 相机轨迹跟随与受控重渲染质量。

## 就绪状态与限制

- 已记录本地真实权重 GPU 推理；官方 PyTorch3D 渲染器一致性及相机控制精度尚未验证。
- 需要逐帧稠密相机轨迹，而非稀疏关键帧位姿。
- 默认 MapAnything 权重使用非商业许可。
