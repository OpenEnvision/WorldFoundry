## 用来做什么

需要相机可控视频时选 `spatia`：相机轨迹进、受控视频出。视角必须跟随路径时，用它而不是无约束 T2V。

树内路由接入 Spatia 推理与稠密 world-to-camera（W2C）轨迹输入：逐帧相机外参驱动重渲染。除内置源码外的架构内部细节仓库未记录。

catalog 记录的任务包括 相机可控视频、视频到视频、世界模型。模态上，它接受视频，输出视频。

记录的评测入口包括[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（相机轨迹跟随与受控重渲染质量）。

## 运行时契约

可选 `prompt`、`input_path`、`frames`、`fps`、`height`；产物 `spatia.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `SpatiaPipeline`。

系列状态：**已验证**。

`default` 记录默认值：frames=121, fps=24, height=704, width=1248, seed=20917。

提供源图像或视频及逐帧稠密 W2C 相机轨迹。 可选 mask_path 将一张与原始源帧尺寸一致的前景掩码传入重建阶段；改变缓存输入时设置 force_rebuild_intermediate。 本地图像输入已完成 832x480、40 步、17 帧推理；相机轨迹遵循性尚未确立。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run spatia --pipeline.task-profile default` 跟随相机路径。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `Jinjing713/Spatia`、`Wan-AI/Wan2.2-TI2V-5B`、`facebook/map-anything`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh spatia`；下载缺失的公开权重时加 `--download`。
