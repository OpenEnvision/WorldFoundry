Video Depth Anything 为 Depth Anything 家族带来时序一致性：在任意长度的视频上估计深度，避免逐帧估计的闪烁。本 catalog 中它是独立的时序深度先验，VIPE pipeline 档案可通过共享运行时配置选用它，而无需持有其代码。

## 用来做什么

做前馈几何时选 `video-depth-anything-prior`：视图进、重建/轨迹/点云出。需要 catalog 的 3D 路由、而不是仅深度先验时用它。

按上游发布，时空头加时间梯度一致性目标把 Depth Anything V2 扩展到视频，并用关键帧策略处理长序列。记录的 checkpoint 为 depth-anything/Video-Depth-Anything-Large（apache-2.0）；注册于 base_models/three_dimensions/depth/videodepthanything。该模型由字节跳动发布。

catalog 记录的任务包括 video-depth-estimation、temporal-depth-estimation、几何先验。别名包括 `video-depth-anything`、`vda-prior`。模态上，它接受图像，输出深度。

## 运行时契约

可选 `input_path`、`model`、`input_size`、`max_frames`、`execute`；产物 `video-depth-anything-prior.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `VideoDepthAnythingPriorPipeline`。

系列状态：**Runner 一致性待确认**。

它作为独立几何先验集成在 worldfoundry/base_models 下，通过共享的 geometry-prior pipeline/operator 契约对外暴露。 上层管线（如 ViPE）从这一规范位置导入它，而不是各自保留私有副本。 配置解析与 pipeline/operator 导入预期可通过；真实先验推理仍受 checkpoint 限制。

受 checkpoint 限制：真实推理需要就位的 Video-Depth-Anything-Large 权重。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run video-depth-anything-prior --pipeline.task-profile default`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `depth-anything/Video-Depth-Anything-Large`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh video-depth-anything-prior`；下载缺失的公开权重时加 `--download`。
