MosaicMem 是记忆增强的世界模型组件：摄取关键帧 patch、检索目标视图、汇总覆盖度并组合潜空间画布——产物是记忆索引而非视频。本 catalog 中其源码路径按记忆计划产物注册，并通过 worldfoundry.core.memory 暴露；生成器资产保持运行时限制。

## 用来做什么

`mosaicmem` 是记录的交互世界线。要用动作推进世界时从这里起步。

架构内部细节仓库未记录（MIT 许可）；源码绑定在固定 commit。记录的产物类型为 memory_index。

catalog 记录的任务包括 世界模型、memory-augmented-generation、视频生成。输出模态为视频。

记录的评测入口包括[MemoBench](/zh/docs/evaluation/benchmark-hub/memobench)（长时程记忆一致性评测）。

产物是记忆索引，不是视频。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run mosaicmem --pipeline.task-profile default`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。
