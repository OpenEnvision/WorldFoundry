Déjà View Looping Transformer (DVLT) is an NVIDIA multi-view reconstruction model covering 3D reconstruction, camera pose estimation, and depth from image collections, exporting GLB scenes. The WorldFoundry wrapper is lazy: it runs the external DVLT GLB export path only when CUDA, dependencies, source, inputs, and weights are all staged locally.

## What it is for

`dvlt` is the recorded reconstruction line. Start here to emit geometry from the documented views.

The catalog records a looping-transformer design for multi-view geometry (paper arXiv 2605.30215); the runtime source is externalized from the public release tree, so architecture internals beyond the recorded tasks are not stored here.

Catalog tasks include 3d-reconstruction, multi-view-reconstruction, camera-pose-estimation, and depth-estimation. Catalog aliases include `deja-view`, `dejaview`, `deja-view-looping-transformer`, and `nvidia/dvlt`.

## Runtime contract

Optional `input_path`, `execute`, `max_points`, and `focal_length`; artifacts `dvlt_reconstruction.glb`.

CLI task profiles: `default`. WorldFoundry binds `DVLTPipeline`.

Family status: **Runner parity pending**.

Runner registration is wired; GPU parity is pending checkpoint and environment validation. The nvidia/dvlt checkpoint carries the NVIDIA non-commercial research/evaluation license — check terms before use. DVLTSynthesis fails fast on missing prerequisites.

Runtime source is externalized from the public release tree; checkpoints remain external assets.

## Running in WorldFoundry

Launch `worldfoundry-eval run dvlt --pipeline.task-profile default` to write geometry. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `nvidia/dvlt`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh dvlt`. Add `--download` to fetch missing public checkpoints.

Recorded licenses include nvidia-noncommercial-research-evaluation; status: **Runner parity pending**.
