Galaxea G0Plus 是星海图（Galaxea AI）的开放 VLA：RGB、语言和状态进，动作轨迹出。发布的 checkpoint 架在 **PaliGemma-3B** 上，配 **flow-matching** 动作采样器和 KV 缓存解码。WorldFoundry 把架构、KV cache、flow 采样器、严格 checkpoint 加载器、tokenizer 适配器、预处理和归一化都放在**树内**。恢复按官方参数名严格对齐。运行时只接受本地就位资产，从不执行 checkpoint 自带的 Python。

发布的 G0Plus 基座面向**下游微调**，不声称是任务就绪策略。必须配对精确的 `dataset_stats.json`——归一化从不编造数值。

## 用来做什么

Galaxea / G0-VLA 静态加载路径。GPU 数值 rollout 仍待验证。

启动 `worldfoundry-eval run galaxea-vla`。

## 运行时契约

必填 `image`、`prompt`、`state`；可选 `model_id`、`policy_family`；产物 `action_trace`、`galaxea_vla_action_trace.json`。

| 变体 | 相机 | 状态 / 动作 | 块 |
| --- | --- | --- | --- |
| `r1lite_mobile` | 3 | 21 / 26 | 32 |
| `r1lite_arm` | 3 | 14 / 14 | 32 |
| `libero` | 2 | 8 / 7 | 32 |
