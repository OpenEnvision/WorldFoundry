## 用来做什么

`sora2` 是托管推理线。卡片上没有本地 checkpoint 时从这里起步。

OpenAI 曾公开将初代 Sora 描述为在视频潜空间时空 patch 上运行的扩散 Transformer；除这一公开表述外，Sora 2 的架构、规模与训练细节均未披露，本仓库亦未记录。

catalog 记录的任务包括 文生视频、图生视频、托管 API。模态上，它接受文本、图像，输出视频。

记录的评测入口包括[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（对比托管文/图生视频输出的标准多维质量评测）、[Physics-IQ Original](/zh/docs/evaluation/benchmark-hub/physics-iq)（检验服务方视频模型是否遵循基本物理合理性）。
