RollingForcing 自回归地流式生成数分钟长的视频：滚动窗口去噪加 attention sink，避免了朴素流式生成的漂移崩坏（论文 arXiv 2509.25161）。本 catalog 中 runner 达到 full_demo_verified——用发布的确切 checkpoint 完成完整 Workspace 推理，126 个潜帧解码为 501 帧 832x480、16 fps 的 H.264，A100 上耗时 31.31 秒的视频内容。

## 用来做什么

需要本系列的文生视频时选 `rolling-forcing`：prompt 进、生成视频出。它是 catalog 上的 T2V 起步线，不是编辑器，也不是世界模型步进器。

树内仅推理 runner 复用现有 forcing pipeline、因果 Wan variant、attention sink/KV 缓存、核心调度器、注意力分发、分布式辅助与视频 I/O；执行绝不导入外部 RollingForcing 仓库。静态集成遵循官方五步、三潜帧块配置。该模型由腾讯（ARC Lab）/ 南洋理工大学发布。

catalog 记录的任务包括 文生视频、长视频生成、autoregressive-video-generation。别名包括 `RollingForcing`、`rolling_forcing`、`rollingforcing`。模态上，它接受文本，输出视频。

记录的评测入口包括[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（长文生视频输出的质量评测）、[ChronoMagic-Bench](/zh/docs/evaluation/benchmark-hub/chronomagic-bench)（长时程时间连贯性评测）。
