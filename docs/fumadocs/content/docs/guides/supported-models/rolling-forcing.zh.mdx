## 架构

树内仅推理 runner 复用现有 forcing pipeline、因果 Wan variant、attention sink/KV 缓存、核心调度器、注意力分发、分布式辅助与视频 I/O；执行绝不导入外部 RollingForcing 仓库。静态集成遵循官方五步、三潜帧块配置。

## 运行时契约

发布路径仅文生视频——未验证的图生视频行为不对外宣传。BF16 与显存容量是硬件要求；官方 126 潜帧解码为 16 fps 长视频，更小的三的倍数可作冒烟运行。上游条款仅允许学术使用。
