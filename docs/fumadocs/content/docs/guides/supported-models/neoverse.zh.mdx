## 用来做什么

`neoverse` 是记录的交互世界线。要用动作推进世界时从这里起步。

按上游发布（arXiv 2601.00393），NeoVerse 在 Wan 视频基座上叠加 4D 重建与控制角色。 WorldFoundry 将其表达为共享 Wan 基础设施上的原生组装——真实推理仍受 checkpoint/GPU 限制，不使用仅元数据的 runner 壳。该模型由CreateAI（原图森未来）发布。

catalog 记录的任务包括 4D world modeling from in-the-wild monocular videos。别名包括 `NeoVerse: Enhancing 4D World Model`。

记录的评测入口包括[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（评估可游走的生成世界）、[4DWorldBench](/zh/docs/evaluation/benchmark-hub/4dworldbench)（契合该条目的 4D 世界模型定位）。

## 运行时契约

`official-tilt-up-video` 记录默认值：seed=42。

运行需要 NeoVerse、Wan、重建器、LoRA 与 CUDA 资产。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run neoverse --pipeline.task-profile official-tilt-up-video`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `Yuppie1204/NeoVerse`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh neoverse`；下载缺失的公开权重时加 `--download`。
