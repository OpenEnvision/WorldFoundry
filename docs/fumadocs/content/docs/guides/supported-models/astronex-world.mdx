## Architecture

Wan2.2 TI2V-5B with PRoPE camera conditioning, 64-dimensional actions and embodiment conditioning. The official sampler remains external; no Wan backbone is copied into this integration.

## Runtime contract

Select mode=causal or bidirectional; supply source_root and checkpoint_dir. execute=True runs inference. latent_frames counts generated latent frames, not video frames; causal blocks require (latent_frames + reference_count) % 8 == 0.

## Readiness and limitations

- Official inference command construction is CPU-validated; checkpoint-backed generation remains pending.
- The released action prediction head is zero initialized; action prediction is not advertised.
