## 用来做什么

需要动作条件世界步进时选 `wilddet3d`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

这是感知模型，而非视频生成器。官方模型结合 SAM3 图像特征与 LingBot-Depth 几何信息；源码和子模块从仓库外的固定版本检出加载。

catalog 记录的任务包括 3d-detection、wild-3d-perception、world-understanding。

## 运行时契约

产物 `generated_3d_asset`、`wilddet3d_predictions.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `WildDet3DPipeline`。

系列状态：**已验证**。

传入 image_path，并用英文逗号分隔 prompt 中的检测类别；可选传入 3x3 的 intrinsics_path（.npy）。 需要完整的 allenai/WildDet3D checkpoint、robbyant/lingbot-depth-postrain-dc-vitl14/model.pt，以及含子模块的官方固定版本源码。 上游源码使用 SAM License。

仅感知：不产出视频或世界生成结果。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run wilddet3d --pipeline.task-profile default` 推进世界。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `allenai/WildDet3D`、`robbyant/lingbot-depth-postrain-dc-vitl14`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh wilddet3d`；下载缺失的公开权重时加 `--download`。

状态：**已验证**。
