## What it is for

Pick `solaris` when you need an action-conditioned world stepper: recorded actions and a frame in, a rollout out. Use it for interactive world inference, not a text-to-video prompt dump.

The runtime is JAX/Orbax-based per the recorded checkpoint format; internals beyond the recorded tasks are not stored here. The upstream license is flagged for manual review. It is published by New York University (VisionX).

Catalog tasks include video generation, multi-agent-world-model, and interactive-video-generation. Catalog aliases include `solaris-wm`. Documented outputs include video.

Recorded evaluation entry points include [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Multi-agent world-rollout quality).

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run solaris --pipeline.task-profile default`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `nyu-visionx/solaris`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh solaris`. Add `--download` to fetch missing public checkpoints.
