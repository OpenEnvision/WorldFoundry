## What it is for

Pick `spirit-v1.5` when you want the catalog VLA policy: instruction and observation in, an action trace out. Use it to roll the recorded policy, not to train a new one.

A Qwen3-VL vision-language backbone with Spirit's action prediction head. Architecture internals beyond the official repository pointer are not recorded in this repository.

Catalog tasks include vla action prediction and vla policy rollout. Catalog aliases include `spirit-vla`, `spirit-v1p5`, and `spirit_v1p5`.
