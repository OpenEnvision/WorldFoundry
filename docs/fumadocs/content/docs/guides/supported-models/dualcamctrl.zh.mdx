DualCamCtrl 用**相机轨迹加深度图**控制视频：RGB 和深度一起钉住几何，让相机运动落地。WorldFoundry 把推理放在 `worldfoundry/synthesis/visual_generation/dualcamctrl`，对外是 `DualCamCtrlPipeline`。Runner **和** demo 都按官方 RGB / 深度 / 相机契约**已验证**。

## 用来做什么

双相机控制，面向立体风格成对输入。

启动 `worldfoundry-eval run dualcamctrl`。

评测入口：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（受控生成的相机轨迹贴合度）。

## 运行时契约

必填 `prompt`、`image`；可选 `video`；`actions`：camera_trajectory, depth_image；产物 `dualcamctrl.mp4`、`seaside.mp4`。

| 旋钮 | 官方 demo |
| --- | --- |
| 尺寸 | **320×480** |
| 帧数 | **61** |
| 步数 | **50** |
| 轨迹 | `.torch` 相机文件 |

## 在 WorldFoundry 中运行

状态：**已验证**。统一环境 `worldfoundry-unified-cu128`（Python 3.11, CUDA 12.8）。先把 `FayeHongfeiZhang/DualCamCtrl`、`alibaba-pai/Wan2.1-Fun-V1.1-1.3B-Control-Camera`、`Wan-AI/Wan2.1-T2V-1.3B` 等就位到本地，缺文件加载失败，运行时不下载。在该环境执行 `worldfoundry-eval run dualcamctrl`。catalog 未记录 VRAM。
