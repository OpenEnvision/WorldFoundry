Depth Anything V1 is the foundation model for relative monocular depth that popularized large-scale unlabeled-data depth training. In this catalog both integration and runner status are verified: the in-tree pipeline exports relative depth and geometry artifacts, and the Studio route produced a visually validated nonblank depth map on 2026-07-10.

## What it is for

Pick `depth-anything-v1` for feed-forward geometry: views in, reconstruction / trajectory / point cloud out. Use it when you need the catalog 3D route rather than a depth-only prior.

It is published by TikTok / The University of Hong Kong.

Catalog tasks include depth, geometry, and monocular-depth-estimation. Documented modalities: image in, depth out.

## Runtime contract

Optional `input_path`, `grayscale`, and `operator_kwargs`; artifacts `depth-anything-v1.png`.

CLI task profiles: `default`. WorldFoundry binds `DepthAnything1Pipeline`.

Family status: **Verified**.

A verified, dependable prior — good default for relative depth. For metric depth choose depth-anything-v2-prior or depth-anything-v3-prior instead.

In-tree Depth Anything V1 pipeline is registered for relative depth and geometry artifact export.

## Running in WorldFoundry

Launch `worldfoundry-eval run depth-anything-v1 --pipeline.task-profile default` to write geometry. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `LiheYoung/depth-anything-large-hf`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh depth-anything-v1`. Add `--download` to fetch missing public checkpoints.

Status: **Verified**.
