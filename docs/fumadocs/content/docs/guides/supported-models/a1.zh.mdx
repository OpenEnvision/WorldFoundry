A1（AffordVLA）是可供性（affordance）引导的视觉-语言-动作策略：先将操作任务锚定到视觉可供性，再预测机器人动作。WorldFoundry 将 AffordVLA 完整内置树内——Molmo 与 CLIP ViT 编码器、 L1/DiT/flow 动作头与预处理——并确认两个 checkpoint：任务用 spatialtemporal-ai/a1-libero，预训练策略 a1-pretrain。

## 用来做什么

用 `a1` 做本卡的视觉-语言-动作推理。这条配方用来启动已记录的策略 profile。

该栈将 Molmo（VLM）与 CLIP ViT 视觉编码同可选动作头（L1 回归、DiT 或 flow）耦合。运行时从 checkpoint 张量推导动作维度并校验每个动作 token 边界，不匹配的 checkpoint 会快速失败。

catalog 记录的任务包括 视觉-语言-动作（VLA）、VLA 策略执行、机器人策略。别名包括 `affordvla-a1`、`spatialtemporal-ai/a1-libero`、`spatialtemporal-ai/a1-pretrain`。

记录的评测入口包括[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（a1-libero checkpoint 面向 LIBERO 操作任务）。

## 运行时契约

可选 `prompt`、`input_path`、`interactions`、`fps`、`timeout_seconds`；产物 `action_trace`、`a1_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `A1Pipeline`。

系列状态：**Runner 一致性待确认**。

运行前需在本地就位 tokenizer 与 checkpoint 资产。 资产仅从本地加载，绝不执行 checkpoint 携带的 Python；运行时加载采用严格键匹配。

AffordVLA, Molmo, CLIP ViT, L1/DiT/flow action heads, preprocessing, and safe local checkpoint loading run in tree.

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run a1 --pipeline.task-profile default` 执行策略。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是独立 profile `worldfoundry-vla-a1`（Python 3.11，CUDA 12.8，torch>=2.8）。

记录的权重仓库包括 `spatialtemporal-ai/a1-libero`、`Qwen/Qwen2-7B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh a1`；下载缺失的公开权重时加 `--download`。

状态：**Runner 一致性待确认**。
