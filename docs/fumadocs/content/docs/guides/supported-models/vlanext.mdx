## What it is for

Use `vlanext-libero` for vision-language-action inference on this card. The recipe exists so you can launch the recorded policy profile.

Public checkpoints cover the LIBERO suites (VLANeXt_libero_spatial.pt, _object.pt and more). Architecture internals beyond the official repository pointer are not recorded in this repository. It is published by Nanyang Technological University (S-Lab).

Catalog tasks include vla, vla action prediction, and vla policy rollout. Catalog aliases include `vlanext-libero` and `vla-next`.

Recorded evaluation entry points include [LIBERO](/docs/evaluation/benchmark-hub/libero) (Official LIBERO checkpoint collection), [LIBERO-Plus](/docs/evaluation/benchmark-hub/libero-plus) (LIBERO-plus contracts are recorded).

## Running in WorldFoundry

Launch `worldfoundry-eval run vlanext-libero --pipeline.task-profile default` to execute the policy. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch==2.4.0).

Recorded weight repositories include `DravenALG/VLANeXt`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh vlanext-libero`. Add `--download` to fetch missing public checkpoints.

Recorded licenses include s-lab-1.0; status: **Static load only**.
