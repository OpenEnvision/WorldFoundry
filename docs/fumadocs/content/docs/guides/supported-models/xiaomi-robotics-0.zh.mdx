Xiaomi-Robotics-0 是小米的开放 VLA 策略线，提供尤为完整的 Apache-2.0 基准模型阵容：LIBERO、CALVIN ABCD-D、CALVIN ABC-D、SimplerEnv Google Robot 与 SimplerEnv WidowX 的 checkpoint，以及一个预训练基座 checkpoint。默认使用 LIBERO checkpoint。

论文是 [arXiv 2602.12684](https://arxiv.org/abs/2602.12684)。代码：[XiaomiRobotics/Xiaomi-Robotics-0](https://github.com/XiaomiRobotics/Xiaomi-Robotics-0)。

别名：`xr0`、`xiaomi-robotics-zero`、`Xiaomi-Robotics-0`。

## 用来做什么

将 Xiaomi-Robotics-0 作为视觉-语言-动作策略运行。先跑 `xiaomi-robotics-0-libero`；还有 `xiaomi-robotics-0-calvin-abcd`、`xiaomi-robotics-0-calvin-abc`、`xiaomi-robotics-0-simplerenv-google` 等。启动 `wf run xiaomi-robotics-0-libero`——必填 `instruction`、`prompt`、`image`、`state`；产物 `action_trace`、`xiaomi_robotics_0_action_trace.json`。

不是 [Xiaomi Robotics 1](/zh/docs/guides/supported-models/xiaomi-robotics-1)。评测看 [LIBERO](/zh/docs/evaluation/benchmark-hub/libero)、[CALVIN](/zh/docs/evaluation/benchmark-hub/calvin)。

## 运行时契约

必填：`instruction`、`prompt`、`image`、`state`。可选：`video`、`state_dim`、`action_chunk`、`action_chunk_max`。产物：`action_trace`、`xiaomi_robotics_0_action_trace.json`。按基准选择 checkpoint：LIBERO、任一 CALVIN 划分或 SimplerEnv 本体。更新一代请见 xiaomi-robotics-1。

## 在 WorldFoundry 中运行

使用独立环境 `worldfoundry-xiaomi-robotics-0-cu128`（Python 3.12，CUDA 12.8）。将 `XiaomiRobotics/Xiaomi-Robotics-0-LIBERO`、`XiaomiRobotics/Xiaomi-Robotics-0-Calvin-ABCD_D`、`XiaomiRobotics/Xiaomi-Robotics-0-Calvin-ABC_D` 等准备到本地。启动 `wf run xiaomi-robotics-0-libero`。许可：Apache-2.0。
