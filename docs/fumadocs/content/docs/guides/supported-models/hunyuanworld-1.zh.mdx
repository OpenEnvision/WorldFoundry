## 用来做什么

需要动作条件世界步进时选 `hunyuanworld-1`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

按上游发布，生成以全景为先：先生成全景代理图，再做语义分层并提升为 3D 世界表示。除此之外的架构内部细节仓库未记录。该模型由腾讯（混元）发布。

catalog 记录的任务包括 世界模型。

记录的评测入口包括[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（生成可探索世界的标准评分）。
