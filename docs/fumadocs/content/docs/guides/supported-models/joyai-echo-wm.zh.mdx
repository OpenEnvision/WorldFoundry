## 用来做什么

`joyai-echo-wm` 是记录的相机控制路由。按 catalog 相机路径推进时从这里起步。

两个公开变体均使用带 UCPE 相机条件的 LTX-2.3 音视频骨干。Base 为双向模型并分别使用视频/音频 CFG；Flash 以 DMD 蒸馏 guidance，并维护有界的视频、音频、跨模态及相机注意力缓存。该模型由京东（JoyAI / Echo 团队）发布。

catalog 记录的任务包括 image-to-world-video、相机可控视频、交互式世界模型、音视频联合生成。别名包括 `echo-wm`、`joyai-echo-world-model`。

记录的评测入口包括[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（相机与导航动作遵循度）、[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（通用动作条件世界滚动生成质量）、[WBench](/zh/docs/evaluation/benchmark-hub/wbench)（上游 Flash 示例采用 WBench 相机控制案例）。
