腾讯 ARC 的 VerseCrafter 是基于 4D 控制的相机可控图生视频世界模型：几何感知渲染阶段产出 4D 控制信号，引导扩散阶段沿指定相机路径生成。WorldFoundry 将官方源码（revision 008693b5）与精确的 VideoX-Fun 子模块（revision 246a0e3a）内置树内，checkpoint 引用为 TencentARC/VerseCrafter。

## 架构

树内接通两个阶段：仅相机的 4D 控制渲染，随后是扩散阶段。扩散骨干来自锁定版本的 VideoX-Fun 子模块。更多架构内部细节仓库未记录。

## 运行时契约
