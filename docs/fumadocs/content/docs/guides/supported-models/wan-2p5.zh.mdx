Wan 2.5 API 是阿里巴巴通义万相 Wan 2.5 视频生成模型的 DashScope 托管接入点，记录文生视频与图生视频任务。与本 catalog 中可本地运行的开源 Wan 权重不同，本条目覆盖的是服务方托管的生成路径：请求发往阿里云 DashScope，成片以产物形式返回。别名 wan2.5、wan-2.5 同样解析到本条目。

## 用来做什么

要阿里云 DashScope 托管成片、而不是本地 [Wan2.1](/zh/docs/guides/supported-models/wan2.1) 权重时，用 Wan 2.5。文生视频走 prompt，图生视频走起始图；成片以 WorldFoundry 产物返回。

启动 `worldfoundry-eval run wan-2p5`，任务 profile 为 `text-to-video`。别名 `wan2.5`、`wan-2.5` 解析到这里。后续托管卡：[Wan 2.6 API](/zh/docs/guides/supported-models/wan-2p6)、[Wan 2.7 API](/zh/docs/guides/supported-models/wan-2p7)。

相关套件：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)、[Physics-IQ](/zh/docs/evaluation/benchmark-hub/physics-iq)。

## 运行时契约

本卡不钉本地 checkpoint、分辨率、帧数或步数——这些旋钮在 DashScope 请求里。记录任务：文生视频、图生视频。状态：**Runner parity pending**（托管路径，本地 runner 不适用）。自备服务方密钥。

## 在 WorldFoundry 中运行

不创建本地 GPU 环境。在 dashscope.aliyun.com 开通 DashScope key，然后启动 `worldfoundry-eval run wan-2p5`，任务 profile 为 `text-to-video`。费用、配额与内容政策以阿里云账号为准。
