Self-Forcing 弥合了自回归视频扩散的训练-推理差距：在训练时模拟推理过程——让每帧以自己先前生成的帧为条件——从而在单卡上实现实时流式文生视频（arXiv 2506.08009）。本 catalog 中官方仅推理运行时已内置树内；一致性待 Self-Forcing DMD checkpoint 与 Wan2.1 权重就位。

## 用来做什么

一条配方同时覆盖文生视频与图生视频时选 `self-forcing`：prompt 进、可选静帧、视频出。不必再拼两条上游 demo。

按论文，基于 Wan2.1 的因果学生在自生成滚动上做整体分布匹配训练，并用 KV 缓存实现流式。runner 在树内负责提示词/i2v 数据物化、Wan 权重软链、命令构造与输出加载（checkpoint： gdhe17/Self-Forcing）。该模型由Adobe 研究院 / 得克萨斯大学奥斯汀分校发布。

catalog 记录的任务包括 文生视频、图生视频、autoregressive-video-generation。别名包括 `Self-Forcing`、`selfforcing`、`self_forcing`。模态上，它接受文本、图像，输出视频。

记录的评测入口包括[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（流式文生视频的质量评测）。

## 运行时契约

可选 `prompt`、`interactions`、`fps`、`seed`、`num_output_frames`；产物 `self-forcing.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `SelfForcingPipeline`。

系列状态：**Runner 一致性待确认**。

`default` 记录默认值：seed=0。

默认 checkpoint 路径遵循 $\{WORLDFOUNDRY_CKPT_DIR\}/Self-Forcing 的官方 HF 布局——另行就位时请覆盖 checkpoint_path。 完整一致性需要 wan_models 兼容布局下的 Wan2.1 权重；benchmark 提示词列表需自行准备，并通过本地输入配置提供。
