X-WAM is a GPU-validated world-action model: one Wan 2.2 joint flow process predicts future RGB/depth, proprioception, and robot actions together. RoboCasa-SFT passed checkpoint-backed action and future-RGB inference; RoboTwin-SFT additionally matched the pinned official runner on one paired in-domain episode (Apache-2.0).

## Architecture

Built on Wan2.2-TI2V-5B: a joint flow model over visual futures and action streams. The official deployed policy uses asynchronous early stopping after 10 action steps and returns a 32-step action chunk; optional full world decoding continues to 50 steps. Both Hub repos are revision-pinned.

## Runtime contract

Stage the X-WAM checkpoint states plus the Wan2.2-TI2V-5B base. The runtime is self-contained in-tree and never imports an external X-WAM checkout; training, simulators, ZeroMQ services, Lightning, and DeepSpeed orchestration are excluded.

## Evaluation benchmarks

- [RoboCasa](/docs/evaluation/benchmark-hub/robocasa) — The RoboCasa-SFT checkpoint passed GPU inference; no closed-loop benchmark was run.
- [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) — The RoboTwin-SFT checkpoint matched the pinned official runner on one paired episode; no closed-loop benchmark was run.
- [EWMBench](/docs/evaluation/benchmark-hub/ewmbench) — Joint world-action prediction quality.

## Readiness and limitations

- Optional depth decoding remains unvalidated.
- The 38.9 GB checkpoint requires substantial local storage.
