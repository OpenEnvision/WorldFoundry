## What it is for

`x-wam-robocasa-sft` is the recorded world-action line. Start here to predict actions conditioned on world state.

Built on Wan2.2-TI2V-5B: a joint flow model over visual futures and action streams. The official deployed policy uses asynchronous early stopping after 10 action steps and returns a 32-step action chunk; optional full world decoding continues to 50 steps. Both Hub repos are revision-pinned.

Catalog tasks include wam, world action model, wam world action modeling, and robot policy. Catalog aliases include `x_wam`, `xwam`, and `X-WAM`. Documented modalities: image in, depth out. Also recorded: `x-wam-robotwin-sft`, `x-wam-pretrained`.

Recorded evaluation entry points include [RoboCasa](/docs/evaluation/benchmark-hub/robocasa) (The RoboCasa-SFT checkpoint passed GPU inference; no closed-loop benchmark was run), [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) (The RoboTwin-SFT checkpoint matched the pinned official runner on one paired episode; no closed-loop benchmark was run), [EWMBench](/docs/evaluation/benchmark-hub/ewmbench) (Joint world-action prediction quality).
