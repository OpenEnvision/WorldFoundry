InternRobotics 的 EventVLA 是长时程记忆 VLA：在 Qwen3-VL-4B 基座上增加事件头、时间锚点与原始关键帧图像记忆，使策略在长任务中记住已发生的事件。仓库记录 Apache-2.0 的 ganlinyang/EventVLA checkpoint 集合，默认策略为 RoboTwin-MeM 子目录。

## 用来做什么

用 `eventvla` 做本卡的视觉-语言-动作推理。这条配方用来启动已记录的策略 profile。

Qwen3-VL 编码馈入动作 token 收集与兼容 checkpoint 的 MLP 动作头；事件头与时间锚点维护情节结构，关键帧图像构成记忆。全部在树内进程内运行。该模型由上海人工智能实验室（InternRobotics）发布。

catalog 记录的任务包括 视觉-语言-动作（VLA）、VLA 动作预测、vla.long_horizon_memory。别名包括 `event-vla`、`eventvla-robotwin-mem`。

记录的评测入口包括[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（RoboTwin-MeM checkpoint 面向 RoboTwin 记忆任务）。

## 运行时契约

可选 `prompt`、`input_path`、`interactions`、`fps`、`timeout_seconds`；产物 `action_trace`、`eventvla_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `EventVLAPipeline`。

系列状态：**Runner 一致性待确认**。

在本地就位 EventVLA checkpoint（子目录 RoboTwin-MeM）与 Qwen3-VL-4B-Instruct 基座。 训练、数据集、模拟器、基准启动器与 WebSocket 传输均被排除。

发布的策略面向 RoboTwin 记忆任务；其他套件需微调。

必填 `image`、`prompt`；可选 `model_id`、`state`、`temporal_anchors`、`action_dim`、`action_horizon`；产物 `action_trace`、`eventvla_action_trace.json`。

默认子目录：`ganlinyang/EventVLA` 下的 **RoboTwin-MeM**。还记录了 `RMBench`。基座 VLM：`Qwen/Qwen3-VL-4B-Instruct`。RoboTwin-MeM 在 A100 Workspace 上完成了有限 **50×14** 开环块——这是数值验证，不是闭环分数。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run eventvla --pipeline.task-profile default`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch>=2.6.0）。

记录的权重仓库包括 `ganlinyang/EventVLA`、`Qwen/Qwen3-VL-4B-Instruct`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh eventvla`；下载缺失的公开权重时加 `--download`。

状态：**Runner 一致性待确认**。
