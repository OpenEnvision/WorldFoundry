Pusa VidGen (Pusa V1) demonstrates vectorized timestep adaptation: instead of one shared diffusion timestep for the whole video, each frame gets its own, which unlocks image-to-video, text-to-video, and video extension from one cheap LoRA training run on Wan2.2. WorldFoundry assembles it entirely from canonical Wan2.2 components — no external runtime checkout is needed at inference time.

## What it is for

`pusa-vidgen` is the recorded text/image-to-video line. Use it when you want both prompt and still conditioning on the same catalog card.

Pusa V1 = Wan2.2 base (canonical denoisers, conditioner, VAE, loaders, shared staged runner) + the official Pusa V1 LoRA checkpoint (RaphaelLiu/Pusa-Wan2.2-V1). The vectorized-timestep behavior comes from the LoRA; no alternate diffusion backend is involved. It is published by City University of Hong Kong.

Catalog tasks include image-to-video, text-to-video, and video-extension. Catalog aliases include `pusa-v1` and `pusa-wan2.2-v1`. Documented modalities: image and text in, video out.

Recorded evaluation entry points include [VBench](/docs/evaluation/benchmark-hub/vbench) (General T2V/I2V quality suite).
