DreamDojo predicts robot-view video from an initial image and normalized robot actions. WorldFoundry integrates the offline **2B GR-1 post-trained teacher** with a native action-conditioned Cosmos DiT, shared Reason1 text encoder, Wan video codec, and UniPC sampling. The separate [DreamDojo Student](./dreamdojo-student) route provides low-step distilled inference and resident normalized-action streaming.

## Runtime contract

Integration status: **Integrated**. The model is a robot world model, not an action-generating VLA policy.

Supply one initial image and already-normalized actions shaped `[N,384]` or `[1,N,384]`, where `N` is a positive multiple of 12. Each chunk generates 13 frames at 480×640 and 5 fps. Continuation uses the final generated frame as the next observation and removes duplicate boundary frames. Action files may be `.npy`, `.json`, or PyTorch tensors.

The unified action layout includes GR-1 `[0,58)`, G1 `[58,101)`, YAM `[101,147)`, AgiBot `[147,169)`, MANO `[220,352)`, and latent actions `[352,384)`. Dataset-specific normalization remains caller-owned.

## Running in WorldFoundry

Prepare the GR-1 EMA checkpoint, Cosmos-Predict2.5 video tokenizer, and Cosmos-Reason1-7B text encoder. The public loader automatically converts distributed checkpoint shards to `model_ema_bf16.pt` when needed.

```python
from worldfoundry.pipelines.component_pipelines import DreamDojoPipeline

pipeline = DreamDojoPipeline.from_pretrained(
    {
        "checkpoints_dir": "/weights/DreamDojo/2B_GR1_post-train",
        "vae_path": "/weights/Cosmos-Predict2.5-2B/tokenizer.pth",
        "text_encoder_path": "/weights/Cosmos-Reason1-7B",
    },
    device="cuda",
)
pipeline(
    images="/inputs/robot.png",
    interactions=["/inputs/normalized-actions.npy"],
    output_path="/outputs/dreamdojo.mp4",
    num_inference_steps=35,
    guidance_scale=7.0,
    seed=42,
)
```

For precomputed official Reason1 features, replace `text_encoder_path` with `text_embeddings_path`. Features must have shape `[1,S,100352]`; this uses actual supplied text embeddings rather than loading the text encoder.

The reproducible public-loader command is `python tests/manual/dreamdojo_inference.py --help`. Checkpoints, inputs, and generated videos remain external assets.

## Executed evidence

A checkpoint-backed public-loader smoke on H100 generated and exported 13 frames at 480×640 and 5 fps, with neutral normalized actions, 35 sampling steps, and seed 42. A two-chunk A/B/A replay generated 25 frames per request from 24 actions: repeated A pixels matched exactly, and changed actions changed the generated pixels.

## Limitations

- This teacher profile supports offline 2B GR-1 inference. Distilled inference uses the separate student route and explicit student weights. Other checkpoint scales remain unsupported.
- Official numerical parity, GR-1 evaluation quality, and robot-task success are not validated.
