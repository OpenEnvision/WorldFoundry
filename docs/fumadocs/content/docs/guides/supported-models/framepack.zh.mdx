FramePack 是斯坦福的**恒定记忆**长图生视频打包器（ControlNet 作者）：输入帧上下文被压进**定长**窗口，片段变长时生成成本大致不变，有限显存也能做分钟级视频。WorldFoundry 把最小化仅推理运行时放在 `worldfoundry/synthesis/visual_generation/framepack/framepack_runtime`，对外是 `FramePackPipeline`。**集成已验证**。**Runner 和官方长视频 demo 仍 pending**。

## 用来做什么

从起始图按下一帧块打包长视频。

启动 `worldfoundry-eval run framepack`。

评测入口：[ChronoMagic-Bench](/zh/docs/evaluation/benchmark-hub/chronomagic-bench)（长时程生成评测，契合 FramePack 的长视频定位）。

## 运行时契约

可选 `prompt`、`negative_prompt`、`input_path`、`frames`、`fps`；产物 `framepack.mp4`。

| 旋钮 | 默认 |
| --- | --- |
| 时长 | **5** 秒 |
| FPS | **30** |
| 步数 | 每个 FramePack 段 **25** |
| 潜窗口 | **9** |
| CFG / GS / RS | **1.0** / **10.0** / **0.0** |
| Seed | **31337** |
| TeaCache | **开** |
