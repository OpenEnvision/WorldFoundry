## What it is for

Use `depth-anything-v2-prior` for catalog geometry inference. Choose it when the artifact is a reconstruction, not a generated video.

It is published by TikTok / The University of Hong Kong.

Catalog tasks include monocular-depth-estimation, metric-depth-estimation, and geometry-prior. Catalog aliases include `dav2-prior` and `depth-anything-v2`. Documented modalities: image in, depth out.

## Runtime contract

Optional `input_path`, `model`, `execute`, `max_points`, and `focal_length`; artifacts `depth-anything-v2-prior.npz`.

CLI task profiles: `default`. WorldFoundry binds `DepthAnythingV2PriorPipeline`.

Family status: **Verified**.

It is integrated as an independent geometry prior under worldfoundry/base_models and exposed through the shared geometry-prior pipeline/operator contract. Higher-level pipelines (e.g. ViPE) import it from this canonical owner instead of keeping private copies. Runner parity is verified through the shared contract.

Integrated as an independent depth prior at worldfoundry/base_models/three_dimensions/depth/depth_anything/depth_anything_v2.

## Running in WorldFoundry

Launch `worldfoundry-eval run depth-anything-v2-prior --pipeline.task-profile default` to write geometry. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `depth-anything/Depth-Anything-V2-Large`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh depth-anything-v2-prior`. Add `--download` to fetch missing public checkpoints.

Status: **Verified**.
