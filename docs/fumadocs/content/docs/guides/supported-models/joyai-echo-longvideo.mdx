## What it is for

Use `joyai-echo-longvideo` for catalog text-to-video inference. The recipe exists so you can launch a recorded T2V profile without assembling an upstream demo.

The release builds on LTX-2.3 and adds few-step DMD generation plus a paired cross-modal memory bank. WorldFoundry keeps the official Python 3.11, PyTorch 2.8, CUDA 12.8 runtime external and communicates through the checked-in CLI contract. It is published by JD.com (JoyAI / Echo Team).

Catalog tasks include reference-to-video, audio-video-generation, and long-video-generation. Catalog aliases include `joyai-echo`, `echo-longvideo`, and `joyai-echo-1.5`. Documented modalities: image in, video out.

Recorded evaluation entry points include [ChronoMagic-Bench](/docs/evaluation/benchmark-hub/chronomagic-bench) (Long-horizon temporal continuity across generated shots), [VBench](/docs/evaluation/benchmark-hub/vbench) (Baseline video quality and motion evaluation).
