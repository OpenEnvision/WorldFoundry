StarVLA is a Lego-like modular VLA framework; this catalog entry is GPU-validated: the official QwenOFT predict_action ran on an 80GB CUDA GPU with the local Qwen3-VL-OFT-LIBERO-4in1 checkpoint and Qwen3-VL-4B base VLM. A WM4A world-action checkpoint (Wan2.2-based) is also staged with tensor/import probes but is not promoted by the policy run.

## Architecture

The validated path is QwenOFT: a Qwen3-VL-4B backbone with OFT-style parallel action decoding, fine-tuned on four LIBERO suites in one checkpoint (4in1). The WM4A variant couples the policy with a Wan2.2 world model and remains probe-level.

## Runtime contract

Use the QwenOFT 4in1 checkpoint for LIBERO evaluation; treat WM4A as staged-but-unvalidated. Stage the Qwen3-VL-4B-Instruct base alongside the policy checkpoint.

## Evaluation benchmarks

- [LIBERO](/docs/evaluation/benchmark-hub/libero) — The 4in1 checkpoint covers four LIBERO suites.

## Readiness and limitations

- The WM4A world-action route is not promoted; only QwenOFT is GPU-verified.
- No license is recorded for the QwenOFT checkpoint (WM4A is MIT).
