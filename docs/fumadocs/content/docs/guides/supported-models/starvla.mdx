## What it is for

Pick `starvla-qwen3-vl-oft-libero-4in1` when you want the catalog VLA policy: instruction and observation in, an action trace out. Use it to roll the recorded policy, not to train a new one.

The validated path is QwenOFT: a Qwen3-VL-4B backbone with OFT-style parallel action decoding, fine-tuned on four LIBERO suites in one checkpoint (4in1). The WM4A variant couples the policy with a Wan2.2 world model and remains probe-level.

Catalog tasks include vla, wam, vla policy rollout, and wam world action modeling. Catalog aliases include `Qwen3-VL-OFT-LIBERO-4in1` and `WM4A-Wan2d2-OFT-LIBERO-4in1`. Also recorded: `starvla-wm4a-wan2d2-oft-libero-4in1`.

Recorded evaluation entry points include [LIBERO](/docs/evaluation/benchmark-hub/libero) (The 4in1 checkpoint covers four LIBERO suites).
