Xiaomi-Robotics-1 是小米的下一代 VLA（Apache-2.0）：Qwen3-VL 策略 token 图配 rectified flow DiT 动作解码器，输出相对动作。锁定 revision 的公开仓库包含报告与发布公告；此处使用的推理源码快照已集成树内，checkpoint 就位于 WORLDFOUNDRY_CKPT_DIR。

## 用来做什么

用 `xiaomi-robotics-1` 做本卡的视觉-语言-动作推理。这条配方用来启动已记录的策略 profile。

Qwen3-VL 骨干产生策略 token，由 rectified-flow DiT 消费并解码相对动作；预处理与归一化提取内置树内。checkpoint 侧 Python 仅作为字面归一化元数据解析，绝不执行。该模型由小米机器人（Xiaomi Robotics）发布。

catalog 记录的任务包括 视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行、机器人策略。别名包括 `xr1`、`xiaomi-robotics-one`。

不是 [Xiaomi Robotics 0](/zh/docs/guides/supported-models/xiaomi-robotics-0)。

## 运行时契约

可选 `prompt`、`input_path`、`interactions`、`fps`、`timeout_seconds`；产物 `action_trace`、`xiaomi_robotics_1_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `XiaomiRobotics1Pipeline`。

系列状态：**Runner 一致性待确认**。

checkpoint 就位于 $\{WORLDFOUNDRY_CKPT_DIR\}/embodied_action/xiaomi-robotics-1。 模型、 processor、设备、dtype、注意力后端与 checkpoint 加载均仅本地。

公开仓库为预发布项目页；推理快照未在其中发布。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run xiaomi-robotics-1 --pipeline.task-profile default`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是独立 profile `worldfoundry-xiaomi-robotics-1-cu128`（Python 3.12，CUDA 12.8，torch==2.8.0）。

本卡片未记录公开 checkpoint id；按使用说明就位权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh xiaomi-robotics-1`；下载缺失的公开权重时加 `--download`。

状态：**Runner 一致性待确认**。
