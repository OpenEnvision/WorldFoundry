pi0.5 is Physical Intelligence's open-world generalization upgrade of pi0: a PaliGemma-based VLA with a flow-matching action expert. The independent `pi05` binding reuses WorldFoundry's in-tree OpenPI runtime and has generated actions with the official `pi05_libero` checkpoint.

## What it is for

Launch `worldfoundry-eval run pi05` with a staged `pi05_libero` checkpoint. A GPU run through this public binding produced finite 10×7 actions from synthetic dual-camera images and the checkpoint-mean state. This establishes action inference structure, not success on [LIBERO](/docs/evaluation/benchmark-hub/libero). Do not route this through LeRobot policy-zoo.

## Runtime contract

Required `image`, `instruction`, and `prompt`. `actions`: `robot_action`, `proprio`, `action_space`. Artifact: `pi05_action_trace.json`. Keep the official OpenPI runtime with the pi05-specific config.

## Running in WorldFoundry

Use an OpenPI environment with JAX GPU support and the package dependencies in `requirements/worldfoundry-unified.txt`. Stage `gs://openpi-assets` with gsutil or pass an explicit checkpoint path. License is on the [OpenPI](/docs/guides/supported-models/openpi) card (Apache-2.0). Status: **checkpoint-backed inference verified** for the `pi05_libero` configuration; task performance and the `pi05_base`/`pi05_droid` checkpoints are untested.

`pi05_libero` is the validated `get_action` reference. Import official LIBERO results with `worldfoundry-eval zoo benchmark-run --benchmark-id libero --mode official-validation` and read `success_rate`. Suite import is normalizer-only — not a leaderboard.
