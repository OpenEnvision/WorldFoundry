A1 (AffordVLA) is an affordance-guided vision-language-action policy: it grounds manipulation in visual affordances before predicting robot actions. WorldFoundry runs AffordVLA fully in-tree — Molmo and CLIP ViT encoders, L1/DiT/flow action heads, and preprocessing — with two confirmed checkpoints: spatialtemporal-ai/a1-libero for tasks and a1-pretrain as the pretrained policy.

## What it is for

Use `a1` for vision-language-action inference on this card. The recipe exists so you can launch the recorded policy profile.

The stack couples Molmo (VLM) and CLIP ViT visual encoding with selectable action heads (L1 regression, DiT, or flow). The runtime derives action dimensions from checkpoint tensors and validates every action-token boundary, so mismatched checkpoints fail fast.

Catalog tasks include vla, vla policy rollout, and robot policy. Catalog aliases include `affordvla-a1`, `spatialtemporal-ai/a1-libero`, and `spatialtemporal-ai/a1-pretrain`.

Recorded evaluation entry points include [LIBERO](/docs/evaluation/benchmark-hub/libero) (The a1-libero checkpoint targets LIBERO manipulation tasks).

## Runtime contract

Optional `prompt`, `input_path`, `interactions`, `fps`, and `timeout_seconds`; artifacts `action_trace` and `a1_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `A1Pipeline`.

Family status: **Runner parity pending**.

Stage tokenizer and checkpoint assets locally before running. Assets are local-only and checkpoint-provided Python is never executed; runtime loading uses strict key matching.

AffordVLA, Molmo, CLIP ViT, L1/DiT/flow action heads, preprocessing, and safe local checkpoint loading run in tree.

## Running in WorldFoundry

Launch `worldfoundry-eval run a1 --pipeline.task-profile default` to execute the policy. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the dedicated environment `worldfoundry-vla-a1` (Python 3.11, CUDA 12.8, torch>=2.8).

Recorded weight repositories include `spatialtemporal-ai/a1-libero` and `Qwen/Qwen2-7B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh a1`. Add `--download` to fetch missing public checkpoints.

Status: **Runner parity pending**.
