Prior Depth Anything 是深度补全先验：接受任意粗糙或稀疏的米制深度先验加一张图像，将其细化为致密且更锐利的米制深度图。本 catalog 中它已验证——Workspace 于 2026-07-11 加载官方 checkpoint，并对真实的 Depth Anything 3 米制深度条件完成了细化。

## 用来做什么

用 `prior-depth-anything` 做 catalog 几何推理。产物是重建而不是生成视频时选它。

catalog 记录其为提示条件的深度补全设计：模型同时消费提示米制深度与图像（checkpoint 为 Rain729/Prior-Depth-Anything，apache-2.0）。注册于 base_models/three_dimensions/depth/priorda，供上层几何管线共享而不嵌套于其下。

catalog 记录的任务包括 depth-completion、米制深度估计、几何先验。别名包括 `priorda`、`prior-depth-anything-prior`。模态上，它接受图像，输出深度。

## 运行时契约

可选 `input_path`、`prompt_depth_path`、`prior_depth_path`、`execute`、`max_points`；产物 `prior-depth-anything.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `PriorDepthAnythingPipeline`。

系列状态：**已验证**。

它作为独立几何先验集成在 worldfoundry/base_models 下，通过共享的 geometry-prior pipeline/operator 契约对外暴露。 上层管线（如 ViPE）从这一规范位置导入它，而不是各自保留私有副本。 请与米制深度源（如 depth-anything-v3-prior）配对使用，由它细化该源的输出。

需要米制深度条件作为输入——它细化先验而非从零估计。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run prior-depth-anything --pipeline.task-profile default`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。
