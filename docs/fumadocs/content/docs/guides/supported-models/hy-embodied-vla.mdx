**Publisher:** Tencent Hunyuan · Company

Hy-Embodied-0.5-VLA is Tencent Hunyuan's bimanual manipulation VLA, GPU-validated in this catalog: the RoboTwin checkpoint restored strictly and produced finite 20x20 decoded actions from the official six-frame, three-camera input on an A100, and the UMI checkpoint produced a finite 50x20 relative-action chunk in BF16. Both Apache-2.0 checkpoints are pinned on Hugging Face and ModelScope.

## Architecture

An inference-only mixture-of-transformers (MoT) backbone with in-tree preprocessing and action decoding. The official input contract is six frames from three cameras; RoboTwin decodes absolute joint actions while UMI decodes relative actions.

## Runtime contract

Choose the RoboTwin checkpoint for simulator benchmark work and the UMI checkpoint for UMI-style relative-action deployments; both run through the same in-tree runtime.

## Evaluation benchmarks

- [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) — GPU-validated RoboTwin policy checkpoint.

## Readiness and limitations

- Validation covers action decoding on A100; full benchmark rollout parity is tracked separately.
