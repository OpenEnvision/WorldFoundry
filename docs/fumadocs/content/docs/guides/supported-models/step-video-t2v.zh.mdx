## 架构

上游：30B DiT，配深压缩 Video-VAE（空间 16x16、时间 8x）与双语文本编码器。本仓库在进程内重装配原生 pipeline；原 xFuser 与 caption/VAE HTTP 服务运行时不再是后端。已验证使用真实权重的 204 帧 GPU 产物（一个受控提示词）。

## 运行时契约

已验证使用真实权重在 GPU 上以 992x544、50 步生成的 204 帧视频（一个受控提示词）。请使用 id step-video-t2v。30B 规模需要充足显存或多卡配置。
