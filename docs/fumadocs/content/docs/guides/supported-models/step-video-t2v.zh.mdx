## 用来做什么

需要本系列的文生视频时选 `step-video-t2v`：prompt 进、生成视频出。它是 catalog 上的 T2V 起步线，不是编辑器，也不是世界模型步进器。

上游：30B DiT，配深压缩 Video-VAE（空间 16x16、时间 8x）与双语文本编码器。本仓库在进程内重装配原生 pipeline；原 xFuser 与 caption/VAE HTTP 服务运行时不再是后端。已验证使用真实权重的 204 帧 GPU 产物（一个受控提示词）。

catalog 记录的任务包括 文生视频、视频生成。别名包括 `step-video`、`stepvideo-t2v`、`step_video_t2v`。模态上，它接受文本，输出视频。

记录的评测入口包括[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（标准开源文生视频质量评测）。
