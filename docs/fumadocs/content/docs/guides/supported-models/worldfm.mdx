## What it is for

`worldfm` is the recorded interactive world line. Start here when the job is stepping a world with actions.

Outputs cover both video and panorama artifacts, reflecting a world-generation design that renders beyond a single fixed viewport. Architecture internals beyond the official repository and checkpoint pointers are not recorded in this repository.

Catalog tasks include world, video, and world model. Documented outputs include video.

Recorded evaluation entry points include [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Unified world-generation quality for 3D world output).

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run worldfm --pipeline.task-profile official-meta-demo`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `inspatio/WorldFM`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh worldfm`. Add `--download` to fetch missing public checkpoints.
