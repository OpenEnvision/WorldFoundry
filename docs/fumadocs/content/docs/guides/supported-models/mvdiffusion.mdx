## What it is for

Pick `mvdiffusion` for feed-forward geometry: views in, reconstruction / trajectory / point cloud out. Use it when you need the catalog 3D route rather than a depth-only prior.

Per the NeurIPS 2023 paper (arXiv 2307.01097), parallel diffusion-model branches generate all views simultaneously with correspondence-aware attention keeping them globally consistent. Missing source checkout, checkpoints, or CUDA dependencies are reported at inference time. It is published by Simon Fraser University.

Catalog tasks include correspondence-aware multiview image generation and scene texturing. Catalog aliases include `MVDiffusion: Enabling Holistic Multi-view Image Generation`.

## Running in WorldFoundry

Launch `worldfoundry-eval run mvdiffusion --pipeline.task-profile default` to write geometry. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

No public checkpoint id is recorded on this card; follow the usage notes for staging. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh mvdiffusion`. Add `--download` to fetch missing public checkpoints.
