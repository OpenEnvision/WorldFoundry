GEN3C generates **camera-controlled** video with an explicit **3D cache**: it builds a rough 3D scene from the input image via depth, warps that cache along the requested camera path, then lets the video model fill in the rest. Catalog venue: **CVPR 2025**. WorldFoundry assembles it natively on the same denoiser, T5 conditioner, latent initializer, **Karras x0 AB2** scheduler, codec, and loader contracts as the Cosmos Predict1 family. Pipeline: `Gen3CPipeline`. There is **no** copied Cosmos Predict1 runtime and **no** external GEN3C checkout.

<ModelPaperFigures modelId="gen3c" locale="en" />

Named camera trajectories, **MoGe** depth, and RGBD forward warping live inside the latent-initializer role. Callers may also supply pre-rendered 3D-cache tensors. Transformer / T5 structure, native camera geometry, registry, and scheduler contracts pass local validation. **Full-resolution native GPU output parity remains pending** — earlier official-runtime demo evidence does **not** carry over to this native path.

Paper: [arXiv 2503.03751](https://arxiv.org/abs/2503.03751). Project: [research.nvidia.com/labs/toronto-ai/GEN3C](https://research.nvidia.com/labs/toronto-ai/GEN3C/). Code: [nv-tlabs/GEN3C](https://github.com/nv-tlabs/GEN3C) (**nvidia-source-code**). Weights: `nvidia/GEN3C-Cosmos-7B` plus `Ruicheng/moge-vitl`. Status: **Runner parity pending**.

## Runtime contract

Required: `prompt` and `image`; optional: `video`; `actions`: camera_trajectory; artifacts: `gen3c.mp4`.

| Knob | Default |
| --- | --- |

| Frames | **121** |
| FPS | **24** |
| Steps | **35** |
| Guidance | **1.0** |
| Trajectory | `left`, `center_facing`, distance **0.3** |
| Seed | **1** |
