## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run veo3 --pipeline.task-profile default`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

The environment profile is not recorded.

Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh veo3`. Add `--download` to fetch missing public checkpoints.
