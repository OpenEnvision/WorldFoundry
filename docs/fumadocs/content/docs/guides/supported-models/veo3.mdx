Veo3 is the catalog entry for Google DeepMind's Veo 3 hosted video model, recorded for text-to-video and image-to-video. WorldFoundry submits generation requests through Google's API and collects the rendered clips as artifacts, so Veo 3 results can be lined up against open models in the same evaluation harness. The model itself never leaves Google's infrastructure.

## Architecture

This is a hosted, provider-operated model: the vendor has not published its architecture, parameter count, or training recipe, and this repository does not record them. What WorldFoundry records is the integration surface only — a Studio pipeline that submits requests to the provider endpoint and collects the returned video artifacts.

## Runtime contract

The catalog marks this entry as integrated: the hosted-API Studio pipeline is available, but you must supply your own provider API key and account. No weights are downloaded and no GPU environment is provisioned locally — generation happens on the provider side, so cost, quota, and content policy follow your provider account. Veo access is provisioned through Google's AI developer offerings (e.g. the Gemini API); regional availability applies.

## Readiness and limitations

- Requires a paid provider account and API key; WorldFoundry does not ship credentials.
- The provider controls model versioning, so outputs can change over time without any change in this repository — the manifest records runner parity as not applicable for this reason.
- No local weights, no offline mode, and no reproducibility pinning beyond the request parameters WorldFoundry stores.
