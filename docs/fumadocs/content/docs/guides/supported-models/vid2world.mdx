## What it is for

`vid2world` is the recorded interactive world line. Start here when the job is stepping a world with actions.

The core idea recorded here is video-diffusion adaptation: converting a full-sequence diffusion model to causal, action-conditioned rollout. Architecture internals beyond the official repository pointer (thuml/Vid2World, pinned head ae24077a) are not recorded in this repository. It is published by Tsinghua University (THUML).

Catalog tasks include interactive-world-model, video-diffusion-adaptation, and action-conditioned-video.

Recorded evaluation entry points include [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Action-conditioned interactive rollout quality).
