## 架构

按论文，相机运动控制模块以相机位姿序列为条件、物体运动控制模块以轨迹为条件，挂接在 LVDM 系视频基座上。WorldFoundry 将 LVDM 栈、控制模块、采样器、默认配置与运动 fixture 内置于 synthesis/visual_generation/motionctrl/motionctrl_runtime 并在进程内加载。

## 运行时契约
