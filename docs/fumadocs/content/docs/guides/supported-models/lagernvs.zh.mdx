## 用来做什么

用 `lagernvs` 做 catalog 几何推理。产物是重建而不是生成视频时选它。

catalog 记录其为 512 分辨率的新视角/相机路径渲染模型；内部细节仓库未记录。许可为 FAIR 非商用研究许可。该模型由Meta AI（FAIR）发布。

catalog 记录的任务包括 新视角合成、3d-scene-rendering、camera-path-rendering。别名包括 `lager-nvs`、`facebook/lagernvs_general_512`、`facebookresearch/lagernvs`。

## 运行时契约

可选 `input_path`、`frames`、`fps`、`model_repo`、`python_executable`；产物 `generated_video`、`lagernvs.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `LagrNVSPipeline`。

系列状态：**Runner 一致性待确认**。

`default` 记录默认值：frames=16, fps=25。

运行前请先接受 gated 条款并设置 HF_TOKEN。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run lagernvs --pipeline.task-profile default` 写出几何。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `facebook/lagernvs_general_512`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh lagernvs`；下载缺失的公开权重时加 `--download`。

gated `facebook/lagernvs_general_512`，下载前需在上游接受条款；状态：**Runner 一致性待确认**。
