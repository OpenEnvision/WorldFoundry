## What it is for

`worldlabs-marble-1.1` is the recorded interactive world line. Start here when the job is stepping a world with actions.

Closed API service: no architecture details are recorded in this repository. The recorded official sources are the release notes and the API endpoint.

Catalog tasks include world-generation, 3d-world-generation, and api-world-model. Catalog aliases include `marble-1.1` and `worldlab-marble-1.1`.

Recorded evaluation entry points include [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Explorable 3D world generation quality).

Not [World Labs](/docs/guides/supported-models/worldlabs). Score on [WorldScore](/docs/evaluation/benchmark-hub/worldscore).

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run worldlabs-marble-1.1 --pipeline.task-profile default`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh worldlabs-marble-1.1`. Add `--download` to fetch missing public checkpoints.

Status: **Planned**.
