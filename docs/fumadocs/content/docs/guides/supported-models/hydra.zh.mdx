HyDRA 是相机可控的视频到视频世界模型：按 camera JSON 描述的新相机行为重新渲染输入视频。固定版本的运行时用官方样例和 50 步推理生成了连贯的 77 帧续写；另一个合成相机案例出现遮挡。

## 用来做什么

用 `hydra` 做相机条件视频推理。配方绑定了已记录的相机控制 profile。

架构内部细节仓库未记录。固定的公开 revision 无 LICENSE 文件，下游使用前必须先做许可审查。

catalog 记录的任务包括 相机可控视频、视频到视频、世界模型。别名包括 `h-embodvis-hydra`。模态上，它接受视频，输出视频。

记录的评测入口包括[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（重渲染视频的相机行为贴合度）。

## 运行时契约

可选 `prompt`、`input_path`、`frames`、`fps`、`height`；产物 `hydra.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `HydraPipeline`。

系列状态：**已验证**。

`default` 记录默认值：frames=77, fps=15, height=480, width=832, seed=42。

必须使用内置源码——外部源码检出会被拒绝。 输入为提示词、视频与 camera_json。 官方样例 50 步推理已完成；合成轨迹下的画质仍需检查。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run hydra --pipeline.task-profile default` 跟随相机路径。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `H-EmbodVis/HyDRA`、`Wan-AI/Wan2.1-T2V-1.3B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hydra`；下载缺失的公开权重时加 `--download`。
