IRASim（交互式真实机器人动作模拟器）从初始帧加动作轨迹生成逼真的机械臂视频——机器人数据的学习型模拟器。本 catalog 中其模型、扩散与推理 pipeline 模块已内置树内；真实生成待手动就位官方 checkpoint 归档。

## 用来做什么

需要动作条件世界步进时选 `irasim`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

按上游发布，DiT 视频扩散模型以逐帧动作 token 为条件，生成轨迹精确的机器人视频。打包在 synthesis/visual_generation/irasim/irasim_runtime 的运行时已裁剪训练数据加载器、评估脚本与交互 demo。该模型由字节跳动发布。

catalog 记录的任务包括 机器人世界模型、视频生成、action-conditioned-generation。别名包括 `ira-sim`、`ira_sim`。输出模态为视频。

记录的评测入口包括[EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench)（具身世界模型视频预测质量）。
