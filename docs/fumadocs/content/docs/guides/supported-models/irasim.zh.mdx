## 架构

按上游发布，DiT 视频扩散模型以逐帧动作 token 为条件，生成轨迹精确的机器人视频。打包在 synthesis/visual_generation/irasim/irasim_runtime 的运行时已裁剪训练数据加载器、评估脚本与交互 demo。

## 运行时契约

发布的 checkpoint 归档不是当前下载器支持的 HF 模型仓库——期望得到真实视频前请手动提供 checkpoint 与任务 fixture。
