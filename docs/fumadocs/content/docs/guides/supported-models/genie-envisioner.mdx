Genie Envisioner is AgiBot's robotics world model platform: a video-generative backbone that predicts action-conditioned robot manipulation futures, usable for policy learning and evaluation. In this catalog the official WorldArena-listed source is vendored in-tree; execution waits on the Genie-Envisioner and LTX-Video checkpoints plus robot task assets.

The compatibility launcher runs the released **GE-base** multiview transformer with local LTX tokenizer, T5, and VAE. For the official history input, pass `input_views` as a JSON list of three camera directories in `head` / `left-wrist` / `right-wrist` order; each directory must contain `0.png` through `3.png`. The three default ALOHA still images are repeated across the four history slots, so they are smoke inputs only. The synthetic-three-view path is also smoke-only. The published GE-base-fast video sample has been reproduced with four-frame histories; checkpoint-matched AgiBot or LeRobot trajectories are still required for action-quality parity.

## What it is for

Use `genie-envisioner` for three-view robot video prediction from camera history and a text prompt. This GE-base video launcher does not consume action arrays; action-conditioned policy variants need separate integration.

The recorded checkpoints reveal an LTX-Video-based video backbone (Lightricks/LTX-Video) with AgiBot's own world-model weights (agibot-world/Genie-Envisioner). The runtime is vendored under synthesis/visual_generation/genie_envisioner/genie_envisioner_runtime.

Catalog tasks include robotics-world-model, image-to-video, action-conditioned-video, and robot-multiview-video; the integrated GE-base video path covers history-and-text-conditioned generation only. Catalog aliases include `genie_envisioner`, `genieenvisioner`, and `genie-envisioner-sim`. Documented modalities: camera images and text in, video out.

Recorded evaluation entry points include [WorldArena](/docs/evaluation/benchmark-hub/worldarena) (The entry is listed on WorldArena for robot world-model evaluation), [EWMBench](/docs/evaluation/benchmark-hub/ewmbench) (Embodied world-model video prediction quality).

## Runtime contract

Required `prompt` and `input_views` for official-style history inference; pass three directories with four numbered PNG frames each. Set `input_mode` to `explicit-three-view` (the default). Three individual image paths or one image in `synthetic-three-view` mode exercise only smoke paths. Artifact: `genie-envisioner.mp4`.

CLI task profiles: `robot-multiview-video`. WorldFoundry binds `GenieEnvisionerPipeline`.

The published GE-base-fast `sample_0` configuration has passed real GPU inference and video comparison. Other configurations and action-quality parity remain pending.

Recorded `robot-multiview-video` smoke defaults: height=192, width=256, num_inference_steps=5, guidance_scale=1.0, fps=8, seed=42. The published GE-base-fast sample uses 50 steps and 5 fps.

The pipeline resolves the vendored inference entrypoint and returns blocked runtime diagnostics until checkpoints and task assets are staged. Stage both recorded checkpoint sets before submitting jobs.

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run genie-envisioner --pipeline.task-profile robot-multiview-video`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `agibot-world/Genie-Envisioner` and `Lightricks/LTX-Video`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh genie-envisioner`. Add `--download` to fetch missing public checkpoints.
