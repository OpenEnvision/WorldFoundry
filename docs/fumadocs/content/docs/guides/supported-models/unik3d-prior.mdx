UniK3D generalizes metric 3D estimation to any camera — pinhole, fisheye, even full panoramas — with one model. In this catalog it is a checkpoint-verified universal-camera geometry prior: real checkpoint inference is verified through the shared contract with automatic camera estimation, while pinhole and panorama overrides stay explicit.

## What it is for

Pick `unik3d-prior` for feed-forward geometry: views in, reconstruction / trajectory / point cloud out. Use it when you need the catalog 3D route rather than a depth-only prior.

Per the upstream publication, UniK3D represents the camera with a learned spherical-basis model, decoupling ray directions from radial depth so that no distortion-specific tuning is needed. The default checkpoint resolves from lpiccinelli/unik3d-vitl; registered at base_models/three_dimensions/depth/unik3d. It is published by ETH Zurich.

Catalog tasks include panoramic-depth-estimation, metric-3d-estimation, monocular-depth-estimation, and geometry-prior. Catalog aliases include `unik3d` and `unik3d-vitl`. Documented modalities: image in, depth out.
