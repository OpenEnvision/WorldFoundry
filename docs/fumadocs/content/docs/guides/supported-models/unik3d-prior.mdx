UniK3D generalizes metric 3D estimation to any camera — pinhole, fisheye, even full panoramas — with one model. In this catalog it is a checkpoint-verified universal-camera geometry prior: real checkpoint inference is verified through the shared contract with automatic camera estimation, while pinhole and panorama overrides stay explicit.

## Architecture

Per the upstream publication, UniK3D represents the camera with a learned spherical-basis model, decoupling ray directions from radial depth so that no distortion-specific tuning is needed. The default checkpoint resolves from lpiccinelli/unik3d-vitl; registered at base_models/three_dimensions/depth/unik3d.

## Runtime contract

It is integrated as an independent geometry prior under worldfoundry/base_models and exposed through the shared geometry-prior pipeline/operator contract. Higher-level pipelines (e.g. ViPE) import it from this canonical owner instead of keeping private copies. Prefer it over pinhole-only priors when inputs include fisheye or panoramic imagery. The upstream release is CC-BY-NC-4.0.
