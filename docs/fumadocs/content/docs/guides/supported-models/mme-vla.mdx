## What it is for

Pick `perceptual-framesamp-modul` when you want the catalog VLA policy: instruction and observation in, an action trace out. Use it to roll the recorded policy, not to train a new one.

The recorded design combines a perceptual frame-sampling module with policy learning and an optional VLM subgoal predictor. Resolver, runtime import, and compileall checks pass without an external checkout; further internals are not recorded in this repository.

Catalog tasks include vla, vla action prediction, vla policy rollout, and embodied benchmark. Catalog aliases include `mme_vla`, `robomme-policy-learning`, and `perceptual-framesamp-modul`.

Recorded evaluation entry points include [RoboMME](/docs/evaluation/benchmark-hub/robomme) (Native benchmark of the RoboMME project).

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run perceptual-framesamp-modul --pipeline.task-profile default`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch==2.7.1).

Recorded weight repositories include `Yinpei/perceptual-framesamp-modul`, `Yinpei/mme_vla_suite`, and `Yinpei/pi05_baseline` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh perceptual-framesamp-modul`. Add `--download` to fetch missing public checkpoints.

Recorded licenses include apache-2.0; status: **Static load only**.
