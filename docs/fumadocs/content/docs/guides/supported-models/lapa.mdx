LAPA (Latent Action Pretraining) learns actions without action labels: it pretrains a video-action model on unlabeled video by discovering latent actions, then transfers to real robot control. The MIT-licensed LAPA-7B-openx checkpoint is confirmed and pinned; WorldFoundry vendors the latent-action inference runtime in-tree.

## What it is for

Pick `lapa-7b-openx` when you want the catalog VLA policy: instruction and observation in, an action trace out. Use it to roll the recorded policy, not to train a new one.

A 7B video-action model trained on Open X-Embodiment scale data with latent action quantization. The in-tree runtime passed py_compile, from_pretrained, plan-only execution, and alias validation.

Catalog tasks include va, vam, latent action, and video action modeling. Catalog aliases include `LAPA` and `LAPA-7B-openx`.

## Runtime contract

Optional `prompt`, `input_path`, `interactions`, `fps`, and `seed`; artifacts `lapa_action_tokens.json`.

CLI task profiles: `interactive-video`. WorldFoundry binds `LAPAPipeline`.

Family status: **Runner parity pending**.

Recorded `interactive-video` defaults: seed=1234.

Real 7B inference is currently blocked by environment issues: the prepare environment lacks tux and the gpu-jax0325 environment has incompatible JAX. Plan-only execution works; full inference needs a compatible JAX environment.

## Running in WorldFoundry

Launch `worldfoundry-eval run lapa-7b-openx --pipeline.task-profile interactive-video` to execute the policy. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the dedicated environment `worldfoundry-lapa-jax-cu118` (Python 3.10, CUDA 11.8).

Recorded weight repositories include `latent-action-pretraining/LAPA-7B-openx`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lapa-7b-openx`. Add `--download` to fetch missing public checkpoints.

Recorded licenses include mit; status: **Runner parity pending**.
