H-RDT (Human-to-Robotics Diffusion Transformer) pretrains a diffusion-transformer policy on large-scale human manipulation data before robot fine-tuning (paper: arXiv 2506.23503, MPL-2.0). The official release is the 48-dimensional human-motion pretraining checkpoint (embodiedfoundation/H-RDT); WorldFoundry keeps the transformer, flow-matching sampler, DINOv2+SigLIP vision path, and optional T5 language path in-tree.

## What it is for

Use `h-rdt` for vision-language-action inference on this card. The recipe exists so you can launch the recorded policy profile.

A diffusion transformer with flow-matching sampling; vision uses DINOv2 plus SigLIP and language optionally uses T5. Module and parameter names preserve the official checkpoint contract with strict restoration.

Catalog tasks include vla, human motion policy, vla policy rollout, and robot policy finetune. Catalog aliases include `h_rdt` and `embodiedfoundation/h-rdt`.

## Runtime contract

Optional `prompt`, `input_path`, `interactions`, `fps`, and `timeout_seconds`; artifacts `action_trace` and `h_rdt_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `HRDTSynthesis`.

Family status: **Static load only**.

The transformer, flow-matching sampler, DINOv2 plus SigLIP vision path, and optional T5 language path are in-tree.

Runtime code never imports a source checkout or executes checkpoint-provided Python.

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run h-rdt --pipeline.task-profile default`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the dedicated environment `worldfoundry-vla-h-rdt` (Python 3.10, Cu121 Or Newer, torch>=2.2).

Recorded weight repositories include `embodiedfoundation/H-RDT` and `google/t5-v1_1-xxl`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh h-rdt`. Add `--download` to fetch missing public checkpoints.

Status: **Static load only**.
