## 用来做什么

需要动作条件世界步进时选 `hunyuanworld-mirror`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

WorldFoundry 通过树内 HunyuanMirrorPipeline 与内置的仅推理 WorldMirror 模型代码执行推理；官方仓库仅作一致性核对的溯源，不是运行时依赖。第三方包（onnxruntime、pycolmap、open3d、gsplat）是环境依赖，不是 catalog 阻塞。该模型由腾讯（混元）发布。

catalog 记录的任务包括 three_dimension。别名包括 `hunyuan-mirror`、`hy-world-mirror`。

## 运行时契约

可选 `input_path`、`confidence_percentile`、`edge_normal_threshold`、`edge_depth_threshold`、`apply_confidence_mask`；产物 `hunyuan_mirror_outputs.zip`。

CLI task profile：`default`。绑定的 pipeline 类是 `HunyuanMirrorPipeline`。

系列状态：**已验证**。

HunyuanMirrorPipeline 接受标准 pipeline runner 传入的 image、input、images 或 image_path 负载，并把重建产物写入样例输出目录。 真实推理需要配置好的 Python 环境、本地 checkpoint 与 GPU 兼容的 torch/gsplat。

运行环境需要 GPU 兼容的 torch/gsplat 包。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run hunyuanworld-mirror --pipeline.task-profile default` 推进世界。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `tencent/HunyuanWorld-Mirror`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hunyuanworld-mirror`；下载缺失的公开权重时加 `--download`。
