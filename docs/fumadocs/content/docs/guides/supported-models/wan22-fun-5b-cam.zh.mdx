Wan2.2-Fun 5B Control Camera 将 VideoX-Fun 相机控制通路带入 Wan2.2 世代的 5B 规模：由显式相机位姿操控的图生视频，上游原生规格为 121 帧、24 FPS。WorldFoundry 将 VideoX-Fun 内置树内（revision 403f1f7b），并为 alibaba-pai/Wan2.2-Fun-5B-Control-Camera 接通专用路由，Apache-2.0 许可。

## 用来做什么

用 `wan22-fun-5b-cam` 做相机条件视频推理。配方绑定了已记录的相机控制 profile。

5B 参数的 Wan2.2 扩散 Transformer，叠加 VideoX-Fun Control-Camera 条件通路。更多内部细节仓库未记录。该模型由阿里云 PAI（VideoX-Fun）发布。

catalog 记录的任务包括 相机可控视频、图生视频。模态上，它接受图像，输出视频。

记录的评测入口包括[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（受控图生视频的相机位姿跟随）、[WRBench](/zh/docs/evaluation/benchmark-hub/wrbench)（原生 121 帧/24FPS 规格适配 WRBench 式请求）。

不是 [Wan2.2](/zh/docs/guides/supported-models/wan2.2)、[Wan2.2 Fun A14B Cam](/zh/docs/guides/supported-models/wan22-fun-a14b-cam)。 评测看 [CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)、[WRBench](/zh/docs/evaluation/benchmark-hub/wrbench)。

## 运行时契约

可选 `prompt`、`input_path`、`frames`、`fps`、`height`；产物 `wan22-fun-5b-cam.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `Wan22Fun5BCameraPipeline`。

系列状态：**Runner 一致性待确认**。

上游原生规格为 121 帧、24 FPS；WRBench 请求值保持显式，请主动设置帧数与 FPS 而非依赖默认。 runner parity 仍为 pending。

VideoX-Fun source is vendored at revision 403f1f7b78dcafccc4f6606dda4ec28e16e667dc.

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run wan22-fun-5b-cam --pipeline.task-profile default` 跟随相机路径。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `alibaba-pai/Wan2.2-Fun-5B-Control-Camera`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh wan22-fun-5b-cam`；下载缺失的公开权重时加 `--download`。

状态：**Runner 一致性待确认**。
