## 用来做什么

需要相机可控视频时选 `magicworld`：相机轨迹进、受控视频出。视角必须跟随路径时，用它而不是无约束 T2V。

除已记录任务外的架构内部细节仓库未存。注意分离的许可：代码为 apache-2.0，而上游 README 对发布的模型材料适用 CC BY-NC-SA 4.0 条款。该模型由vivo（影像研究团队）发布。

catalog 记录的任务包括 交互式世界模型、相机可控视频、图生视频。模态上，它接受图像，输出视频。

记录的评测入口包括[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（交互滚动生成的相机控制贴合度）。
