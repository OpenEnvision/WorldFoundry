DynamiCrafter animates an open-domain still: picture (plus optional prompt) in, a plausible motion clip out. It is a U-Net-era latent video diffusion with **dual-stream** image conditioning (CLIP image features + VAE latents). WorldFoundry wraps two resolution profiles as in-tree runtimes. Default pipeline: `DynamiCrafter512I2VPipeline`. Variants: `dynamicrafter-512-i2v`, `dynamicrafter-1024-i2v`.

<ModelPaperFigures modelId="dynamicrafter" locale="en" />

Paper: [arXiv 2310.12190](https://arxiv.org/abs/2310.12190). Project: [doubiiu.github.io/projects/DynamiCrafter](https://doubiiu.github.io/projects/DynamiCrafter/). Publisher: Tencent AI Lab / CUHK. Catalog license unset; the manifest **gates redistribution** until upstream license review.

Both variants are wired; **official long-config parity is pending**. Start at 512 for speed, 1024 for finals. It invents motion — it does **not** follow camera paths or actions.
