## 架构

按 NeurIPS 2023 论文（arXiv 2307.01097），多个并行扩散分支借助「对应感知注意力」同时生成所有视图并保持全局一致。源码、checkpoint 或 CUDA 依赖缺失会在推理时报告。

## 运行时契约

已验证的图像扩展路线需要一张输入图像，默认产物为全景 PNG；可选旋转视频和完整上游一致性尚未验证。

## 就绪状态与限制

- 各视角生成的墙面和物体可能明显偏离输入场景。
- 可选旋转视频与上游 checkpoint 摘要尚未验证。
- 训练面向全景场景：自由相机轨迹不在其范围内。
