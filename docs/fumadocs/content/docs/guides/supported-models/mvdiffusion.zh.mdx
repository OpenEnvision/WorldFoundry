## 用来做什么

做前馈几何时选 `mvdiffusion`：视图进、重建/轨迹/点云出。需要 catalog 的 3D 路由、而不是仅深度先验时用它。

按 NeurIPS 2023 论文（arXiv 2307.01097），多个并行扩散分支借助「对应感知注意力」同时生成所有视图并保持全局一致。源码、checkpoint 或 CUDA 依赖缺失会在推理时报告。该模型由西蒙菲莎大学（Simon Fraser University）发布。

catalog 记录的任务包括 correspondence-aware multiview image generation and scene texturing。别名包括 `MVDiffusion: Enabling Holistic Multi-view Image Generation`。

## 运行时契约

可选 `prompt`、`input_path`、`steps`、`text_path`、`gen_video`；产物 `generated_image`、`mvdiffusion.png`。

CLI task profile：`default`。绑定的 pipeline 类是 `MVDiffusionPipeline`。

系列状态：**Runner 一致性待确认**。

已验证的图像扩展路线需要一张输入图像，默认产物为全景 PNG；可选旋转视频和完整上游一致性尚未验证。

各视角生成的墙面和物体可能明显偏离输入场景。
