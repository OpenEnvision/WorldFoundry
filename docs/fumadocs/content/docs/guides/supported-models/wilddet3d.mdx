## What it is for

Pick `wilddet3d` when you need an action-conditioned world stepper: recorded actions and a frame in, a rollout out. Use it for interactive world inference, not a text-to-video prompt dump.

This is a perception entry, not a video generator. The official model combines SAM3 image features and LingBot-Depth geometry; upstream source and submodules are loaded from a pinned external checkout. It is published by Allen Institute for AI (AI2).

Catalog tasks include 3d-detection, wild-3d-perception, and world-understanding.

## Running in WorldFoundry

Launch `worldfoundry-eval run wilddet3d --pipeline.task-profile default` to step the world. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `allenai/WildDet3D` and `robbyant/lingbot-depth-postrain-dc-vitl14`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh wilddet3d`. Add `--download` to fetch missing public checkpoints.
