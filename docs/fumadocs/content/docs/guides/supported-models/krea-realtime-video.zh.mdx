## 用来做什么

在 WorldFoundry 里用 `krea-realtime-video` 做 catalog 文生视频推理。这条配方让你按已记录的 T2V profile 启动，而不用自己拼上游 demo。

上游将其描述为面向实时块式生成蒸馏的 14B 自回归/流式视频模型（权重在 krea/krea-realtime-video，apache-2.0）。本仓库记录了基于块的生成控制（num_blocks）与 prompt/video 输入契约；更深的内部细节仓库未记录。

catalog 记录的任务包括 realtime-video-generation、文生视频、视频到视频、streaming-video。别名包括 `krea-rt-14b`。模态上，它接受文本、视频，输出视频。

记录的评测入口包括[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（流式文生视频输出的基础质量检查）。

## 运行时契约

可选 `prompt`、`negative_prompt`、`frames`、`fps`、`height`；产物 `krea-realtime-video.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `KreaRealtimeVideoPipeline`。

系列状态：**Runner 一致性待确认**。

`interactive-video` 记录默认值：fps=16, height=480, width=832, seed=42。

实时吞吐高度依赖你的 GPU——14B 规模要达到真正实时帧率需要数据中心级硬件。
