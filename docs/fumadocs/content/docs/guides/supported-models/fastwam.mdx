FastWAM is a GPU-validated world-action model built on the Wan video stack: a mixture-of-transformers (MoT) action-inference graph rides on Wan2.1-T2V-1.3B components. Both official LIBERO and RoboTwin checkpoint variants passed real A100 workspace inference with finite 32-step action chunks using their official camera/state contracts — the catalog status is Verified (MIT license).

## What it is for

Use `fastwam` for vision-language-action inference on this card. The recipe exists so you can launch the recorded policy profile.

The released MoT action-inference graph, Wan VAE, UMT5 encoder, scheduler, preprocessing, and normalization all live in-tree. Runtime execution never imports an adjacent FastWAM source checkout and never enables remote checkpoint code.

Catalog tasks include wam, robot policy, policy rollout, and embodied benchmark.

Recorded evaluation entry points include [LIBERO](/docs/evaluation/benchmark-hub/libero) (GPU-validated LIBERO checkpoint variant), [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) (GPU-validated RoboTwin checkpoint variant).

## Runtime contract

Optional `prompt`, `input_path`, `steps`, `seed`, and `state`; artifacts `action_trace` and `fastwam_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `FastWAMPipeline`.

Family status: **Verified**.

Both LIBERO and RoboTwin variants are declared in the runtime data configuration — pick per benchmark. Stage yuanty/fastwam plus the Wan-series converted safetensors and Wan2.1-T2V-1.3B base locally.

WorldFoundry contains the released MoT action-inference graph, Wan VAE, UMT5 encoder, scheduler, preprocessing, and normalization code.

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run fastwam --pipeline.task-profile default`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the dedicated environment `worldfoundry-vla-fastwam` (Python 3.10, Cu121 Or Newer, torch>=2.2).

Recorded weight repositories include `yuanty/fastwam`, `DiffSynth-Studio/Wan-Series-Converted-Safetensors`, and `Wan-AI/Wan2.1-T2V-1.3B` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh fastwam`. Add `--download` to fetch missing public checkpoints.

Status: **Verified**.
