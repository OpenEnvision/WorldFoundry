Mem-0 ("Memory Matters") is a memory-augmented manipulation policy from the RoboTwin RMBench line: an episodic memory bank lets the policy execute multi-task sequences that depend on what happened earlier. The confirmed qiuly/Mem-0-m1mix-RMBench checkpoint targets the published M1 multi-task execution setting; the full runtime is in-tree and statically verified.

## What it is for

`mem-0` is the recorded instruction-to-action line. Start here when you need a WorldFoundry VLA rollout rather than a video generator.

The in-tree runtime contains the episodic memory bank, a Qwen feature path, a task classifier, and a flow-matching action decoder. Output matches the official 14-value dual-arm joint adapter, excluding the two model-only padding channels.

Catalog tasks include vla, vla policy rollout, robot policy, and memory policy. Catalog aliases include `mem0` and `memorymatters`.

Recorded evaluation entry points include [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) (Built on the RoboTwin platform's RMBench memory tasks).

## Runtime contract

Optional `prompt`, `input_path`, `interactions`, `fps`, and `timeout_seconds`; artifacts `action_trace` and `mem-0_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `Mem0Pipeline`.

Family status: **Static load only**.

This entry targets the M1 multi-task execution checkpoint and does not require the high-level planning server. The published checkpoint is byte-split — the runtime reads its contiguous parts directly without assembling another copy.

The in-tree runtime contains the episodic memory bank, Qwen feature path, classifier, and flow-matching action decoder.

The official execution checkpoint is stored as nine byte-split parts. The in-tree runtime exposes them as one seekable stream without materializing a second 15.3 GB file.

## Running in WorldFoundry

Launch `worldfoundry-eval run mem-0 --pipeline.task-profile default` to execute the policy. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the dedicated environment `worldfoundry-vla-mem-0` (Python 3.11, Cu124 Or Newer, torch>=2.6).

Recorded weight repositories include `qiuly/Mem-0-m1mix-RMBench` and `Qwen/Qwen3-VL-2B-Instruct`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh mem-0`. Add `--download` to fetch missing public checkpoints.

Status: **Static load only**.
