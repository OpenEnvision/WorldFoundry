Luma Ray2 是 Luma AI 的托管视频生成模型，catalog 记录其文生视频与图生视频能力。 WorldFoundry 的 Studio pipeline 封装了 Luma API：一条提示词或一帧起始图，最终以标准 WorldFoundry 结果目录中的可下载视频呈现。模型本身完全不在本地运行；该条目承担的是托管路径的记录与管道工作。
