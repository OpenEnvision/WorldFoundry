FantasyWorld 通过统一视频与 3D 预测实现几何一致的世界建模：从一张图生成相机可控、几何连贯的世界视频。记录两个 variant——已验证的 Wan2.1 pipeline（面向发布的默认路径），以及在官方显存策略验证前对 Studio 隐藏的 Wan2.2 pipeline。

## 用来做什么

用 `fantasyworld-wan21` 做 catalog 世界模型推理。需要动作条件未来帧、而不是独立片段生成器时选它。

FantasyWorld 在 Wan 视频基座上增加统一的 3D 预测分支，使生成帧遵守场景几何（见 arXiv 2509.21657）。运行需要本地 FantasyWorld Wan2.1、Wan2.1 I2V、MoGe 与 CUDA 资产。该模型由阿里巴巴（高德 Fantasy-AMAP 团队）发布。

catalog 记录的任务包括 geometry-consistent world modeling。别名包括 `Geometry-Consistent World Modeling via Unified Video and 3D Prediction`。同系列还有 `fantasyworld-wan22`。

记录的评测入口包括[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（评估几何一致的生成世界）、[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（相机控制质量评测）。

## 运行时契约

可选 `input_path`、`prompt`、`camera_json_path`、`fps`、`seed`；产物 `generated_world`、`fantasyworld-wan21.mp4`。

CLI task profile：`official-camera-world`。绑定的 pipeline 类是 `FantasyWorldPipeline`。

起步 variant 是 `fantasyworld-wan21`。catalog 登记了 2 个 variant（上方卡片）：`fantasyworld-wan21`（`image-to-world-video`）：Runner 一致性待确认、`fantasyworld-wan22`（`camera-controlled-world-video`）：Runner 一致性待确认。系列状态：**已验证**。

`official-camera-world` 记录默认值：fps=16, seed=1024。

默认行解析到已验证的树内 Wan2.1 runner——请使用该路径。 Wan2.2 variant 因官方单卡运行需要认可的显存策略而保持 pending。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run fantasyworld-wan21 --pipeline.task-profile official-camera-world` 推进世界。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `acvlab/FantasyWorld-Wan2.1-I2V-14B-480P`、`Wan-AI/Wan2.1-I2V-14B-480P`、`Ruicheng/moge-2-vitl-normal`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh fantasyworld-wan21`；下载缺失的公开权重时加 `--download`。

状态：**已验证**。
