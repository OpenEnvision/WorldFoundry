Pandora 是较早的通用世界模型，采用自然语言动作与视频状态：把世界状态模拟成视频，并允许在任意步骤用自由文本动作操控模拟。本 catalog 中其模型、ChatUniVi 与 DynamiCrafter 运行时模块已内置树内；由于官方权重因数据许可限制未公开，完整生成保持 blocked。

## 用来做什么

需要动作条件世界步进时选 `pandora`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

按上游发布，自回归 LLM 主干（ChatUniVi 系）连接视频扩散解码器（DynamiCrafter 系），使语言动作操控视频状态滚动。内置运行时位于 synthesis/visual_generation/pandora/pandora_runtime。该模型由Maitrix.org（加州大学圣迭戈分校 / MBZUAI）发布。

catalog 记录的任务包括 diffusion-world-model、世界生成、文生视频。别名包括 `pandora-world`。模态上，它接受文本，输出视频。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（语言动作世界滚动生成质量）。
