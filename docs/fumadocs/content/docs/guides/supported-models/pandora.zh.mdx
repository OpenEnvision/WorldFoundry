## 架构

按上游发布，自回归 LLM 主干（ChatUniVi 系）连接视频扩散解码器（DynamiCrafter 系），使语言动作操控视频状态滚动。内置运行时位于 synthesis/visual_generation/pandora/pandora_runtime。

## 运行时契约

PandoraSynthesis 提供运行时计划封装；由于官方权重隐藏或不可得，真实生成需要调用方提供官方兼容的 checkpoint。
