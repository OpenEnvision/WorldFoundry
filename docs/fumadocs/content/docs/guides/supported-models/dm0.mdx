DM0 is Dexmal's Dexbotic-family flow-matching VLA: a Qwen3 flow action expert with merged prefix/suffix attention and triple-view preprocessing. Base and LIBERO checkpoints are recorded (Dexmal/DM0-base, Dexmal/DM0-libero, CC license) and the full inference loop — normalization plus Euler sampler — runs in process from local checkpoints.

## What it is for

Use `dm0` for vision-language-action inference on this card. The recipe exists so you can launch the recorded policy profile.

A Qwen3-based flow action expert decodes actions with an Euler sampler; the Perception Encoder and multimodal base are reused from the compatible in-tree DB-CogACT implementation, keeping the Dexbotic family consistent.

Catalog tasks include vla, vla action prediction, and vla policy rollout. Catalog aliases include `dexbotic-dm0` and `dm0-base`.

Recorded evaluation entry points include [LIBERO](/docs/evaluation/benchmark-hub/libero) (Dedicated DM0-libero policy checkpoint).

## Runtime contract

Optional `prompt`, `input_path`, `interactions`, `fps`, and `timeout_seconds`; artifacts `action_trace` and `dm0_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `DM0Pipeline`.

Family status: **Runner parity pending**.

Use DM0-libero for LIBERO evaluation and DM0-base for initialization. Training, datasets, servers, benchmark launchers, and the optional Triton realtime backend are excluded.

The Qwen3 flow action expert, merged prefix/suffix attention, triple-view preprocessing, normalization, and Euler sampler run in process from local checkpoints.

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run dm0 --pipeline.task-profile default`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch>=2.6.0).

Recorded weight repositories include `Dexmal/DM0-libero` and `Dexmal/DM0-base`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh dm0`. Add `--download` to fetch missing public checkpoints.

Status: **Runner parity pending**.
