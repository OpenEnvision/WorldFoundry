## 用来做什么

用 `infinite-world` 做 catalog 世界模型推理。需要动作条件未来帧、而不是独立片段生成器时选它。

树内运行时可解析本地或 Hugging Face checkpoint 布局，推理时不依赖外部仓库。除已记录结构外的架构内部细节仓库未存。该模型由美团（MeiGen-AI）发布。

catalog 记录的任务包括 世界模型、video。输出模态为视频。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（长时程世界滚动生成质量）、[MemoBench](/zh/docs/evaluation/benchmark-hub/memobench)（长时程一致性评测）。

## 在 WorldFoundry 中运行

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。
