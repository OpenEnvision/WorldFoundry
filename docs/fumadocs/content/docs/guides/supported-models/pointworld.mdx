PointWorld is NVIDIA's point-cloud world model for robotics: instead of predicting pixels it predicts future 3D point-cloud states under actions, giving geometry-native world modeling. In this catalog the official source route is registered at a pinned commit; checkpoint and point-cloud assets stay runtime-gated.

## What it is for

Use `pointworld` for catalog geometry inference. Choose it when the artifact is a reconstruction, not a generated video.

Architecture internals beyond the recorded tasks are not stored in this repository (apache-2.0; checkpoints at nvidia/PointWorld_models). The recorded artifact type is generated_3d_asset.

Catalog tasks include point-cloud-world-model, robot-world-model, and 3d-world-model. Documented outputs include point cloud.

## Running in WorldFoundry

Launch `worldfoundry-eval run pointworld --pipeline.task-profile default` to write geometry. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `nvidia/PointWorld_models`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh pointworld`. Add `--download` to fetch missing public checkpoints.
