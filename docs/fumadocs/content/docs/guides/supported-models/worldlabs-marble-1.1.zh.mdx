World Labs Marble 1.1 是 3D 世界生成的商业 API：从提示生成可探索的 3D 世界，经 api.worldlabs.ai 访问。本 catalog 中通过既有的树内 WorldLabs API pipeline 以 marble-1.1 模型 id 暴露；集成状态为 planned，且不存在本地权重。

## 用来做什么

`worldlabs-marble-1.1` 是记录的交互世界线。要用动作推进世界时从这里起步。

闭源 API 服务：仓库未记录任何架构细节。记录的官方来源为发布说明与 API 端点。

catalog 记录的任务包括 世界生成、3D 世界生成、api-world-model。别名包括 `marble-1.1`、`worldlab-marble-1.1`。

记录的评测入口包括[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（可探索 3D 世界生成质量）。

不是 [World Labs](/zh/docs/guides/supported-models/worldlabs)。 评测看 [WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)。

## 运行时契约

可选 `model`；产物 `worldlabs-marble-1.1.zip`。

CLI task profile：`default`。绑定的 pipeline 类是 `WorldLabsMarble11Pipeline`。

系列状态：**计划中**。

需要 World Labs API 凭证；请求经树内 WorldLabs API pipeline 发出，模型 id 为 marble-1.1。 runner parity 仍为 pending。

仅 API：权重与架构均闭源，依赖外部服务。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run worldlabs-marble-1.1 --pipeline.task-profile default`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh worldlabs-marble-1.1`；下载缺失的公开权重时加 `--download`。

状态：**计划中**。
