## What it is for

Pick `internvla-a1` when you want the catalog VLA policy: instruction and observation in, an action trace out. Use it to roll the recorded policy, not to train a new one.

The A1-3B graph couples Qwen3-VL-2B vision-language encoding with an expert action head, a Cosmos-Tokenizer-CI8x8 wrapper, flow sampling, and a normalization route — all in-tree, local-only, with no remote checkpoint code. It is published by Shanghai AI Laboratory (InternRobotics).

Catalog tasks include vla, robot policy, policy rollout, and embodied benchmark.

Recorded evaluation entry points include [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) (Dedicated InternVLA-A1-3B-RoboTwin checkpoint).

## Running in WorldFoundry

Launch `worldfoundry-eval run internvla-a1 --pipeline.task-profile default` to execute the policy. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the dedicated environment `worldfoundry-vla-internvla-a1` (Python 3.10, CUDA 12.8, torch>=2.7,\<2.8).

Recorded weight repositories include `InternRobotics/InternVLA-A1-3B`, `InternRobotics/InternVLA-A1-3B-RoboTwin`, and `Qwen/Qwen3-VL-2B-Instruct` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh internvla-a1`. Add `--download` to fetch missing public checkpoints.

Status: **Static load only**.
