## What it is for

Pick `wildworld` when you need an action-conditioned world stepper: recorded actions and a frame in, a rollout out. Use it for interactive world inference, not a text-to-video prompt dump.

As an evaluation entry its output artifact is an evaluation_report. Source status is recorded as unknown upstream; structure beyond the pinned repository is not recorded in this repository.

Catalog tasks include world-model-benchmark, dataset, and evaluation.

## Running in WorldFoundry

Launch `worldfoundry-eval run wildworld --pipeline.task-profile default` to step the world. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

No public checkpoint id is recorded on this card; follow the usage notes for staging. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh wildworld`. Add `--download` to fetch missing public checkpoints.
