LTX-2.x is Lightricks' current-generation video model family in this catalog, integrated natively for the distilled LTX-2 and LTX-2.3 image-to-video paths. The native route uses the official spatial upscaler between two denoising stages. Six variants are recorded (T2V/I2V/V2V for both 2 and 2.3), but only the two I2V routes are runnable today — the others are upstream capability profiles.

## What it is for

Use `ltx-2-i2v` for the family's joint T2V/I2V inference path. The catalog records both task profiles on this page.

The I2V route is a two-stage denoise with the official Spatial Upscaler as the boundary, loaded automatically from spatial_upsampler_path (not a separate Studio refiner toggle). Assembly uses the shared NativeDiffusionPipeline, joint multi-stage runner, and optimization policies — no Diffusers pipeline or copied upstream pipeline.

Catalog tasks include text-to-video, image-to-video, video-to-video, and audio-video-generation. Documented modalities: text, image, and video in, video out. Also recorded: `ltx-2-t2v`, `ltx-2-v2v`, `ltx-2.3-t2v`.

Recorded evaluation entry points include [AIGCBench](/docs/evaluation/benchmark-hub/aigcbench) (I2V-focused benchmark for the runnable routes).

LTX 2.3-class I2V. Not the 2.5 or original LTX-Video card.

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run ltx-2-t2v --pipeline.task-profile default`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

The in-tree LTX package is **architecture only**. Runtime assembly, scheduling, loading, offload, quantization, and the denoising loop stay in the shared `diffusion_model` infrastructure. The transformer is adapted from [Lightricks/LTX-2](https://github.com/Lightricks/LTX-2) at `d6053703e00195bc668cbd1d5eda9dc0b2e7b74a`. Checkpoints and adapted source remain under the upstream LTX license. AlayaWorld's action/history model reuses this architecture from its own synthesis package.

Recorded weight repositories include `Lightricks/LTX-2` and `Lightricks/LTX-2.3`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh ltx-2-t2v`. Add `--download` to fetch missing public checkpoints.
