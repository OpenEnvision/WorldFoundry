MIRA 是多人交互世界模型：多名玩家在同一个动作条件生成世界中行动（论文 arXiv 2607.05352）。本 catalog 中仅推理的上游源码已内置树内；执行需要兼容的本地 checkpoint 与包含 index.json 的本地 Rocket Science 数据集切分。

项目页：[mira-wm.com](https://mira-wm.com)。代码：[mira-wm/mira](https://github.com/mira-wm/mira)。

## 用来做什么

用 `local-checkpoint` 做 catalog 世界模型推理。需要动作条件未来帧、而不是独立片段生成器时选它。

除已记录任务外的架构内部细节仓库未存（apache-2.0）。Workspace 发现、参数路由与命令生成的覆盖不需加载模型权重；local-checkpoint variant 记录 Rocket Science 滚动生成任务。

catalog 记录的任务包括 action-conditioned-world-model、multiplayer-game-world-model。别名包括 `mira-wm`、`multiplayer-interactive-world-model`。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（多人世界滚动生成质量）。

## 运行时契约

可选 `load.checkpoint_path`、`load.dataset_path`、`plan_only`、`timeout_seconds`；产物 `generated_video`、`mira.mp4`。

CLI task profile：`rocket-science-rollout`。绑定的 pipeline 类是 `MIRAPipeline`。

系列状态：**Runner 一致性待确认**。

`rocket-science-rollout` 记录默认值：seed=42。

公开的 Rocket Science 数据集约 29.24 TB——已固定但有意不自动下载。 TorchCodec ABI 不兼容时视频解码回退到 PyAV；输出使用共享的 WorldFoundry 视频后端。 训练与指标入口有意省略。

必填 `checkpoint_path`、`dataset_path`；可选 `prompt`、`image`、`video`、`seed`、`clip_index`、`n_context_frames`、`num_unrolled_frames`、`n_diffusion_steps`、`schedule_type`、`noise_level`、`compile`、`overlay_actions`、`generated_only`、`plan_only`、`timeout_seconds`；`actions`：rocket_league_keyboard, game_action；产物 `generated_video`、`mira.mp4`。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run local-checkpoint --pipeline.task-profile rocket-science-rollout`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是独立 profile `mira`（Python 3.12，CUDA 12.8，torch==2.8.0+cu128）。

准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh local-checkpoint`；下载缺失的公开权重时加 `--download`。

状态：**Runner 一致性待确认**。
