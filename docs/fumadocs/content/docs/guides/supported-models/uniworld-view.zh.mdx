## 运行时契约

使用固定版本的官方源码及 extern 下的 STream3R、独立的官方环境和本地权重。上游 CLI 使用 BLIP2 自动描述，不读取用户文本提示。

## 就绪状态与限制

- 上游建议显存至少 60 GB。
- 已对官方样例的指定配置完成真实权重推理，其他场景及相机角度精度尚未量化验证。
- 默认保持输入宽高比时，实际输出尺寸可能不同于请求的高和宽。
