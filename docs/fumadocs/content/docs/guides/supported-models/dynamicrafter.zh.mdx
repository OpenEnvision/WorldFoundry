DynamiCrafter 给开放域静帧做动画：图（加可选提示词）进去，一段像样的运动出来。它是 U-Net 时代的潜视频扩散，**双流**图像条件（CLIP 图像特征 + VAE 潜变量）。WorldFoundry 把两个分辨率 profile 封成树内运行时。默认 pipeline：`DynamiCrafter512I2VPipeline`。变体：`dynamicrafter-512-i2v`、`dynamicrafter-1024-i2v`。

论文：[arXiv 2310.12190](https://arxiv.org/abs/2310.12190)。项目页：[doubiiu.github.io/projects/DynamiCrafter](https://doubiiu.github.io/projects/DynamiCrafter/)。发布方：腾讯 AI Lab / 港中文。catalog 未记许可证；manifest 在上游许可审完前**限制再分发**。

两条变体都已接线；**官方长配置一致性待验证**。求快用 512，定稿用 1024。它会发明运动——**不**跟相机路径或动作。

## 用来做什么

用 DynamiCrafter 图生视频把静帧动起来。

启动 `worldfoundry-eval run dynamicrafter-512-i2v`。

评测入口：[AIGCBench](/zh/docs/evaluation/benchmark-hub/aigcbench)（与 DynamiCrafter 任务对齐的图生视频评测）。

## 运行时契约

必填 `prompt`、`image`；可选 `video`；`actions`：seed；产物 `dynamicrafter-512-i2v.mp4`。

| 变体 | 尺寸 | 帧数 | 帧步长 | 产物 |
| --- | --- | --- | --- | --- |
| `dynamicrafter-512-i2v` | **320×512** | **50** | **24** | `dynamicrafter-512-i2v.mp4` |
| `dynamicrafter-1024-i2v` | **576×1024** | **50** | **10** | `dynamicrafter-1024-i2v.mp4` |

## 在 WorldFoundry 中运行

状态：**Runner 一致性待验证**。统一环境 `worldfoundry-unified-cu128`（Python 3.11, CUDA 12.8）。先把 `Doubiiu/DynamiCrafter`、`Doubiiu/DynamiCrafter_512`、`Doubiiu/DynamiCrafter_1024` 就位到本地，缺文件加载失败，运行时不下载。在该环境执行 `worldfoundry-eval run dynamicrafter-512-i2v`。catalog 未记录 VRAM。
