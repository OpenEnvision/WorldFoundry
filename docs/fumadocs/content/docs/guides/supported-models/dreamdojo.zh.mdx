DreamDojo 从初始图像与归一化机器人动作预测机器人视角视频。WorldFoundry 已通过原生动作条件 Cosmos DiT、共享 Reason1 文本编码器、Wan 视频编码解码与 UniPC 采样接入离线 **2B GR-1 后训练 teacher**。独立的 [DreamDojo Student](./dreamdojo-student) 入口提供低步数蒸馏推理与常驻归一化动作流式推理。

## 运行时契约

集成状态：**已集成**。此模型是机器人世界模型，不是输出动作的 VLA 策略。

提供一幅初始图像与已经归一化的动作，形状为 `[N,384]` 或 `[1,N,384]`，其中 `N` 是 12 的正整数倍。每块在 480×640、5 fps 下生成 13 帧。续接使用上一块最终生成帧作为新观测，并移除重复的边界帧。动作文件支持 `.npy`、`.json` 与 PyTorch tensor。

统一动作布局包括 GR-1 `[0,58)`、G1 `[58,101)`、YAM `[101,147)`、AgiBot `[147,169)`、MANO `[220,352)` 与潜动作 `[352,384)`。数据集专用归一化由调用方完成。

## 在 WorldFoundry 中运行

准备 GR-1 EMA 权重、Cosmos-Predict2.5 视频 tokenizer 与 Cosmos-Reason1-7B 文本编码器。需要时，公共加载入口会自动将分布式 checkpoint 分片转换为 `model_ema_bf16.pt`。

```python
from worldfoundry.pipelines.component_pipelines import DreamDojoPipeline

pipeline = DreamDojoPipeline.from_pretrained(
    {
        "checkpoints_dir": "/weights/DreamDojo/2B_GR1_post-train",
        "vae_path": "/weights/Cosmos-Predict2.5-2B/tokenizer.pth",
        "text_encoder_path": "/weights/Cosmos-Reason1-7B",
    },
    device="cuda",
)
pipeline(
    images="/inputs/robot.png",
    interactions=["/inputs/normalized-actions.npy"],
    output_path="/outputs/dreamdojo.mp4",
    num_inference_steps=35,
    guidance_scale=7.0,
    seed=42,
)
```

如已准备官方 Reason1 特征，可用 `text_embeddings_path` 替代 `text_encoder_path`。特征形状必须为 `[1,S,100352]`；该路径使用实际提供的文本 embedding，不再加载文本编码器。

可复现公共入口命令见 `python tests/manual/dreamdojo_inference.py --help`。权重、输入与生成视频保持为外部资产。

## 已执行证据

H100 上的真实权重公共入口检查使用归一化零动作、35 步采样与 seed 42，生成并导出 480×640、5 fps 的 13 帧视频。两块动作的 A/B/A 回放每次使用 24 步动作生成 25 帧；重复 A 的像素完全一致，改变动作会改变生成像素。

## 限制

- 此 teacher 配置支持离线 2B GR-1 推理。蒸馏推理通过独立学生入口使用显式学生权重，暂不支持其他权重规模。
- 尚未验证官方数值一致性、GR-1 评测质量与机器人任务成功率。
