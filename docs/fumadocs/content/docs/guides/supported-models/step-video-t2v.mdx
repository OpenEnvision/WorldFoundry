## What it is for

Pick `step-video-t2v` when you want this family's text-to-video line in WorldFoundry: a prompt in, a generated clip out. Use it as the catalog T2V start rather than an editor or a world-model stepper.

Upstream: a 30B DiT with a deeply compressed Video-VAE (16x16 spatial, 8x temporal) and bilingual text encoders. This repository re-assembles the native pipeline in-process; the former xFuser and caption/VAE HTTP-service runtime is not a backend. A checkpoint-backed 204-frame GPU artifact is verified for one prompt.

Catalog tasks include text-to-video and video-generation. Catalog aliases include `step-video`, `stepvideo-t2v`, and `step_video_t2v`. Documented modalities: text in, video out.

Recorded evaluation entry points include [VBench](/docs/evaluation/benchmark-hub/vbench) (Standard open T2V quality suite).

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run step-video-t2v --pipeline.task-profile interactive-video`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `stepfun-ai/stepvideo-t2v`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh step-video-t2v`. Add `--download` to fetch missing public checkpoints.
