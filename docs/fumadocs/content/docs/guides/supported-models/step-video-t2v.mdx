Step-Video-T2V is StepFun's large open text-to-video model (30B parameters upstream, MIT weights at stepfun-ai/stepvideo-t2v). In WorldFoundry the public pipeline is assembled from native role-based components with the shared diffusion runner — DiT, Step-LLM text encoder, CLIP, scheduler, latent initialization, and VAE decoding all execute in-process.

## Architecture

Upstream: a 30B DiT with a deeply compressed Video-VAE (16x16 spatial, 8x temporal) and bilingual text encoders. This repository re-assembles the native pipeline in-process; the former xFuser and caption/VAE HTTP-service runtime is not a backend. A checkpoint-backed 204-frame GPU artifact is verified for one prompt.

## Runtime contract

A checkpoint-backed 204-frame GPU artifact at 992x544 and 50 steps is verified for one prompt. Use id step-video-t2v. At 30B scale plan for serious VRAM or multi-GPU setups.
