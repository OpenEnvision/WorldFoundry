## 用来做什么

本卡是托管 API 而不是本地 checkpoint 时选 `hailuo-2p3`：走记录的提供商路由，而不是就位权重。

这是由服务方托管运行的模型：厂商未公开其架构、参数规模或训练细节，本仓库也未记录这些信息。WorldFoundry 记录的只是集成层——一条向服务方端点提交请求并回收生成视频产物的 Studio pipeline。

catalog 记录的任务包括 audio-video、图生视频、托管 API。别名包括 `minimax-i2v`、`minimax_i2v`。模态上，它接受图像，输出视频。

记录的评测入口包括[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（对比托管文/图生视频输出的标准多维质量评测）、[Physics-IQ Original](/zh/docs/evaluation/benchmark-hub/physics-iq)（检验服务方视频模型是否遵循基本物理合理性）。
