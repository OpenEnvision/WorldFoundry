## What it is for

Pick `worldgrow` when you need an action-conditioned world stepper: recorded actions and a frame in, a rollout out. Use it for interactive world inference, not a text-to-video prompt dump.

The runtime dependency on TRELLIS assets indicates a structured-3D-latent generation backbone extended with block-wise scene growth. Architecture internals beyond the official repository pointer (world-grow/WorldGrow, pinned head 1f2ac49c) are not recorded in this repository.

Catalog tasks include world-generation, interactive-world-model, and scene-expansion.

Recorded evaluation entry points include [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Growable 3D world coherence and quality).
