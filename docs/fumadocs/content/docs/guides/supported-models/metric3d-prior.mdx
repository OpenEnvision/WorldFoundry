Metric3D recovers metric-scale depth from a single image by normalizing images into a canonical camera space, which lets one model generalize across cameras. In this catalog it is a verified metric-depth prior: the VIPE SLAM defaults reference it by name through the shared priors factory, and checkpoint-backed inference runs through the geometry-prior contract.

## What it is for

`metric3d-prior` is the recorded reconstruction line. Start here to emit geometry from the documented views.

Per the upstream publication (ICCV 2023), a canonical-camera transformation resolves the metric ambiguity of single-image depth, and the recorded checkpoint is JUGGHM/Metric3D under a bsd-2-clause license. Registered at base_models/three_dimensions/depth/metric3d. It is published by DJI / Zhejiang University.
