Galaxea G0Plus is Galaxea AI's open VLA: RGB, language, and state in; an action trace out. The released checkpoint sits on a **PaliGemma-3B** base with a **flow-matching** action sampler and KV-cached decoding. WorldFoundry keeps architecture, KV cache, flow sampler, strict checkpoint loader, tokenizer adapter, preprocessing, and normalization **in-tree**. Restoration is strict on official parameter names. Runtime accepts only staged local assets and never executes checkpoint-provided Python.
