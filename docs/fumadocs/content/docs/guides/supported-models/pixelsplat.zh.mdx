## 架构

按论文，极线 Transformer 消解两视图间的尺度歧义，网络预测高斯参数的概率分布。 WorldFoundry 将源码内置于 base_models/three_dimensions/point_clouds/pixelsplat，并对官方测试入口做惰性封装（MIT 许可；checkpoint 镜像 dylanebert/pixelSplat）。

## 运行时契约

model_path 指向 re10k.ckpt 或 acid.ckpt，同时指定匹配的 experiment 与标定数据 dataset_roots/index_path。需安装已声明的运行依赖和本地高斯光栅化扩展。仅传图像列表时使用合成基线。PLY 导出归一化几何、DC 颜色和标准透明度 logit。

## 就绪状态与限制

- 支持原始卷积版本权重，不能直接替换为更新的 camera-ready 网络权重。
- 验证覆盖每个数据集的两个场景，并非完整基准；未标定输入不能证明几何准确性。
- PLY 仅保留 DC 颜色，视角相关外观仍需使用原生渲染器。
