## 用来做什么

用 `pixelsplat` 做 catalog 几何推理。产物是重建而不是生成视频时选它。

按论文，极线 Transformer 消解两视图间的尺度歧义，网络预测高斯参数的概率分布。 WorldFoundry 将源码内置于 base_models/three_dimensions/point_clouds/pixelsplat，并对官方测试入口做惰性封装（MIT 许可；checkpoint 镜像 dylanebert/pixelSplat）。该模型由麻省理工学院（MIT）发布。

catalog 记录的任务包括 3D 重建、高斯泼溅、新视角合成。别名包括 `pixel-splat`、`pixel_splat`。

## 运行时契约

可选 `input_path`、`interactions`、`checkpoint_path`、`index_path`、`dataset_roots`；产物 `pixelsplat.ply`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `PixelSplatPipeline`。

系列状态：**已验证**。

model_path 指向 re10k.ckpt 或 acid.ckpt，同时指定匹配的 experiment 与标定数据 dataset_roots/index_path。 需安装已声明的运行依赖和本地高斯光栅化扩展。 仅传图像列表时使用合成基线。 PLY 导出归一化几何、DC 颜色和标准透明度 logit。

支持原始卷积版本权重，不能直接替换为更新的 camera-ready 网络权重。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run pixelsplat --pipeline.task-profile interactive-video` 写出几何。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 11.3）。

记录的权重仓库包括 `dylanebert/pixelSplat`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh pixelsplat`；下载缺失的公开权重时加 `--download`。

记录 license 为 mit；状态：**已验证**。
