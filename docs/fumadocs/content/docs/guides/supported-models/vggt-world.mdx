VGGT-World builds a world model on top of VGGT-style 3D scene understanding: it couples geometry-grounded scene perception with video generation so rollouts stay consistent with the underlying 3D structure. WorldFoundry registers the official source route in-tree (paper: arXiv 2603.12655); checkpoints and assets are runtime-gated.

## What it is for

Use `vggt-world` for catalog world-model inference. Choose it when you need action-conditioned future frames rather than a standalone clip generator.

Beyond the recorded official repository (SimonSun0810/VGGT-World, pinned head c90f5ee2) and the arXiv paper pointer, architecture internals are not recorded in this repository.

Catalog tasks include world-model, 3d-scene-understanding, and video-generation. Documented outputs include video.

Recorded evaluation entry points include [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Unified world-generation quality across 3D-grounded rollouts).

Not [VGGT](/docs/guides/supported-models/vggt) and [VGGT-Omega](/docs/guides/supported-models/vggt-omega). Score on [WorldScore](/docs/evaluation/benchmark-hub/worldscore).

Artifacts `generated_world` and `vggt_world_runtime_plan.json`.

Family status: **Runner parity pending**.

Config resolution and pipeline import are expected to pass; real generation emits a runtime plan until required checkpoints/assets are staged. Missing assets are reported by the plan and are not treated as catalog blockers.

VGGT-World official source route is registered; checkpoints/assets are runtime-gated.

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run vggt-world --pipeline.task-profile default`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

No public checkpoint id is recorded on this card; follow the usage notes for staging. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh vggt-world`. Add `--download` to fetch missing public checkpoints.
