MAGI-2 generates video and audio jointly from text. WorldFoundry integrates the Preview MoE, an optional dense video Refiner, Turbo video decoder, audio codec, and text encoder from [SandAI-org/MAGI-2-preview](https://github.com/SandAI-org/MAGI-2-preview), under Apache-2.0.

## Runtime contract

Integration status: **Integrated**. The public pipeline supports ten-second text-to-video clips. Preview output is 12.5 fps; optional refinement increases temporal resolution and exports at 25 fps while preserving Preview audio.

The Refiner packs video in 8×4×4 latent blocks and uses the released radius-two local-attention window. Exact range-union attention preserves allowed keys without a quadratic dense mask. Sampling uses zero-SNR renoising, five UniPC steps, shift 5, and guidance 2 by default.

## Running in WorldFoundry

Prepare the `sand-ai/MAGI-2-preview` checkpoint layout: `preview/`, `refiner/`, `turbo_vae/`, `stable-audio-open-1.0/`, and `text_encoder/`. Components load lazily; Preview layers use sequential GPU residency.

```python
from worldfoundry.pipelines.magi2 import NativeMagi2Pipeline

pipeline = NativeMagi2Pipeline.from_pretrained("/weights/MAGI-2-preview", device="cuda")
pipeline(
    prompt="A cinematic camera move through a sunlit forest.",
    use_refiner=True,
    refiner_num_inference_steps=5,
    refiner_height=1088,
    refiner_width=1920,
    output_path="/outputs/magi2-refined.mp4",
    seed=42,
)
```

`use_refiner=False` retains Preview-only behavior. Refiner height and width must be positive multiples of 16. Refinement maps latent temporal size `T` to `2T−1`; output audio comes from the Preview stage.

## Executed evidence

A checkpoint-backed Refiner-stage replay on H100 used a saved real Preview latent and real Qwen3.5, Refiner, and Turbo weights. Five steps with seed 42 exported 249 frames at 128×128 and 25 fps, retaining the original stereo 44.1 kHz Preview audio. The replay command is `python tests/manual/magi2_refinement.py --help`.

## Limitations

- Image conditioning is unsupported.
- Default-resolution 1920×1088 replay and official numerical/visual parity remain pending.
- The 114B Preview requires substantial host RAM and sequential offloading; upstream targets eight Hopper GPUs.
