UniK3D 把米制 3D 估计推广到任意相机——针孔、鱼眼、乃至完整全景——单一模型通吃。本 catalog 中它是 checkpoint 已验证的通用相机几何先验：真实 checkpoint 推理已通过共享契约验证并支持自动相机估计，针孔与全景相机覆盖保持显式配置。

## 用来做什么

做前馈几何时选 `unik3d-prior`：视图进、重建/轨迹/点云出。需要 catalog 的 3D 路由、而不是仅深度先验时用它。

按上游论文，UniK3D 用学习到的球谐基相机模型表示相机，把射线方向与径向深度解耦，无需针对畸变单独调参。默认 checkpoint 从 lpiccinelli/unik3d-vitl 解析；注册于 base_models/three_dimensions/depth/unik3d。该模型由苏黎世联邦理工学院（ETH Zurich）发布。

catalog 记录的任务包括 panoramic-depth-estimation、metric-3d-estimation、单目深度估计、几何先验。别名包括 `unik3d`、`unik3d-vitl`。模态上，它接受图像，输出深度。
