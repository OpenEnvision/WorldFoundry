Matrix-Game 3.0 是昆仑万维的第三代，以少步推理把交互式世界视频推到更高分辨率。本 catalog 中 runner 已验证——官方 cityscape 图像条件 demo 以「forward + camera_r」动作、12 次迭代、3 步推理、 704x1280、int8 量化、编译 VAE 与 mg_lightvae 解码器运行。

## 用来做什么

在 Matrix-Game 3 上滚交互世界。1、2.0 与 3.5 第一人称在兄弟卡片。

启动 `worldfoundry-eval run matrix-game-3 --pipeline.task-profile official-cityscape-image`。

评测入口：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件游戏世界滚动生成质量）。

## 运行时契约

必填 `prompt`、`image`；可选 `video`；`actions`：keyboard, mouse；产物 `matrix-game-3.mp4`。

默认旋钮：num_inference_steps=3，fps=17。

`official-cityscape-image` 记录默认值：num_inference_steps=3, fps=17。
