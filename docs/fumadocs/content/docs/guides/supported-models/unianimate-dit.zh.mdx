## 用来做什么

用 `unianimate-dit` 跑本系列联合 T2V/I2V 推理路径。本页记录了这两种任务 profile。

构建在 Wan2.1 图生视频扩散 Transformer 之上，以姿态序列为条件驱动人物动画（checkpoint： ZheWang123/UniAnimate-DiT）。更深的条件机制细节仓库未记录。该模型由阿里巴巴（通义实验室）发布。

catalog 记录的任务包括 human-image-animation、图生视频、视频生成。模态上，它接受图像，输出视频。
