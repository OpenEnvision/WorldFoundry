UniAnimate-DiT 是阿里 ali-vilab 基于 Wan2.1-I2V 的人物图像动画模型：让人物照片按驱动姿态序列动起来。树内路径使用本地 checkpoint 资产运行，暴露 max_frames、分辨率、步数与 seed 控制。

## 用来做什么

`unianimate-dit` 是图生视频模型：输入静态图，输出视频。

构建在 Wan2.1 图生视频扩散 Transformer 之上，以姿态序列为条件驱动人物动画（checkpoint：ZheWang123/UniAnimate-DiT）。该模型由阿里巴巴（通义实验室）发布。

任务：human-image-animation、图生视频、视频生成。模态上，它接受图像，输出视频。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `height`、`width`、`steps`、`seed`、`max-frames`；产物 `unianimate-dit.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `UniAnimateDiTPipeline`。

系列状态：**Runner 一致性待确认**。

`interactive-video` 的默认值：height=832, width=480, seed=0。

为获得最佳效果，请准备干净的人物照片与驱动姿态序列。

姿态对齐与生成均通过已安装的 WorldFoundry 包模块执行。输出目录中的 `unianimate_dit_workspace/` 链接到已准备的数据和 checkpoint。`use_usp=true` 保留由 `nproc_per_node` 指定的多 GPU 序列并行 worker，需要匹配的 CUDA 与 xfuser 环境。

## 在 WorldFoundry 中运行

运行 `wf run unianimate-dit --pipeline.task-profile interactive-video` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`ZheWang123/UniAnimate-DiT`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh unianimate-dit`；下载缺失的公开权重时加 `--download`。
