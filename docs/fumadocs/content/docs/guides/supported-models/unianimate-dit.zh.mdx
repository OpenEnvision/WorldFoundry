## 架构

构建在 Wan2.1 图生视频扩散 Transformer 之上，以姿态序列为条件驱动人物动画（checkpoint： ZheWang123/UniAnimate-DiT）。更深的条件机制细节仓库未记录。

## 运行时契约

已通过真实权重的短片 GPU 冒烟验证；完整 runner parity 仍待验证。为获得最佳效果，请准备干净的人物照片与驱动姿态序列。

## 就绪状态与限制

- 已验证 9 帧、4 步的 GPU 冒烟产物；官方 81 帧、50 步的质量与姿态控制一致性尚未测量。
- Checkpoint 属于外部资产——权重缺失时会在运行时报告，而不会自动下载。
- 专精人物主体——不是通用图生视频模型。
