## What it is for

`mochi-1-preview-t2v` is the recorded prompt-to-video route — not image editing and not a policy. Start here when the job is a clip from text.

Upstream describes Mochi-1 as a 10B-parameter Asymmetric Diffusion Transformer (AsymmDiT) with a dedicated video VAE. This repository records the runner wiring and the standard prompt/image/video/actions input schema; further internals are not recorded here.

Catalog tasks include text-to-video. Documented modalities: text in, video out.

Recorded evaluation entry points include [VBench](/docs/evaluation/benchmark-hub/vbench) (Standard T2V quality suite).

## Running in WorldFoundry

Launch `worldfoundry-eval run mochi-1-preview-t2v --pipeline.task-profile interactive-video` to sample the clip. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `genmo/mochi-1-preview`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh mochi-1-preview-t2v`. Add `--download` to fetch missing public checkpoints.
