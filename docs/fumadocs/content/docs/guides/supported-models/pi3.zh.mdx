Pi3（π³）是前馈式视觉几何模型，重建 3D 场景、相机轨迹与点云，且不依赖固定参考视图——其置换等变设计对所有输入视图一视同仁。本 catalog 中树内点云导航 pipeline 已按重建与轨迹渲染注册。

## 用来做什么

`pi3` 是记录的重建线。从记录的视图写出几何时从这里起步。

按论文（arXiv 2507.13347），Pi3 用置换等变 Transformer 预测仿射不变的相机位姿与尺度不变的局部点图，摆脱了参考视图启发式。权重为 apache-2.0；除已记录任务外的内部细节此处未存。

catalog 记录的任务包括 3D 重建、轨迹、点云。输出模态为点云。
