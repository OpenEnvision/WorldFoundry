## What it is for

Pick `worldcrafter-fast` when you need camera-controlled video: a camera trajectory in, a steered clip out. Use it instead of unconstrained T2V when viewpoint must follow a path.

Catalog tasks include text-to-video, image-to-video, camera-controlled-video, and world-model. Documented modalities: text and image in, video out.

## Runtime contract

Optional `prompt`, `image`, `actions`, `seed`, and `frames`; artifacts `worldcrafter.mp4`.

## Running in WorldFoundry

Launch `worldfoundry-eval run worldcrafter-fast --pipeline.task-profile text-to-video` to follow the camera path. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `TencentARC/WorldCrafter-Fast`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh worldcrafter-fast`. Add `--download` to fetch missing public checkpoints.
