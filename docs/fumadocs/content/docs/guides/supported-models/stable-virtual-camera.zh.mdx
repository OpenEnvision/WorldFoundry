## 架构

按论文（arXiv 2503.14489），多视角扩散模型以两阶段程序化方式在采样相机位姿处生成目标视图，在轨迹通用性与一致性之间取得平衡。除已记录任务外的细节仓库未存。

## 运行时契约

运行前请在 Hugging Face 接受 gated checkpoint 条款并设置 HF_TOKEN；gated 权限缺失会在推理时报告。适配器驱动上游 demo.py 的 Fire 入口。
