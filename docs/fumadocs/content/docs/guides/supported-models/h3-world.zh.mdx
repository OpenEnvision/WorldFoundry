H3-World 是基于 MiniMax-H3 构建的交互式动作条件世界模型，将键盘状态转换为逐 latent 的英文指令，并通过定向注意力路由与 rank-32 LoRA 适配器将每条指令绑定到对应的视频 latent。

论文：[arXiv 2609.01560](https://arxiv.org/abs/2609.01560)。

项目页：[danzer1xxxxchan.github.io/H3-World](https://danzer1xxxxchan.github.io/H3-World)。代码：[Danzer1xxxxChan/H3-World](https://github.com/Danzer1xxxxChan/H3-World)。

## 运行时契约

H3-World 在统一环境中直接复用 WorldFoundry 的规范化 MiniMax-H3 FL2VA 组件（DiT、Qwen3-VL 编码器、音视频 VAE、序列打包器、去噪循环与 MP4 封装器）。

运行前准备 MiniMax-H3 的 `FL2VA` 基础权重（`MiniMaxAI/MiniMax-H3`）和 H3-World LoRA 权重（`DANNY621/H3-World`，`step-10000.safetensors`）：

```bash
wf run h3-world --pipeline.task-profile action-video --json
```

输入包括起始帧（`images`）、场景描述（`prompt`）以及动作控制参数：`action_preset`（`still`、`forward`、`back`、`strafe-left`、`strafe-right`、`tilt-up`、`tilt-down`、`pan-left`、`pan-right`、`pan-left-fast`、`pan-right-fast`）、`interactions`（按键组合或逐 latent 调度表）或显式 `action_script` 指令列表。默认输出为 `832x480`、24 fps 的 124 帧视频及同步 32 kHz 立体声音频（`h3-world.mp4`）。

## 限制

帧数需满足 `17k + 5`（如 124、243、481），宽高需为 32 的倍数。MiniMax-H3 基础权重与 H3-World LoRA 权重均受 MiniMax H3 Community License Agreement 约束。
