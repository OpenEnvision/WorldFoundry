## 用来做什么

用 `lda-1b` 做本卡的视觉-语言-动作推理。这条配方用来启动已记录的策略 profile。

Qwen3-VL 提供多模态编码，DINOv3-ViT 补充视觉特征，MMDiT（多模态扩散 transformer）采样动作，状态打包与动作反归一化内置树内。模型与参数名保持发布 checkpoint 契约。

catalog 记录的任务包括 视觉-语言-动作（VLA）、机器人策略、策略执行、具身评测。别名包括 `lda1b`、`wayer2/lda-robocasa`。

记录的评测入口包括[RoboCasa](/zh/docs/evaluation/benchmark-hub/robocasa)（发布的 checkpoint 面向 RoboCasa）。
