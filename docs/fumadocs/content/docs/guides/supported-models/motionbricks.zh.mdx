## 用来做什么

`motionbricks` 是记录的交互世界线。要用动作推进世界时从这里起步。

除已记录任务外的架构内部细节仓库未存（apache-2.0）；源码从 GR00T-WholeBodyControl 仓库以固定 commit 绑定。记录的产物类型为 action_trace。该模型由英伟达（NVIDIA）发布。

catalog 记录的任务包括 human-action-generation、motion-generation、世界模型。

## 运行时契约

产物 `action_trace`、`motionbricks_runtime_plan.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `MotionBricksPipeline`。

系列状态：**Runner 一致性待确认**。

配置解析与 pipeline 导入预期可通过；在所需 checkpoint/资产就位前，真实生成会输出运行时计划。 缺失资产由计划报告，不视为 catalog 阻塞。

WorldFoundry tracks upstream source and checkpoint 计划中; no runnable pipeline is registered.

必填 `prompt`、`video`；可选 `image`；`actions`：whole_body_motion, control_sequence；产物 `action_trace`、`motionbricks_runtime_plan.json`。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run motionbricks --pipeline.task-profile default` 推进世界。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

本卡片未记录公开 checkpoint id；按使用说明就位权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh motionbricks`；下载缺失的公开权重时加 `--download`。

状态：**Runner 一致性待确认**。
