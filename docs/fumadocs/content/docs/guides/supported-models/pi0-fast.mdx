pi0-FAST is the autoregressive variant of pi0: instead of flow matching it uses the FAST action tokenizer to decode actions as discrete tokens, trading some smoothness for faster, simpler decoding. WorldFoundry reuses the in-tree OpenPI runtime with the pi0_fast_droid configuration and pi0-FAST checkpoint resolution.

## What it is for

Start on `pi0-fast` when you want discrete FAST tokens on the same PaliGemma backbone. Launch `worldfoundry-eval run pi0-fast`. Default configuration is `pi0_fast_droid`. Do not route this through LeRobot policy-zoo.

## Runtime contract

Required `image`, `instruction`, and `prompt`. `actions`: `robot_action`, `proprio`, `action_space`. Artifact: `pi0_fast_action_trace.json`. Faster decode, less smooth chunks than flow-matching π0.

## Running in WorldFoundry

Dedicated `worldfoundry-openpi-cu12` (Python 3.11, CUDA 12.4 or newer). Stage GCS checkpoints with gsutil. License is on the [OpenPI](/docs/guides/supported-models/openpi) card (Apache-2.0). Status: **Runner parity pending** until assets are present.
