Navigation World Models (NWM) is Meta's navigation world model (CVPR 2025 highlight): a conditional diffusion transformer that predicts egocentric future video from past frames and navigation actions, and can plan trajectories by imagining them. Recorded variants cover RECON and SCAND dataset checkpoints. In this catalog the source is vendored in-tree; execution stays checkpoint/dataset gated.

Project page: [amirbar.net/nwm](https://www.amirbar.net/nwm/). Code: [facebookresearch/nwm](https://github.com/facebookresearch/nwm).

## What it is for

Use `nwm-recon` for catalog world-model inference. Choose it when you need action-conditioned future frames rather than a standalone clip generator.

Per the upstream release, a Conditional Diffusion Transformer (CDiT) scales to 1B parameters and conditions on action and time embeddings for egocentric prediction (checkpoints at facebook/nwm, CC-BY-NC-4.0). It is published by Meta AI (FAIR).

Catalog tasks include navigation-world-model, action-conditioned-video, and egocentric-video-generation. Catalog aliases include `navigation-world-models`, `nwm-recon`, and `nwm-scand`. Documented outputs include video. Also recorded: `nwm-scand`.

Recorded evaluation entry points include [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Navigation world-rollout quality).

Imagine egocentric future video from past frames plus navigation actions. Pick `nwm-recon` for RECON weights, or `nwm-scand` for SCAND.

## Runtime contract

Artifacts `nwm.mp4`.

CLI task profiles: `default`. WorldFoundry binds `NWMPipeline`.

Start on `nwm-recon`. The family registers 2 catalog variants (cards above): `nwm-recon` (`navigation-world-model`) — Planned; `nwm-scand` (`navigation-world-model`) — Planned. Family status: **Runner parity pending**.

The pipeline resolves the official NWM inference entrypoint and returns blocked diagnostics until checkpoints and evaluation datasets are staged. It is the recorded candidate for non-driving navigation video evaluation.

WorldFoundry registers an in-tree runtime manifest pipeline for the vendored NWM source.

## Running in WorldFoundry

Launch `worldfoundry-eval run nwm-recon --pipeline.task-profile default` to step the world. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `facebook/nwm`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh nwm-recon`. Add `--download` to fetch missing public checkpoints.

Status: **Runner parity pending**.
