## 用来做什么

用 `recammaster` 做相机条件视频推理。配方绑定了已记录的相机控制 profile。

按论文（arXiv 2503.11647），ReCamMaster 通过帧维度条件化把源视频注入预训练文生视频模型（开源版基于 Wan 系），从而在生成时更换相机轨迹。运行需要本地 Wan2.1、ReCamMaster checkpoint、torchvision 与 CUDA 资产。该模型由快手（可灵团队）发布。

catalog 记录的任务包括 camera-controlled video rerendering。别名包括 `Camera-Controlled Generative Rendering from A Single Video`。

记录的评测入口包括[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（直接评估相机轨迹控制质量）。
