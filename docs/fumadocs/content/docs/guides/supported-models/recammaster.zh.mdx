## 架构

按论文（arXiv 2503.11647），ReCamMaster 通过帧维度条件化把源视频注入预训练文生视频模型（开源版基于 Wan 系），从而在生成时更换相机轨迹。运行需要本地 Wan2.1、ReCamMaster checkpoint、torchvision 与 CUDA 资产。

## 运行时契约

开源参考运行时受 checkpoint/GPU 限制——不注册空 runner 壳。提交任务前请就位 Wan2.1 与 ReCamMaster checkpoint；每次运行的视觉 QA 在 catalog 外跟踪。

## 就绪状态与限制
