VMem 是带「面元索引视图记忆」的交互式视频场景生成模型：当你在场景中游走时，它记住哪些表面曾从哪些视角被看到，使新视角与历史保持一致。集成与 runner 状态均为 verified——Studio/API 视觉验证使用树内运行时与就位的 VMem、CUT3R checkpoint，复现了官方导航 demo。

## 架构

VMem 以面元（surfel）索引历史视图，检索相关视图作为下一视角生成的条件（见论文 arXiv 2506.18903）。该路径以 CUT3R 为几何主干；两组 checkpoint 均需就位。

## 运行时契约

video 类别中少数完整验证过的交互式路径之一——树内 Studio/API 路径已于 2026-06-27 产出并通过视觉验证官方风格导航 demo。输入覆盖 prompt/image/video/actions；输出为 generated_video 产物。

## 评测 Benchmark

- [WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore) — 评估可相机游走的生成场景。

## 就绪状态与限制

- 需要同时在本地就位 VMem 与 CUT3R checkpoint。
- 场景游走质量依赖几何主干；极端视角变化仍可能破坏一致性。
