Wan2.1-Fun V1.1 14B Control Camera is Alibaba PAI's largest Wan2.1-generation camera-control checkpoint in the VideoX-Fun family: image-to-video generation steered by explicit camera pose sequences. WorldFoundry vendors VideoX-Fun in-tree (revision 403f1f7b) and wires a dedicated route for the alibaba-pai/Wan2.1-Fun-V1.1-14B-Control-Camera checkpoint under Apache-2.0.

## What it is for

`wan21-fun-14b-cam` is the recorded camera-control route. Start here to follow a catalog camera path.

A 14B-parameter Wan2.1 diffusion transformer with the VideoX-Fun Control-Camera conditioning pathway: camera extrinsics are injected as control signals alongside the image condition. Further internals are not recorded in this repository. It is published by Alibaba PAI (VideoX-Fun).

Catalog tasks include camera-controlled-video and image-to-video. Documented modalities: image in, video out.

Recorded evaluation entry points include [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera-pose adherence for controlled i2v generation).

Not [Wan2.1](/docs/guides/supported-models/wan2.1) and [Wan2.1 Fun 1.3B Cam](/docs/guides/supported-models/wan21-fun-1p3b-cam). Score on [CameraBench](/docs/evaluation/benchmark-hub/camerabench).

## Runtime contract

Optional `prompt`, `input_path`, `frames`, `fps`, and `height`; artifacts `wan21-fun-14b-cam.mp4`.

CLI task profiles: `default`. WorldFoundry binds `Wan21Fun14BCameraPipeline`.

Family status: **Runner parity pending**.

Use the sibling wan21-fun-1p3b-cam entry for a GPU-validated reference of the same route at 1.3B scale; the 14B route itself is wired but parity is pending. Camera pose sequences must be supplied explicitly.

VideoX-Fun source is vendored at revision 403f1f7b78dcafccc4f6606dda4ec28e16e667dc.

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run wan21-fun-14b-cam --pipeline.task-profile default`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `alibaba-pai/Wan2.1-Fun-V1.1-14B-Control-Camera`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh wan21-fun-14b-cam`. Add `--download` to fetch missing public checkpoints.

Status: **Runner parity pending**.
