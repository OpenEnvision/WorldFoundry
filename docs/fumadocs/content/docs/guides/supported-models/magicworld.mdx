## What it is for

Pick `magicworld` when you need camera-controlled video: a camera trajectory in, a steered clip out. Use it instead of unconstrained T2V when viewpoint must follow a path.

Architecture internals beyond the recorded tasks are not stored in this repository. Note the split licensing: code is apache-2.0, while the upstream README applies CC BY-NC-SA 4.0 terms to released model materials. It is published by vivo (Camera Research).

Catalog tasks include interactive-world-model, camera-controlled-video, and image-to-video. Documented modalities: image in, video out.

Recorded evaluation entry points include [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera-control adherence of interactive rollouts).

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run magicworld --pipeline.task-profile default`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).
