## What it is for

Use `lagernvs` for catalog geometry inference. Choose it when the artifact is a reconstruction, not a generated video.

The catalog records a novel-view/camera-path rendering model at 512 resolution; internals are not recorded in this repository. License is the FAIR non-commercial research license. It is published by Meta AI (FAIR).

Catalog tasks include novel-view-synthesis, 3d-scene-rendering, and camera-path-rendering. Catalog aliases include `lager-nvs`, `facebook/lagernvs_general_512`, and `facebookresearch/lagernvs`.

## Running in WorldFoundry

Launch `worldfoundry-eval run lagernvs --pipeline.task-profile default` to write geometry. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `facebook/lagernvs_general_512`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lagernvs`. Add `--download` to fetch missing public checkpoints.
