## Running in WorldFoundry

Launch `worldfoundry-eval run last-r1 --pipeline.task-profile interactive-video` to execute the policy. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `chenhao01/LaST-R1`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh last-r1`. Add `--download` to fetch missing public checkpoints.
