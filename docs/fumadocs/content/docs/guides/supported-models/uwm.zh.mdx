## 架构

UWM 是视频-动作扩散设计：单个扩散过程联合建模未来观测与机器人动作，同一网络兼任预测与策略角色。官方仓库指针之外的细节仓库未记录。

## 运行时契约

配置解析与 pipeline 导入预期可通过；在所需 checkpoint/资产就位前，真实生成会输出运行时计划。缺失资产由计划报告，不视为 catalog 阻塞。请按评测套件选择 LIBERO-90 或 DROID 变体。

## 评测 Benchmark

- [LIBERO](/zh/docs/evaluation/benchmark-hub/libero) — uwm-libero90 变体面向 LIBERO 任务。
- [EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench) — 机器人世界模型滚动生成质量。
