## 用来做什么

需要动作条件世界步进时选 `uwm`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

UWM 是视频-动作扩散设计：单个扩散过程联合建模未来观测与机器人动作，同一网络兼任预测与策略角色。官方仓库指针之外的细节仓库未记录。该模型由华盛顿大学（WEIRD 实验室）发布。

catalog 记录的任务包括 机器人世界模型、动作条件视频、video-action-diffusion。别名包括 `uwm-libero90`、`uwm-droid`。

记录的评测入口包括[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（uwm-libero90 变体面向 LIBERO 任务）、[EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench)（机器人世界模型滚动生成质量）。
