## 用来做什么

`starwm` 是记录的交互世界线。要用动作推进世界时从这里起步。

运行时为端点-客户端设计：路由构建官方 run_inference_client.py 命令，执行前校验 input_file、mode 与 served_model_id/api_model_id。模型架构内部细节仓库未记录。

catalog 记录的任务包括 multi-agent-world-model、starcraft-world-model、动作条件视频。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件游戏世界滚动生成质量）。
