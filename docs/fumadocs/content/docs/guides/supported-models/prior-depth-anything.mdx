## What it is for

Use `prior-depth-anything` for catalog geometry inference. Choose it when the artifact is a reconstruction, not a generated video.

The catalog records a prompt-conditioned depth-completion design: the model consumes prompt metric depth alongside the image (checkpoint Rain729/Prior-Depth-Anything, apache-2.0). It is registered at base_models/three_dimensions/depth/priorda and shared by higher-level geometry pipelines without being nested under them.

Catalog tasks include depth-completion, metric-depth-estimation, and geometry-prior. Catalog aliases include `priorda` and `prior-depth-anything-prior`. Documented modalities: image in, depth out.
