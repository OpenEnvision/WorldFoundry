H-RDT（Human-to-Robotics Diffusion Transformer）先在大规模人类操作数据上预训练扩散 transformer 策略，再做机器人微调（论文：arXiv 2506.23503，MPL-2.0）。官方发布为 48 维人体动作预训练 checkpoint（embodiedfoundation/H-RDT）；WorldFoundry 将 transformer、flow-matching 采样器、 DINOv2+SigLIP 视觉路径与可选 T5 语言路径内置树内。

## 用来做什么

用 `h-rdt` 做本卡的视觉-语言-动作推理。这条配方用来启动已记录的策略 profile。

扩散 transformer 配 flow-matching 采样；视觉用 DINOv2 加 SigLIP，语言可选 T5。模块与参数名保持官方 checkpoint 契约，恢复为严格模式。

catalog 记录的任务包括 视觉-语言-动作（VLA）、human_motion_policy、VLA 策略执行、robot_policy_finetune。别名包括 `h_rdt`、`embodiedfoundation/h-rdt`。

## 运行时契约

可选 `prompt`、`input_path`、`interactions`、`fps`、`timeout_seconds`；产物 `action_trace`、`h_rdt_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `HRDTSynthesis`。

系列状态：**仅静态加载**。

发布的 checkpoint 是人体动作预训练阶段（48 维），而非未发布的 14 维机器人微调——机器人部署需自行微调。 训练、数据集、ROS、机器人驱动、模拟器客户端与 hub mixin 均被排除。

仅发布人体动作预训练 checkpoint；机器人微调版未发布。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run h-rdt --pipeline.task-profile default`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是独立 profile `worldfoundry-vla-h-rdt`（Python 3.10，Cu121 Or Newer，torch>=2.2）。

记录的权重仓库包括 `embodiedfoundation/H-RDT`、`google/t5-v1_1-xxl`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh h-rdt`；下载缺失的公开权重时加 `--download`。

状态：**仅静态加载**。
