## 用来做什么

需要动作条件世界步进时选 `leworldmodel`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

记录的结构覆盖潜空间（JEPA）与像素两类世界模型 variant（checkpoint 位于 eren23/lewm-models）。运行时 eval 配置位于 data/models/runtime/configs/le_wm/config/eval；推理不需要训练配置。该模型由Mila 魁北克人工智能研究所 / 蒙特利尔大学发布。

catalog 记录的任务包括 潜空间世界模型、JEPA 世界模型、pixel-world-model。

## 运行时契约

可选 `plan_only`、`timeout_seconds`；产物 `generated_world`、`leworldmodel_result.json`。

CLI task profile：`pusht-eval`。绑定的 pipeline 类是 `LeWorldModelPipeline`。

系列状态：**Runner 一致性待确认**。

路径匹配官方 eval.py 配置流程，并在执行前报告缺失的 stable-worldmodel 包、任务数据集或非随机策略 checkpoint。 官方 PushT 评估一致性仍待验证。

面向评估的世界模型：用于评价动力学，不渲染演示视频。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run leworldmodel --pipeline.task-profile pusht-eval` 推进世界。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `eren23/lewm-models`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh leworldmodel`；下载缺失的公开权重时加 `--download`。
