Segment and Track Anything（SAM-Track）把 SAM 分割与 AOT/DeAOT 跟踪结合起来：对象只需分割一次即可在整段视频中被跟踪，GroundingDINO 支持文本提示选择。本 catalog 中它是经共享 geometry-prior 契约调用的独立跟踪先验。

## 用来做什么

用 `track-anything-prior` 做 catalog 几何推理。产物是重建而不是生成视频时选它。

记录的结构组合三个子组件——SAM 出掩码、GroundingDINO 做文本定位、AOT/DeAOT 做传播——并在可用时复用 WorldFoundry 的规范组件。注册于 base_models/perception_core/tracking/track_anything；上游许可为 AGPL-3.0。该模型由浙江大学（ReLER 实验室）发布。

catalog 记录的任务包括 video-object-segmentation、object-tracking、几何先验。别名包括 `segment-and-track-anything`、`track-anything`、`aot-deaot-l`。
