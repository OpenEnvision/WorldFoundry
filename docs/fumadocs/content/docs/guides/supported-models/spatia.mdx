Spatia is a camera-controlled video-to-video world model: given source video and a target camera trajectory it re-renders the scene along the new viewpoint path. WorldFoundry vendors the official source in-tree (revision f75b10c9) and exposes it through the shared pipeline runner with the Jinjing713/Spatia checkpoint reference, released under Apache-2.0.

## Architecture

The in-tree route wires Spatia inference with a dense world-to-camera (W2C) trajectory input: per-frame camera extrinsics drive the re-rendering. Architecture internals beyond the vendored source are not recorded in this repository.

## Runtime contract

Provide a source image or video and a dense per-frame W2C camera trajectory. Optional mask_path passes one foreground mask matching the original source-frame size to reconstruction; set force_rebuild_intermediate when changing cached inputs. A local image-input run completed 17 frames at 832x480 and 40 steps; camera adherence has not been established.

## Evaluation benchmarks

- [CameraBench](/docs/evaluation/benchmark-hub/camerabench) — Camera-trajectory adherence for controlled re-rendering.

## Readiness and limitations

- A local checkpoint-backed GPU inference run is recorded; official PyTorch3D renderer parity and camera-control accuracy remain unverified.
- Requires dense per-frame camera trajectories, not sparse keyframe poses.
- The default MapAnything checkpoint has a non-commercial license.
