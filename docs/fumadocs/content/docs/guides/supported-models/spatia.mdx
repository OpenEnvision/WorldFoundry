Spatia is a camera-controlled video-to-video world model: given source video and a target camera trajectory it re-renders the scene along the new viewpoint path. ## What it is for

Pick `spatia` when you need camera-controlled video: a camera trajectory in, a steered clip out. Use it instead of unconstrained T2V when viewpoint must follow a path.

The in-tree route wires Spatia inference with a dense world-to-camera (W2C) trajectory input: per-frame camera extrinsics drive the re-rendering. Architecture internals beyond the vendored source are not recorded in this repository.

Catalog tasks include camera-controlled-video, video-to-video, and world-model. Documented modalities: video in, video out.

Recorded evaluation entry points include [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera-trajectory adherence for controlled re-rendering).

## Running in WorldFoundry

Launch `worldfoundry-eval run spatia --pipeline.task-profile default` to follow the camera path. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `Jinjing713/Spatia`, `Wan-AI/Wan2.2-TI2V-5B`, and `facebook/map-anything`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh spatia`. Add `--download` to fetch missing public checkpoints.
