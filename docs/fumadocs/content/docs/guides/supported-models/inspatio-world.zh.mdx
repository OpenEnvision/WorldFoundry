InSpatio-World 是 1.3B 的视频条件世界生成器：给定一段视频与目标轨迹，合成同一世界的轨迹条件新视角。本 catalog 中它已完整验证——树内 pipeline 于 2026-07-10 经 Workspace 生成并通过视觉验证 297 帧视频，所有默认组件均从本地 checkpoint 存储解析。

## 运行时契约
