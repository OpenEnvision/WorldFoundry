WorldMem targets the core weakness of interactive world models — forgetting: it equips a Minecraft-style interactive world model with an explicit memory so revisited places stay consistent over long horizons (paper: arXiv 2504.12369). WorldFoundry registers the route in-tree; upstream inference model and data assets are runtime-gated.

## What it is for

`worldmem` is the recorded interactive world line. Start here when the job is stepping a world with actions.

The recorded design theme is long-term consistency via memory: past observations are stored and retrieved to condition future rollouts. Architecture internals beyond the official repository and paper pointers are not recorded in this repository.

Catalog tasks include interactive-world-model, minecraft-world-model, and long-term-consistency.

Recorded evaluation entry points include [MemoBench](/docs/evaluation/benchmark-hub/memobench) (Long-term memory consistency of world rollouts), [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Action-conditioned interactive rollout quality).
