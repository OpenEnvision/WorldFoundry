## What it is for

Pick `shotstream` when you want this family's text-to-video line in WorldFoundry: a prompt in, a generated clip out. Use it as the catalog T2V start rather than an editor or a world-model stepper.

Architecture internals beyond the recorded tasks are not stored in this repository (weights at KlingTeam/ShotStream). The upstream repository lacks a root license and is flagged for manual review. It is published by Kuaishou (Kling Team).

Catalog tasks include interactive-video-generation, real-time-video-generation, and streaming-video. Catalog aliases include `interactive-video-generation`. Documented outputs include video.

## Running in WorldFoundry

Launch `worldfoundry-eval run shotstream --pipeline.task-profile causal-video` to sample the clip. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `KlingTeam/ShotStream` and `Wan-AI/Wan2.1-T2V-1.3B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh shotstream`. Add `--download` to fetch missing public checkpoints.
