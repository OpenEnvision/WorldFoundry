ABot-World-0-5B-LF 是高德的交互式世界模型：输入一张图加动作序列，它逐块滚动生成世界视频，并在动作块之间保持因果 KV 状态常驻。本 catalog 中它已通过 checkpoint/GPU 验证——真实 A100 Workspace 推理用公开的 0.5B-LF checkpoint 在官方 1280x704 分辨率下产出完全可解码的九帧 H.264 产物。

## 用来做什么

需要动作条件世界步进时选 `abot-world-0-5b-lf`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

仅集成因果推理与常驻交互滚动；Wan 注意力、T5、Wan2.2 VAE、调度器、媒体 I/O 与 FP8 支持在树内复用，训练、Gradio、benchmark 与实验性量化器源码被排除。记录的 checkpoint 为 acvlab/ABot-World-0-5B-LF（causal student）。该模型由阿里巴巴（高德地图 AMAP-CVLab）发布。

catalog 记录的任务包括 image-to-world-video、动作条件视频、交互式世界模型。别名包括 `abot-world`、`abot`。模态上，它接受图像，输出世界状态、视频。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（世界模型滚动生成质量的通用评测）。

ABot World 0.5B 长世界。不是 M0 策略卡。

## 运行时契约

可选 `prompt`、`input_path`、`interactions`、`frames`、`fps`；产物 `generated_world_video`、`abot-world.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `ABotWorldPipeline`。

系列状态：**已验证**。

运行为离线优先，需要本地 checkpoint 目录。 常驻 API 在动作块之间保持因果 KV 状态；首个块返回 9 帧 RGB，后续块返回 12 帧——客户端缓冲请按此规划。

离线优先：不做运行时下载，所有资产必须本地就位。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run abot-world-0-5b-lf --pipeline.task-profile interactive-video`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

记录的权重仓库包括 `acvlab/ABot-World-0-5B-LF`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh abot-world-0-5b-lf`；下载缺失的公开权重时加 `--download`。

状态：**已验证**。
