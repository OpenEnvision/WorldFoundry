T2V-Turbo 是从 VideoCrafter2 蒸馏出的快速文生视频模型，结合一致性蒸馏与奖励反馈，4-8 步即可生成可看的视频。在本 catalog 中它由共享原生扩散组件装配：VideoCrafter2 基座与有序的 T2V-Turbo LoRA 是两个独立的声明式 checkpoint 输入。

## 架构

基座：VideoCrafter2 的 U-Net 潜空间视频扩散。之上：以混合奖励反馈训练的一致性蒸馏 LoRA（见论文 arXiv 2405.18750）。WorldFoundry 使用共享原生装配器、runner、checkpoint 加载器、offload 策略与 LVDM 组件。

## 运行时契约

runner 状态记录了原生 checkpoint 验证：本地 VideoCrafter2 与 T2V-Turbo VC2 资产可用于严格的组件与 LoRA 校验。适合需要大量快速文生视频草稿、而非极致质量的场景。

## 评测 Benchmark

- [VBench](/zh/docs/evaluation/benchmark-hub/vbench) — T2V-Turbo 的优化目标正是该评测的各维度。

## 就绪状态与限制

- 少步生成以细节换速度——质量上限受 VideoCrafter2 基座限制。
- 需要基座 checkpoint 与有序 LoRA 两个独立输入。
