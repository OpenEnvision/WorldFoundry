T2V-Turbo 是从 VideoCrafter2 蒸馏出的快速文生视频模型，结合一致性蒸馏与奖励反馈，4-8 步即可生成可看的视频。在本 catalog 中它由共享原生扩散组件装配：VideoCrafter2 基座与有序的 T2V-Turbo LoRA 是两个独立的声明式 checkpoint 输入。

## 用来做什么

需要本系列的文生视频时选 `t2v_turbo_t2v`：prompt 进、生成视频出。它是 catalog 上的 T2V 起步线，不是编辑器，也不是世界模型步进器。

基座：VideoCrafter2 的 U-Net 潜空间视频扩散。之上：以混合奖励反馈训练的一致性蒸馏 LoRA（见论文 arXiv 2405.18750）。WorldFoundry 使用共享原生装配器、runner、checkpoint 加载器、offload 策略与 LVDM 组件。该模型由加州大学圣塔芭芭拉分校（UCSB）发布。

catalog 记录的任务包括 文生视频。别名包括 `t2v-turbo-t2v`、`t2v-turbo`。模态上，它接受文本，输出视频。

记录的评测入口包括[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（T2V-Turbo 的优化目标正是该评测的各维度）。

## 运行时契约

可选 `prompt`、`frames`、`fps`、`height`、`width`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `T2VTurboT2VPipeline`。

系列状态：**仅静态加载**。

`interactive-video` 记录默认值：frames=16, fps=8, height=320, width=512, seed=0。

runner 状态记录了原生 checkpoint 验证：本地 VideoCrafter2 与 T2V-Turbo VC2 资产可用于严格的组件与 LoRA 校验。 适合需要大量快速文生视频草稿、而非极致质量的场景。
