## Architecture

Per the paper (arXiv 2408.13912), Splatt3R builds on MASt3R's two-view geometry backbone and adds a Gaussian-parameter head. WorldFoundry keeps the runtime under base_models/three_dimensions/general_3d/splatt3r/splatt3r_runtime, importing MASt3R/DUSt3R from their canonical sibling paths; the packaged runtime is inference-only (training loaders and demo code are pruned).

## Runtime contract

Splatt3RSynthesis loads the in-tree runtime in-process and emits a PLY Gaussian-splat artifact. Checkpoints stay external assets (brandonsmart/splatt3r_v1.0) — stage them before running.

## Readiness and limitations

- Two-view input: large scenes need multiple pairs and external merging.
- Inherits MASt3R/DUSt3R licensing considerations through its backbone lineage.
