## What it is for

`splatt3r` is the recorded reconstruction line. Start here to emit geometry from the documented views.

Per the paper (arXiv 2408.13912), Splatt3R builds on MASt3R's two-view geometry backbone and adds a Gaussian-parameter head. WorldFoundry keeps the runtime under base_models/three_dimensions/general_3d/splatt3r/splatt3r_runtime, importing MASt3R/DUSt3R from their canonical sibling paths; the packaged runtime is inference-only (training loaders and demo code are pruned). It is published by University of Oxford (Active Vision Lab).

Catalog tasks include 3d-reconstruction and gaussian-splatting. Catalog aliases include `splattr` and `splatt3r-official`.
