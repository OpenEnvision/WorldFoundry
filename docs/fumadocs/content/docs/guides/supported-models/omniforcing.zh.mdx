## 用来做什么

需要动作条件世界步进时选 `omniforcing`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

除已记录任务（音视频世界模型、实时生成、蒸馏）外的架构内部细节仓库未存。上游仓库缺少根许可文件，已标记需人工审查。

catalog 记录的任务包括 audio-visual-world-model、实时生成、蒸馏。
