Video Depth Anything brings temporal consistency to the Depth Anything family: it estimates depth over arbitrarily long videos without the flicker of frame-by-frame estimation. In this catalog it is an independent temporal depth prior that VIPE pipeline profiles can select through shared runtime config without owning the code.

## Architecture

Per the upstream release, a spatiotemporal head with a temporal-gradient consistency objective extends Depth Anything V2 to video, plus a keyframe strategy for long sequences. The recorded checkpoint is depth-anything/Video-Depth-Anything-Large (apache-2.0); registered at base_models/three_dimensions/depth/videodepthanything.

## Runtime contract

It is integrated as an independent geometry prior under worldfoundry/base_models and exposed through the shared geometry-prior pipeline/operator contract. Higher-level pipelines (e.g. ViPE) import it from this canonical owner instead of keeping private copies. Config resolution and pipeline/operator import are expected to pass; real prior inference remains checkpoint-gated.

## Readiness and limitations

- Checkpoint-gated: real inference needs the staged Video-Depth-Anything-Large weights.
- Relative depth focus — pair with a metric prior when metric scale is required.
