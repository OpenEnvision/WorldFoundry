Video Depth Anything brings temporal consistency to the Depth Anything family: it estimates depth over arbitrarily long videos without the flicker of frame-by-frame estimation. In this catalog it is an independent temporal depth prior that VIPE pipeline profiles can select through shared runtime config without owning the code.

## What it is for

Pick `video-depth-anything-prior` for feed-forward geometry: views in, reconstruction / trajectory / point cloud out. Use it when you need the catalog 3D route rather than a depth-only prior.

Per the upstream release, a spatiotemporal head with a temporal-gradient consistency objective extends Depth Anything V2 to video, plus a keyframe strategy for long sequences. The recorded checkpoint is depth-anything/Video-Depth-Anything-Large (apache-2.0); registered at base_models/three_dimensions/depth/videodepthanything. It is published by ByteDance.

Catalog tasks include video-depth-estimation, temporal-depth-estimation, and geometry-prior. Catalog aliases include `video-depth-anything` and `vda-prior`. Documented modalities: image in, depth out.
