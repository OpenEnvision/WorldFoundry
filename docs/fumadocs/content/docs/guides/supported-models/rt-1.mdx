**Publisher:** Google Research · Company

RT-1 (Robotics Transformer 1) is Google Research's pioneering large-scale robot transformer, trained on 130k real-robot episodes to output discretized actions from images and instructions. WorldFoundry's in-tree SavedModel adapter has completed structural offline GPU action inference with the official checkpoints and supplied synthetic 512-D embeddings; task-grounded encoding remains unverified.

## Architecture

An EfficientNet-B3 image tokenizer with FiLM language conditioning, TokenLearner compression, and a decoder-only transformer emitting discretized action tokens — served as a TensorFlow SavedModel.

## Runtime contract

Supply a 512-D language_embedding from an encoder compatible with the checkpoint along with the image and prompt. The released SavedModel does not turn prompt text into that embedding; WorldFoundry rejects text-only inference instead of silently using zeros. GPU inference needs a TensorFlow/CuDNN-compatible environment.

## Readiness and limitations

- Text-only inference requires a separately staged, checkpoint-compatible language encoder; offline action structure validation does not prove task success.
