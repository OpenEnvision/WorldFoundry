## 用来做什么

用 `hy-embodied-vla-umi` 做本卡的视觉-语言-动作推理。这条配方用来启动已记录的策略 profile。

推理专用的 mixture-of-transformers（MoT）骨干，预处理与动作解码内置树内。官方输入契约为三相机六帧；RoboTwin 解码绝对关节动作，UMI 解码相对动作。

catalog 记录的任务包括 视觉-语言-动作（VLA）、VLA 策略执行、机器人策略、bimanual_manipulation。别名包括 `hy-vla`、`hy-embodied-0.5-vla`、`Hy-Embodied-0.5-VLA`。同系列还有 `hy-embodied-vla-robotwin`。

记录的评测入口包括[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（GPU 已验证的 RoboTwin 策略 checkpoint）。

## 运行时契约

可选 `prompt`、`input_path`、`state`、`variant`、`state_format`；产物 `action_trace`、`hy_embodied_vla_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `HyEmbodiedVLAPipeline`。

起步 variant 是 `hy-embodied-vla-umi`。catalog 登记了 2 个 variant（上方卡片）：`hy-embodied-vla-umi`（`vla.policy_rollout`）：已验证、`hy-embodied-vla-robotwin`（`vla.policy_rollout`）：已验证。系列状态：**已验证**。

模拟器基准工作选 RoboTwin checkpoint，UMI 式相对动作部署选 UMI checkpoint；两者共用同一树内运行时。

验证覆盖 A100 上的动作解码；完整基准 rollout parity 单独跟踪。
