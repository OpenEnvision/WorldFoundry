Open-MAGVIT2 是腾讯 ARC 对 MAGVIT-v2 免查表（lookup-free）视觉分词器的开源复现，并在其上构建自回归生成。本 catalog 中可运行的路径是 ImageNet 类条件图像生成——完整 256 token 生成已通过 checkpoint 加载的 GPU 与语义视觉 QA 验证（256x256、ImageNet 类别 207）。产物是 PNG 图像而非视频。

## 用来做什么

`open-magvit2` 是记录的图像生成线。prompt 到图像的推理从这里起步。

树内记录两部分：带超大码本的免查表量化（LFQ）分词器，以及为指定 ImageNet 类别预测视觉 token 的自回归 Transformer。class_id 输入选择类别；生成通过内置 CUDA 封装执行。该模型由腾讯（ARC Lab）发布。

catalog 记录的任务包括 视频分词、class-conditional-image-generation、autoregressive-generation。别名包括 `open_magvit2`、`openmagvit2`。
