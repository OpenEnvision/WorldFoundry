## 用来做什么

本卡做文生图时选 `emu3.5`：prompt 进、图像出。catalog 任务是静帧而不是视频时用它。

Emu3.5 预测统一的图文 token 序列，并以离散扩散生成视觉 token，再通过独立的视觉 tokenizer 解码。该模型由北京智源人工智能研究院（BAAI）发布。

catalog 记录的任务包括 multimodal-generation、图像生成。别名包括 `emu3p5`、`emu3_5`、`BAAI/Emu3.5`。
