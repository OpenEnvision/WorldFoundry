TinyVLA 追求亚十亿级的快速、数据高效 VLA：LLaVA-Pythia 骨干（Hub 上发布 400M / 700M / 1.3B）配 ACT 或条件 1D 扩散动作头。Hub 上发布的模型是用于策略训练的 VLM 骨干——并非任务训练好的机器人 checkpoint——因此树内运行时为 checkpoint 门控，需自行就位训练好的任务策略。

## 用来做什么

`tinyvla` 是记录的指令到动作线。需要 WorldFoundry VLA rollout 而不是视频生成时从这里起步。

LLaVA-Pythia 多模态骨干配 CLIP/SigLIP 视觉融合与可换动作头（ACT 或条件 1D 扩散），全部进程内执行。支持合并权重与本地 LoRA 加非 LoRA 动作张量两种形式。

catalog 记录的任务包括 视觉-语言-动作（VLA）、VLA 动作预测、具身策略。别名包括 `tiny-vla`、`llava-pythia-vla`。

## 运行时契约

可选 `prompt`、`input_path`、`interactions`、`fps`、`timeout_seconds`；产物 `action_trace`、`tinyvla_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `TinyVLAPipeline`。

系列状态：**Runner 一致性待确认**。

在本地就位兼容的任务 checkpoint、含动作维度与头类型的 config.json 及数据集统计前，运行时构建会尽早失败。

无公开任务训练动作 checkpoint；Hub 发布仅为骨干。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run tinyvla --pipeline.task-profile default`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch>=2.5）。

记录的权重仓库包括 `lesjie/Llava-Pythia-400M`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh tinyvla`；下载缺失的公开权重时加 `--download`。

状态：**Runner 一致性待确认**。
