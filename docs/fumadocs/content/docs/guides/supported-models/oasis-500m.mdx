**Publisher:** Etched / Decart · Company

Oasis 500M (open-oasis) is the open release of the playable-Minecraft world model: an action-conditioned diffusion transformer that renders the next game frame from context frames and keyboard/mouse actions. The in-tree runtime has completed checkpoint-backed GPU inference; each installation must stage the Etched/oasis-500m checkpoint plus prompt image/video and action tensors.

## Architecture

Per the upstream release, a ViT VAE compresses frames and a 500M diffusion transformer generates the next frame conditioned on past frames and actions (MIT license). Internals beyond this are not recorded here.

## Runtime contract

Supply 25-column action tensors in the official Open-Oasis format. The upstream converter maps cameraX from MineRL camera[0] and cameraY from camera[1], then normalizes each as (raw-40)/40. MineRL defines camera[0] as vertical pitch and camera[1] as horizontal yaw, so cameraX is pitch despite its name. Sources: https://github.com/etched-ai/open-oasis/blob/f59deef2c019c212bd0c5a3a5b986a51f3701847/utils.py and https://github.com/minerllabs/minerl/blob/cdeae668c2f334e3c9117adf651b5a94436b45f8/minerl/herobraine/hero/handlers/agent/actions/camera.py. Set WORLDFOUNDRY_CKPT_DIR to the directory containing Etched--oasis-500m when using local weights; missing assets return blocked diagnostics.
